## scNET：让同一张表达矩阵在“细胞图”和“基因图”之间交替传播

### 1. 它不是只做表达插补

scRNA-seq 中的零值和噪声会削弱基因相关性，而通用 PPI 网络又缺少具体组织、细胞状态和条件信息。scNET 的目标是把两者互补起来：PPI 告诉模型哪些蛋白可能相互作用，当前数据集的表达和细胞邻域告诉模型这些关系在本条件下怎样呈现。

最终一次训练同时给出四类产物：gene embedding、cell embedding、重构表达矩阵和经过注意力筛选的 cell KNN 图。gene embedding 可用于功能/网络分析，cell embedding 可用于聚类，重构表达用于 marker 和 pathway 分析。

### 2. 输入为什么天然有两个视角

设表达矩阵为

$$X\in\mathbb R^{G\times C},$$

行是基因，列是细胞。scNET 同时构造：

- 基因图 $A_{PPI}$：节点是表达数据与 PPI 网络交集中的基因；
- 细胞图 $A_{KNN}$：节点是细胞，边来自 PCA 空间的近邻关系。

当把 $X$ 看作“每个基因在所有细胞中的特征”时，可以沿 PPI 聚合；把矩阵转置后，每个细胞以所有基因为特征，可以沿 KNN 聚合。scNET 的 dual view 不是两个独立数据模态，而是对同一矩阵反复转置，在两张图上轮流传播。

本地入口 `scNET/main.py:306-403` 完成预处理、PPI 过滤、KNN、HVG、训练/测试边拆分和训练调用。默认 PPI 分数阈值为 0.5；`build_network()` 还要求基因在当前表达数据中出现并达到最低非零比例（`:36-78`）。所以输出 gene space 是“全局 PPI 受当前数据过滤和表达约束后的条件特异表示”，并非从头推断所有真实分子相互作用。

### 3. 双视图编码器怎样工作

`MutualEncoder` 每层先在细胞维传播，再转置回基因维沿 PPI 传播：

$$X^{(l+1/2)}=GNN_{cell}((X^{(l)})^\top,A_{KNN})^\top,$$

$$X^{(l+1)}=GNN_{gene}(X^{(l+1/2)},A_{PPI}).$$

代码在 `scNET/MultyGraphModel.py:35-64` 实现这一交替过程。每轮先对 `embbed.T` 运行 cell layer，再对转回的矩阵运行 gene layer。直观上，细胞图用相似细胞平滑每个基因的信号，PPI 图再用相互作用基因传播每个细胞中的信息；多轮后两类关系互相影响。

论文将其概括为三层 GCN。当前提交实际使用 `SAGEConv` 执行这段交替传播，后续 gene/cell 降维器才使用 `GCNConv` 加 `TransformerConv`。因此核心数据流一致，但卷积算子不是逐字 Exact。

### 4. 为什么最后还需要两个专门编码器

交替传播后的矩阵分别进入：

- gene encoder：沿 PPI 用 GCN + attention 压到 75 维；
- cell encoder：转置后沿 KNN 用 GCN + attention 压到 75 维。

对应 `MultyGraphModel.py:101-175`。gene embedding 的 attention 使用 PyG `TransformerConv` 的邻居 softmax；cell embedding 使用自定义 `TransformerConvReducrLayer`，因为 cell attention 还要负责删边。

### 5. 注意力怎样把固定 KNN 变成可变邻域

论文对 cell edge $(i,j)$ 写出

$$\alpha_{ij}=\mathrm{sigmoid}\left(
\frac{(W_3x_i)^T(W_4x_j)}{\sqrt d}
\right),$$

并根据低分位数阈值删掉低质量边：

$$E'=\{(i,j)\in E:\alpha_{ij}>\beta\},\qquad
\beta=\max(0,P_{10}).$$

思想是：KNN 初始化强迫每个细胞拥有相同数量的邻居，但真实亚群密度不同，固定 $K$ 会接入跨群假边；训练得到的 attention 可让不同细胞保留不同数量的邻居。

源码 `MultyGraphModel.py:66-99` 在 sigmoid 前对 attention logits 做中心化和标准化，论文公式没有写这一步。`reduce_network()`（`:124-137`）使用第 10 百分位并保证每个源节点至少保留 10 条高分边；论文描述的最少边数是 5。训练每 30 epochs 更新一次 loader（`main.py:217-226`）。这些差异不改变“attention-driven pruning”主机制，但会改变具体图拓扑。

还有一个运行边界：当细胞数超过 10,000，入口自动转为 cell-wise mini-batching。该路径分批得到 cell embeddings 并平均 gene embeddings，却不保存一个跨全部细胞的全局剪枝 KNN 图；不能把普通模式的全部输出合同直接套到大数据分批模式。

### 6. 两个解码目标分别守住什么

#### 6.1 PPI 重构

gene embedding $z_g$ 用 inner-product decoder 区分真实 PPI 边和负采样边：

$$\mathcal L_{PPI}=-\mathbb E_{(i,j)\in E}\log\sigma(z_i^Tz_j)
-\mathbb E_{(i,j)\notin E}\log(1-\sigma(z_i^Tz_j)).$$

代码 `MultyGraphModel.py:177-196,221-224` 与此直接对应。训练前将 PPI 边按 80/20 划分，测试 AUROC 用于监控，而不是使用 cell labels 监督训练。

#### 6.2 表达重构

cell embedding 经三层全连接 decoder 还原 genes×cells 表达，HVG 子集上计算

$$\mathcal L_v=\mathrm{MSE}(M_v,\hat M_v).$$

实现位于 `MultyGraphModel.py:16-33,226-235`。这使 cell embedding 保留表达信号，也让 gene embedding 不只记住固定 PPI 拓扑。

论文给出的总损失为

$$\mathcal L=\lambda_{PPI}\mathcal L_{PPI}+\lambda_v\mathcal L_v.$$

当前代码实际还计算一个额外的 `reg`：先标准化 decoder 输出，再要求其基因相关矩阵也能重构 PPI，最终为

$$\lambda_{rows}\mathcal L_{PPI}+lambda_{cols}(\mathcal L_v+\mathcal L_{reg}).$$

该项见 `MultyGraphModel.py:228-235`，论文主损失公式未单列它，属于实现增强/差异。

### 7. 从输入到输出的实际路径

1. Scanpy 过滤、总量归一化、`log1p`，在 15 PCs 上建 KNN（`main.py:96-105`）。
2. 按 PPI 分数、物种命名、表达基因交集和非零比例建立 gene graph（`:36-78`）。
3. 选择约 3,000 HVGs；输入训练前按基因 z-score（`:153-163,371-393`）。
4. 交替在 cell KNN 和 gene PPI 上传播。
5. 生成 75 维 gene/cell embeddings；重构 PPI 和表达。
6. 周期性按 cell attention 修剪 KNN；每 10 epochs 计算留出 PPI 的 AUROC并保存输出（`:230-249`）。

当前 `run_scNET()` 默认 `n_neighbors=25`、`max_epoch=150`，而论文方法/实验常写 K=15、250 epochs。要复现实验不能只依赖函数默认值，必须使用论文对应参数。

### 8. co-embedded gene network 是训练后构造的

论文后续把 gene embedding 各维之间的相关性转为 gene–gene 网络。当前 `build_co_embeded_network()` 计算 gene embeddings 行间绝对 Pearson correlation，以全矩阵第 99 百分位为阈值二值化，再用 Louvain 检查模块度（`coEmbeddedNetwork.py:234-265`）。

因此这个 co-embedded network 不等同于训练输入 PPI：它是由“受 PPI 和条件表达共同塑造的 gene embedding”重新派生的高相关网络。绝对相关会把强负相关也视为连接；99% cutoff 又决定了稀疏度，网络结论应做阈值敏感性检查。

### 9. 网络传播如何支持 pathway 和 differential network 分析

给定网络归一化邻接 $W'=D^{-1/2}WD^{-1/2}$ 和种子向量 $F^0$，论文使用 random walk with restart：

$$F^{t+1}=\alpha W'F^t+(1-\alpha)F^0.$$

代码 `Utils.py:175-199` 设 $\alpha=0.9$、收敛阈值 $10^{-4}$，并除以全 1 种子的传播结果以校正节点中心性。`coEmbeddedNetwork.py:292-367` 用它预测 KEGG membership 并计算 AUPR；同类传播还用于 Pdcd1 差异网络和下游 TF 分析。

GO semantic similarity和 disease-list随机网络 z-score 的完整评价脚本未在当前仓库中找到；这些结果属于论文证据，不应写成包内一键可复现功能。

### 12. 生物学和使用边界

1. PPI 是先验，不是当前样本中实际发生相互作用的直接测量；embedding/co-network 只能表示条件相关的功能关联候选。
2. 模型传播会平滑信号，也可能削弱真实稀有状态；marker 和通路结果需要独立证据。
3. 物种与基因命名必须匹配 PPI；注释不足的物种覆盖会明显受限。
4. KNN pruning 依赖初始化、attention 标度和阈值，不能自动等同于真实细胞谱系。
5. 重构表达适合排序与下游探索，不应视为恢复了逐细胞真实未观测 counts。
6. co-embedded network 和 propagation 给出关联排序，不提供调控方向或因果性。

一句话总结：scNET 把表达矩阵当作连接 gene-PPI 图与 cell-KNN 图的桥梁，在两张图上交替传播，再用 PPI 重构和表达重构共同约束，使 gene 与 cell 表示既保留先验网络，又随当前生物条件而变化。

## scNET: Context-Specific Gene and Cell Embeddings via PPI Integration

**Nature Methods 2025** | DOI: [10.1038/s41592-025-02627-0](https://doi.org/10.1038/s41592-025-02627-0)

**Authors**: Ron Sheinin, Roded Sharan*, Asaf Madi* (Tel Aviv University)

---

### Motivation & Novelty

#### Biological Problem

Single-cell RNA sequencing captures cellular heterogeneity but suffers from severe **zero inflation** (>90% zero values) — a mix of technical dropout and true biological absence. This destroys gene-gene correlations, rendering coexpression analysis and pathway inference — the workhorses of bulk RNA-seq — unreliable at single-cell resolution.

Protein-protein interaction (PPI) networks encode organism-level functional relationships (complex membership, signal transduction, pathway co-participation) but are static and do not reflect condition-specific dynamics.

#### Limitations of Existing Approaches

- **Imputation methods** (MAGIC, *Cell* 2018; SAVER, *Nature Methods* 2018; DeepImpute, *Genome Biology* 2019; sctransform, *Genome Biology* 2019; CSCORE, *Nature Communications* 2023) recover expression values but don't leverage biological network structure. They focus on numerical dropout recovery rather than functional relationship inference.
- **Foundation models** (scGPT, *Nature Methods* 2024; GeneFormer, *Nature* 2023; scFoundation, *Nature Methods* 2024) capture atlas-scale dynamics but require supervised fine-tuning for specific datasets. Most newly sequenced datasets lack the cell labels needed for this.
- **Network embedding** (scLINE, *Journal of Biomedical Informatics* 2021) integrates PPI but uses a fixed cell similarity representation and cannot simultaneously refine gene-gene and cell-cell relationships.
- **Atlas-level PPI integration** (PINNACLE, *Nature Methods* 2024) learns protein representations at the tissue/organ level across atlases, not at the individual dataset level.

#### Unique Contributions

1. **First dual-view GNN** that jointly learns gene and cell embeddings by alternating convolutions on PPI (gene-gene) and KNN (cell-cell) graphs
2. **Attention-based KNN pruning** that adapts cell neighborhood size to biological heterogeneity (replaces fixed-K assumption)
3. **Unsupervised, dataset-level framework** that requires no cell labels and works on small-to-medium datasets (1K–50K cells)
4. **Co-embedded network** that integrates PPI topology with expression dynamics for condition-specific gene relationship discovery

---

### Method Overview

scNET is a graph neural network autoencoder with a **dual-view architecture**:

1. **Dual-View Encoder**: 3 layers of alternating convolutions — first smooth expression across similar cells (KNN graph), then propagate along protein interaction edges (PPI graph). Each cycle reduces technical noise while enhancing functional signals.

2. **Attention Layer**: A single attention layer produces 75-dimensional embeddings for both genes and cells. The cell encoder uses sigmoid attention (enabling global edge comparison and pruning); the gene encoder uses softmax attention (preserving PPI structure).

3. **KNN Pruning**: Every 30 epochs, attention coefficients identify low-quality cell-cell edges. Edges below the 10th percentile of attention scores are removed, with minimum connectivity preserved. This relaxes the arbitrary assumption that every cell has exactly K neighbors.

4. **Dual Decoder**: Inner product decoder reconstructs PPI edges (binary cross-entropy loss); 3-layer MLP decoder reconstructs gene expression (MSE loss on highly variable genes). An additional regularization term ensures reconstructed expression preserves PPI correlation structure.

5. **Downstream Analysis**: The framework produces gene embeddings, cell embeddings, reconstructed expression, and a pruned KNN graph — enabling co-embedded network construction, pathway enrichment, gene signature propagation, and TF discovery via random walk with restart.

See `doc_method.md` for full mathematical formulation and `doc_code.md` for implementation details.

#### Key Results

**Gene Embedding Quality** (Fig. 2):
- GO semantic similarity correlation: scNET mean ~0.17 vs. next best ~0.08 (2x improvement)
- GO-enriched clusters: consistently higher percentage across K=20-80
- MLP GO annotation prediction: highest AUROC and AUPR in 5-fold cross-validation

**Co-embedded Network** (Fig. 3):
- Modularity: substantially higher than counts-based or scLINE networks at all thresholds
- KEGG pathway reconstruction AUPR: outperforms all methods
- Disease gene list z-scores: ~7.0 vs. 3.0 (PPI) vs. 0.5 (coexpression)
- Blood cancer gene lists: best in 6/9 tested lists

**Cell Clustering** (Fig. 4):
- Usoskin DRG: highest ARI across all Leiden resolutions
- Cancer cell lines: only method to correctly cluster H1975 into a single group
- Cell cycle: ARI 0.46 vs. 0.35 (counts)
- Foundation models (scGPT, GeneFormer) showed "relatively weak performance" in zero-shot setting

**Reconstructed Expression** (Fig. 5, Table 1):
- Marker gene AUPR: scNET best in all 5 markers (Cd4: 0.85, Cd8a: 0.66, Cd14: 0.88, P2ry12: 0.97, Ncr1: 0.89)
- NK cell marker Ncr1: 122% improvement over raw counts (0.89 vs. 0.40)
- GBM pathway analysis: scNET captures cell-type-specific pathways (T cell receptor signaling, phagosome, cell cycle) while raw counts are biased toward macrophages
- Treatment response: 8/9 T cell activation pathways detected vs. 0/9 with raw counts

**Differential Network Analysis** (Extended Data Fig. 2):
- Differential co-embedded network identifies genes differentially associated with PD1 under control vs. treatment conditions
- Captures functional associations (cytokine signaling, costimulatory genes) missed by standard DE analysis

### Reproducibility

**Rating: 4/5 (Good)**

**Strengths:**
- Code publicly available on GitHub (https://github.com/madilabcode/scNET) and PyPI
- All 7 datasets publicly accessible via GEO/ArrayExpress
- Clear conda environment specification (`scNET-env.yml`)
- Pre-trained embeddings included for several datasets
- Random seed set for reproducibility (seed=42)

**Weaknesses:**
- GO semantic similarity evaluation code not included in repository
- Disease gene list z-score evaluation code not included
- Some default hyperparameters in code differ from paper (max_epoch=150 vs 250, n_neighbors=25 vs 15)
- Paper describes GCN, code uses SAGEConv; paper describes raw sigmoid, code uses standardized sigmoid — requires careful reading to match
- Undocumented regularization loss term in code

**Practical Notes:**
- Environment: Python 3.11, PyTorch 2.6.0, PyTorch Geometric 2.6.1
- GPU: 8GB minimum, 24GB+ recommended for medium datasets
- Training time: ~10 min per 1K cells on GPU (A100)
- For >10K cells, cell-wise mini-batching is auto-enabled
- Key parameter to override from defaults: `max_epoch=250` to match paper

**Strengths of the Method:**
1. Unsupervised — no cell labels required
2. Strong biological validation across multiple evaluation axes
3. Particularly effective for rare cell types and pathway analysis
4. Produces multiple useful outputs (embeddings, reconstructed expression, pruned KNN, co-embedded network)
5. Clean, modular codebase (~1200 lines total)

**Limitations:**
1. Requires existing PPI network — limited to well-annotated species (human, mouse)
2. Does not capture transcription factor-mediated regulation (indirect interactions)
3. Memory scales with N_genes² for correlation-based regularization
4. Co-embedded network construction loses sparsity guarantees at lower thresholds
5. Cell-wise batching mode cannot produce a pruned KNN graph
