## HM-OT 中文方法解读：同时学习细胞类型与跨时间分化图

### 1. 它解决的不是普通细胞匹配问题

多时间点单细胞或空间转录组给出的是不同细胞群的快照。传统流程常先在每个时间点独立聚类，再对相邻时间点做 cell-to-cell optimal transport，最后把细胞耦合汇总成 cluster transitions。这样会有两个问题：每个时间点的聚类没有利用前后时间信息；单独得到的相邻耦合也不保证形成一致的长时间轨迹。

HM-OT 把两件事放进同一个目标：

- 每个时间点的细胞属于哪些 latent cell types；
- 相邻时间点的 latent types 如何转移。

所以它的直接输出是 clusterings 和 differentiation maps，而不是必须物化的巨大 cell-by-cell transport matrix。

### 2. 输入、隐变量和输出

对时间点 $t$：

- $X^t$：$n_t$ 个细胞的表达或低维特征；
- $r_t$：用户指定的 latent type 数量；
- $Q_t\in\mathbb R_+^{n_t\times r_t}$：细胞到 latent type 的软耦合；
- $g_t=Q_t^\top\mathbf1$：各 latent type 的质量；
- $T^{(t,t+1)}\in\mathbb R_+^{r_t\times r_{t+1}}$：latent type 间的转移质量。

硬聚类可取 $\arg\max_k[Q_t]_{ik}$，而 $T$ 可画成 Sankey 或有向分化图。必须注意：$r_t$ 不是模型自动发现的，当前实现要求用户事先给出 `rank_list`；论文也把自动模型选择列为未来工作。

### 3. LC factorization 为什么能同时表达聚类和运输

相邻时间点的完整细胞耦合 $P^{(t,t+1)}$ 被分解为：

$$
P^{(t,t+1)}
=Q_t\operatorname{diag}(g_t^{-1})
T^{(t,t+1)}
\operatorname{diag}(g_{t+1}^{-1})Q_{t+1}^{\top}.
$$

可以从左到右读成四步：

1. 细胞通过 $Q_t$ 汇入起点 latent type；
2. 除以 $g_t$ 做条件归一化；
3. 通过 $T^{(t,t+1)}$ 在 latent types 之间运输；
4. 经 $Q_{t+1}$ 把质量展开到终点细胞。

例如起点有 10,000 个细胞、终点有 12,000 个细胞、两边各 20 个 types。完整 $P$ 有 1.2 亿个元素，而核心 latent transition 只有 $20\times20$。$Q$ 仍随细胞数线性增长，但避免了存储完整的二次规模 coupling。

### 4. 全时间序列目标

HM-OT 最小化所有相邻时间运输代价的和：

$$
\min_{\{Q_t,T^{(t,t+1)}\}}
\sum_{t=1}^{N-1}
\left\langle C^{(t,t+1)},
P^{(t,t+1)}\right\rangle_F,
$$

其中 $C^{(t,t+1)}$ 是相邻时间点的表达距离 cost。关键耦合在于内部时间点的同一个 $Q_t$ 同时出现在前一项和后一项；因此 $t$ 时刻的聚类必须同时解释“从哪里来”和“到哪里去”。

该目标是非凸的，论文没有宣称得到全局最优。HM-OT 采用一个可扩展的近似 MAP 流程。

### 5. 为什么叫 Hidden-Markov，但不是标准 HMM

论文把 latent types 看成隐藏状态，$T$ 看成 Markov transition，$Q$ 或归一化后的 $\Lambda$ 看成 observed cells 与 hidden types 的联系。这种结构允许把长程 latent transition 写成相邻 $T$ 的矩阵乘积。

但观测不是由一个有限参数 emission distribution 简单生成，$Q$ 和 $T$ 还受到 optimal transport marginals 和 cost 约束。对所有可能耦合做标准 forward–backward 积分不可行。论文引入 Boltzmann density，并在温度趋近零时用最低能量点的 Dirac mass 代替整个积分。

因此代码中的 `alpha_pass()`、`beta_pass()` 和 `gamma_smoothing()` 是受 HMM 启发的近似 MAP 消息传递，而不是精确 forward–backward inference。

### 6. 三遍算法怎样运行

#### α pass：把过去向前压缩

从第一个时间点向后依次求解 pairwise FRLC。每一步固定前一时间点已得到的表示，优化下一个表示。`Q_t^\alpha` 因而携带从序列开头累积来的贪心信息。

#### β pass：把未来向后压缩

从最后一个时间点反向做对称操作，得到 $Q_t^\beta$。它总结从序列末端传回来的信息。

#### γ smoothing：让内部时间点同时看两边

对内部时间点 $t$，固定 $Q_{t-1}^\alpha$ 与 $Q_{t+1}^\beta$，联合优化：

$$
Q_t^\gamma,quad T^{(t-1,t)},quad T^{(t,t+1)}.
$$

live code 的 `FRLC_LR_opt_multimarginal()` 分别计算左右相邻问题对中间 $Q_t$ 的梯度，再相加：

$$
\nabla_{Q_t}=\nabla_{Q_t}^{\text{right}}+
\nabla_{Q_t}^{\text{left}}.
$$

随后用 log-domain Sinkhorn 做 mirror-descent/projection 更新，并更新左右两个 latent transition matrices。首尾 $Q$ 直接继承 α/β 结果，只有内部时间点进行 triple smoothing。

#### Completion：固定聚类后重算最终转移

得到所有 $Q_t^\gamma$ 后，代码再逐对调用 FRLC，冻结 $Q$ 和 $R$、只更新 $T$。这一步与 supervised HM-OT 的核心相同：若所有 cell-type labels 已知，就不学习聚类，只求最优 differentiation maps。

### 7. live code 中数值更新的关键细节

`FRLC_multimarginal.py` 对 $Q_t$、左 $T$ 和右 $T$ 交替更新。几个论文公式之外但会影响复现的细节是：

- 各时间点细胞默认均匀质量 $1/n_t$；
- 合并的 $Q_t$ 梯度按最大绝对值归一化，再调整有效 step size；
- 所有约束投影使用 log-Sinkhorn，避免直接 Sinkhorn 的指数下溢；
- 一热或稀疏初始化会加入少量 outer-product mass，避免 $\log 0$；
- `HM_OT` 默认 `alpha=0.2`，即代码默认含 20% GW/空间结构项；要复现纯 Wasserstein 需显式设 `alpha=0`；
- 类构造器默认 `min_iter=max_iter=200`，所以外层 solver 默认至少运行到上限，early stopping 实际不起作用，除非用户改变参数。

这些不是“论文错误”，但意味着只照数学目标而忽略实现默认值，可能得到不同结果。

### 8. 空间数据中的 FGW 扩展

表达 cost 比较跨时间点的细胞状态；空间 Gromov–Wasserstein 项比较各切片内部的成对几何关系。混合权重 `alpha` 控制二者：

$$
\mathcal L=(1-\alpha)\mathcal L_W+alpha\mathcal L_{GW}.
$$

空间项鼓励局部组织结构被保留，但不能证明细胞真的沿图中边发生了物理迁移。不同胚胎切片的旋转、非刚性形变、细胞增殖和采样密度仍可能影响推断。

### 9. 如何读 NPMI differentiation score

对起点 type $a$ 和终点 type $b$：

$$
\operatorname{PMI}(a,b)=
\log\frac{T_{ab}}{g_a g_b},
$$

再除以 $-\log T_{ab}$ 得到 NPMI。接近 $+1$ 表示二者比独立假设更强地共处同一轨迹，接近 $0$ 表示近似独立，负值表示共同出现少于独立预期。

NPMI 是 association score，不是 ground-truth accuracy。若 annotation 本身错误，supervised HM-OT 仍会产生数学上最优但生物上可疑的 map；斑马鱼实验正是利用这种矛盾发现 12 hpf notochord annotation 的问题。

### 10. 三张主图如何连起来

- **图 1**：Waddington landscape 提供直觉；LC factorization 展示 $Q$ 与 $T$；最终输出是 cluster-level differentiation graph。
- **图 2**：固定 published labels 时得到不合理 notochord transitions；释放 12 hpf clustering 后，HM-OT 找到空间连贯的 cluster 15，并由 *chrd*、*ripply1* 等 marker 支持其 notochord 身份。这是模型提出的重新注释，并非独立 lineage-tracing 证明。
- **图 3**：在 MOSTA mouse embryo 上展示 supervised differentiation maps、与 moscot 的 NPMI 对比和所用硬件/参数下的运行能力。论文报告 moscot 在需要返回 15 亿元素 full coupling 时超出 GPU memory；这属于特定版本与实验设置下的比较，不应泛化为 moscot 在所有配置下都会失败。

核心实现高度匹配论文：

### 12. 最重要的边界

HM-OT 学到的是在表达/空间 cost、rank、regularization 与低秩约束下最优的 latent trajectories。它不追踪同一个真实细胞，也不自动确定 type 数量，更不保证非凸目标的全局最优。它最大的技术价值是让每个时间点的 clustering 同时受到过去与未来约束，并直接保留 cluster-level transition matrices；最可靠的生物使用方式仍是结合 marker、空间位置、已知谱系和独立 lineage-tracing 数据验证。

## HM-OT: Hidden-Markov Optimal Transport

**Paper**: "Learning Latent Trajectories in Developmental Time Series with Hidden-Markov Optimal Transport"
**Authors**: Peter Halmos, Julian Gold, Xinhao Liu, Benjamin J. Raphael (Princeton University)
**Venue**: bioRxiv, 2025 | DOI: 10.1101/2025.02.14.638351
**Code**: https://github.com/raphael-group/HM-OT

---

### Motivation & Novelty

#### Biological Problem

A central challenge in developmental biology is reconstructing the **Waddington differentiation landscape**: which cell types exist at each developmental stage, and which cell type at time $t$ gives rise to which cell type at time $t+1$? Modern spatial and single-cell RNA sequencing allows transcriptomic profiling at multiple timepoints, but each measurement is destructive — cells can only be measured once. The resulting data are *population snapshots*, not individual cell trajectories, requiring computational inference to link developmental stages.

#### Limitations of Existing Methods

Prior methods attack the two sub-problems of **clustering** and **trajectory inference** separately:

- **Waddington-OT** [Schiebinger et al., *Cell* 2019] and **moscot** [Eyring et al., *Nature* 2024]: use optimal transport to align cell *populations* at consecutive timepoints, but require post-processing to aggregate individual-cell couplings into cluster-level differentiation maps, with no guarantee of optimality or consistency across multiple timepoints.
- **k-NN graph methods** [Lange et al., *Nat. Biotechnol.* 2022; Volkov et al.]: heuristic connections between pairs of cell types that share many nearest neighbors, lacking a principled probabilistic framework.
- **Trajectory inference methods** [Benchmarked in DREAM challenge, Saelens et al., *Nat. Biotechnol.* 2019]: primarily designed for pseudo-temporal ordering along continuous trajectories, not for learning discrete cell-type differentiation maps from time series.

#### Key Innovations

1. **Joint optimization**: HM-OT simultaneously learns cell type clusterings $\{\mathbf{Q}_t\}$ AND transition matrices $\{\mathbf{T}^{(t,t+1)}\}$ across all N timepoints, avoiding the inconsistency of pairwise methods.

2. **Hidden-Markov formulation**: Reinterprets low-rank OT as a hidden Markov model — cells at each timepoint are drawn from latent cell types (emission distributions $\mathbf{\Lambda}_t$), with cell types transitioning via a Markov chain ($\mathbf{T}^{(t,t+1)}$). This provides a principled probabilistic framework for the differentiation map.

3. **Scalability**: The FRLC (Factor Relaxation with Latent Coupling) low-rank OT solver from [Uscidda & Cuturi, *NeurIPS* 2023] factorizes the $n \times m$ coupling matrix as $\mathbf{Q}\text{diag}(1/\mathbf{g})\mathbf{T}\text{diag}(1/\mathbf{g})\mathbf{R}^T$, avoiding storage of the full quadratic coupling and keeping the dominant factor storage linear in cell number for fixed rank. This allowed HM-OT to process more than 100,000 spots in the paper's tested setup.

4. **Supervised and unsupervised modes**: When cell type labels are available, HM-OT can compute the optimal differentiation map directly from annotations. In unsupervised mode, it can identify novel or mislabeled cell types (as demonstrated for notochord at 12hpf in zebrafish).

---

### Method Overview

HM-OT takes as input a time series of single-cell or spatial transcriptomics datasets and a specification of the number of cell types at each timepoint. It outputs:
- **Latent representations** $\mathbf{Q}_t \in \mathbb{R}^{n_t \times r_t}$: soft assignment of $n_t$ cells to $r_t$ latent clusters
- **Differentiation maps** $\mathbf{T}^{(t,t+1)} \in \mathbb{R}^{r_t \times r_{t+1}}$: cluster-level transition matrices

The algorithm approximates the maximum a posteriori (MAP) estimate of the latent representations via a three-pass message passing scheme:

1. **α-pass** (Algorithm 2): Greedy forward pass from t=1 to t=N-1; each $\mathbf{Q}_t^\alpha$ encodes past information.
2. **β-pass** (Algorithm 3): Greedy backward pass from t=N to t=2; each $\mathbf{Q}_t^\beta$ encodes future information.
3. **γ-smoothing** (Algorithm 1, core loop): For each interior timepoint, a multi-marginal OT problem jointly optimizes $\mathbf{Q}_t^\gamma$, $\mathbf{T}^{(t-1,t)}$, $\mathbf{T}^{(t,t+1)}$ conditioned on fixed neighbors $\mathbf{Q}_{t-1}^\alpha$ and $\mathbf{Q}_{t+1}^\beta$.
4. **Completion step**: Given final $\mathbf{Q}_t^\gamma$, solve $N-1$ pairwise OT problems for $\mathbf{T}^{(t,t+1)}$.

This approximation is motivated by the zero-temperature limit of a Boltzmann density on the energy (total transport cost), analogous to the Viterbi algorithm for HMMs but operating in a continuous, high-dimensional constrained space. See `doc_method.md` for full equation derivations and `doc_code.md` for implementation details.

### Evaluation

#### Datasets

| Dataset | Type | Timepoints | Cells/spots | Source |
|---------|------|-----------|-------------|--------|
| Synthetic (tristable Waddington) | Simulation | 3-5 | variable | Langevin dynamics on potential |
| Zebrafish embryogenesis | Stereo-seq spatial | 10hpf, 12hpf, 18hpf | 2081 spots @ 12hpf | Liu et al., *Dev. Cell* 2022 |
| MOSTA mouse embryogenesis | Stereo-seq spatial | E9.5–E16.5 (7 stages) | 5,913–121,767 per stage | Chen et al., *Cell* 2022 |

#### Metrics

- **AMI (Adjusted Mutual Information)**: cluster quality vs. ground truth (synthetic experiments)
- **NPMI (Normalized Pointwise Mutual Information)**: deviation of transition probability from independence. NPMI = +1 means perfect co-trajectory; NPMI = -1 means mutual exclusion.

#### Key Results

**Synthetic experiments**:
- HM-OT AMI = 0.873 vs. independent k-means AMI = 0.393 (Waddington tristable landscape), confirming that jointly leveraging temporal context improves clustering.
- HM-OT correctly identifies trajectories spanning ≥2 timepoints where pairwise low-rank OT fails.

**Zebrafish (supervised)**:
- HM-OT with published annotations [Liu et al., 2022] identifies implausible transitions (notochord at 10hpf → somite at 12hpf, NPMI = -0.107), revealing annotation errors where only 10 notochord spots appear at 12hpf.

**Zebrafish (unsupervised)**:
- HM-OT discovers cluster 15 (333 spots, spatially coherent) as a superior notochord annotation: top DE genes include *chrd* (chordin, Z=6.15) and *ripply1* (Z=10.17) — known notochord markers. Published annotation's top genes are generic ribosomal/mRNA processing proteins.
- Key transitions correctly identified: notochord→notochord (NPMI=0.665), tail-bud→notochord (NPMI=0.610), segmental plate→somite (NPMI=0.497).

**Mouse embryo (MOSTA)**:
- HM-OT scales from E9.5 (5,913 cells) to E15.5 (121,767 cells) with nearly constant runtime (8.98s → 9.31s per transition).
- In the paper's tested moscot configuration, returning the E11.5→E12.5 full coupling (1.5B entries) exceeds GPU memory; HM-OT avoids materializing that matrix and succeeds in that setup.
- HM-OT NPMI values consistently higher than moscot for same-cell-type transitions (e.g., liver NPMI = 0.713 vs -0.0475; brain NPMI = 0.351 vs -0.112).
- Known developmental trajectories recovered: lung primordium→lung (NPMI=0.927), dermomyotome→muscle (NPMI=0.968), sclerotome→cartilage (NPMI=0.866), surface ectoderm→epidermis (NPMI=0.705).

### Reproducibility

**Rating: 3/5**

#### Strengths
- Clean Python package with clear module structure (see `doc_code.md` for full map)
- Demo notebooks (`notebooks/HM_OT_SingleCell_Demo.ipynb`, `HM_OT_CoClustering_Spatial_Demo.ipynb`) provide working examples
- All experiment notebooks are included in `experiments/` (per dataset, per figure)
- `requirements.txt` provided with pinned versions
- Synthetic landscape simulation code fully included

#### Weaknesses / Pitfalls

1. **No data download scripts**: Raw data for zebrafish and MOSTA experiments must be obtained separately from original publications. Preprocessing notebooks include loading code but not download.

2. **High sensitivity to hyperparameters**: `rank_list` (number of cell types) must be specified by the user; results vary substantially. No automated selection is provided. Paper acknowledges this as a limitation.

3. **Default alpha=0.2 (FGW)**: Users expecting pure Wasserstein must explicitly set `alpha=0`. The default uses 20% GW cost even for scRNA-seq without spatial coordinates, which is suboptimal.

4. **min_iter = max_iter = 200**: Default runs always perform exactly 200 iterations regardless of convergence, making tuning non-obvious. Convergence criterion exists (`convergence_criterion=True`) but is not the default behavior (both iter counts equal).

5. **GPU memory requirements**: Experiments with large spatial datasets require GPU with ≥16GB VRAM; CPU-only mode is possible but slow.

6. **Experiment notebooks not self-contained**: Notebooks in `experiments/` require pre-processed data files not included in the repository.
