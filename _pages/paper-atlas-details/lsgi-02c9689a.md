## LSGI：在组织局部寻找“往哪个方向变化”的转录梯度

### 一句话理解

LSGI（Local Spatial Gradient Inference）把组织切成大量重叠的局部邻域，在每个邻域内用空间坐标解释一个基因程序的活性。如果局部线性回归的 $R^2$ 足够高，就认为该处存在空间转录梯度；两个坐标系数则组成一支指向程序活性升高方向的箭头。

它回答三个问题：梯度在哪里、指向哪里、由什么分子程序解释。它不是空间域聚类，也不是从一个全局轴推断连续轨迹。

### 1. 为什么需要“局部”梯度

肿瘤组织中的缺氧、代谢、细胞相互作用和边界效应可以随位置连续改变，但方向未必贯穿整张切片：相邻区域甚至可能突然转向。用一个全局坐标轴拟合整个组织会把这种变化平均掉；单细胞轨迹方法又通常假定状态沿连续流形变化，不能直接表达组织中局部、分叉或径向的空间模式。

LSGI 的策略是：先把表达压缩成可解释表型，再在许多重叠小窗口中独立拟合简单线性模型。局部模型保持可解释性，同时允许不同位置有不同方向。

### 2. 输入与输出的真实边界

核心 R 包的直接输入是：

- `spatial_coords`：$N\times2$ 的细胞/spot 坐标，列为 `X`,`Y`；
- `embeddings`：$N\times K$ 的细胞表型得分，通常是 NMF 的 cell loadings，也可以是单基因表达。

NMF 不在 LSGI 包内。论文使用外部 `singlet` 完成 NMF；vignette 也可用 RcppML。对表达矩阵 $E$，可写作

$$
E\approx HW,
$$

其中 $H$ 给出每个细胞的程序活性，$W$ 给出每个程序的高权重基因。LSGI 实际只消费 $H$；用 top-loading genes 做功能富集属于下游分析。

`local.traj.preprocessing()` 返回网格坐标、每个网格的最佳程序与箭头信息、所有“网格×程序”的完整回归结果，以及距离矩阵等中间量。一个网格可以同时对多个程序显示有效梯度，不能只看 `grid.info` 中最高 $R^2$ 的单个 `Assignment`。

### 3. 重叠空间窗口怎样产生

若有 $N$ 个细胞，参数 $S$ 控制网格数：

$$
P=\left\lfloor\frac{N}{S}\right\rfloor.
$$

默认 $S=5$。源码 `get.grid.coords()` 用 `anticlust::balanced_clustering()` 仅根据坐标把细胞分成 $P$ 个大小相近的组，每组坐标均值作为一个网格中心。然后对每个中心重新寻找最近的 $Q$ 个细胞，默认 $Q=25$。

这里“平衡聚类”只是为了让网格中心均匀覆盖组织；真正的回归窗口是中心的 $Q$ 近邻。由于 $S<Q$，一个细胞平均落入约 $Q/S=5$ 个窗口，窗口彼此重叠，产生密集而平滑的局部扫描。

$Q$ 决定空间分辨率与稳健性的权衡。小 $Q$ 能看到更细的结构，但回归更易把噪声当梯度。论文的坐标置乱实验显示 $Q=10$ 时仍可能得到中等 $R^2$ 的假阳性，而 $Q=25$ 明显更稳健。

### 4. 每个窗口里拟合什么

对窗口 $i$、程序 $j$，论文模型是

$$
F_{ij}\sim X_i+Y_i,
$$

即

$$
F_{ij,c}=\alpha_{ij}+\beta_{X,ij}X_{ic}+\beta_{Y,ij}Y_{ic}+\varepsilon_c.
$$

$F_{ij,c}$ 是窗口内细胞 $c$ 的程序活性。$R^2_{ij}$ 表示坐标能解释多少程序变化；向量

$$
\vec v_{ij}=(\beta_{X,ij},\beta_{Y,ij})
$$

指向程序活性增加最快的方向。

源码 `calc.local.linear()` 对每个网格取 $Q$ 个近邻，再对每个程序调用一次 `lm()`，保存 $R^2$、X 系数和 Y 系数。这是论文核心机制的 Exact 对应。

一个容易漏掉的实现细节是：源码先对每个局部窗口的 X、Y 分别调用 `scale()`。例如某窗口坐标 X 为 100、110、120，标准化后约为 -1、0、1；回归系数表示“坐标变化一个局部标准差”对应的程序变化，而不是每微米变化。论文方法文字没有明确写出这一步，因此不同实现若不标准化，系数大小并不等价。

### 5. 哪些回归算梯度

论文主分析保留 $R^2\ge0.6$ 的局部回归，并默认只保留至少在全部网格 5% 中出现梯度的程序。前者判断单个窗口的空间解释力，后者排除只在极少位置偶然出现的程序。

核心代码存在一个需要用户处理的接口差异：绘图和距离函数的 `minimum.fctr` 是绝对网格数，默认分别可见 5 或 10，并不会自动把“5%”换算为计数。若共有 247 个网格，论文的 5% 应约为 12 个，而不是固定 5 个。复现时应显式计算 `ceiling(0.05 * P)`。

箭头也只应读方向。`optimize.arrow()` 用组织尺度除以固定 `scale.factor=50`，再除以原向量模长，使绘图箭头接近等长。因此图上的箭头长度不是效应大小；强度应看 $R^2$、系数或程序载荷。

### 6. 梯度之间的空间距离

若程序 A 的有效梯度中心为 $G_{A1},\ldots,G_{AK}$，程序 B 的中心为 $G_{B1},\ldots,G_{BL}$，论文定义

$$
d_{Ai}^{B}=\min_j\lVert G_{Ai}-G_{Bj}\rVert_2,
\qquad
D(F_A,F_B)=\frac1K\sum_i d_{Ai}^{B}.
$$

它从每个 A 点寻找最近 B 点，再对 A 点平均。由于反方向改成对 B 点平均，通常

$$D(F_A,F_B)\ne D(F_B,F_A).$$

举例：A 有 2 个点，都靠近 B；B 有 20 个点，其中大多数远离 A。则 A→B 很小，B→A 可以很大。Figure 2B 的热图因此不应被误读为对称相关矩阵。`avg.dist.calc()` 通过两两距离、按目标程序取最近邻再求均值实现同一逻辑。

### 8. 单基因模式与跨样本结果

对 351 基因的 seqFISH 小鼠脊髓数据，作者直接把每个基因当作一个 feature，1237 个细胞形成 247 个网格；212 个基因在至少 5% 网格中出现梯度。`Sox2`、`Shh`、`Notch1` 展示不同背腹/中心模式。这说明核心局部回归不依赖 NMF，但靶向面板的单基因结果受面板选择限制。

### 10. 使用和解释时的检查清单

1. 行名和顺序是否保证坐标与 `embeddings` 一一对应？
2. $Q$ 是否足以抑制置乱数据中的假梯度？
3. 是否把论文的 5% 换算成当前网格数，而不是沿用固定 `minimum.fctr`？
4. 是否把箭头长度误作梯度强度？
5. 是否分别查看所有程序的 `local.linear.info`，而非只看每格最佳 `Assignment`？
6. NMF 的秩、随机性和 top-gene 注释是否做稳健性检查？
7. 是否把空间共定位/反向模式写成关联而非因果关系？
8. 若复现跨样本结论，是否另行获得 Zenodo 分析脚本、补充文件和原始/处理数据？

LSGI 的优势来自“局部、简单、可画出来”：每支箭头都能回到一个邻域、一组细胞和一个线性回归。它的边界同样清楚：检测的是局部线性关联，程序构建与大规模生物学解释依赖外部流程，不能由核心 R 包单独复现。

### Motivation & Novelty

#### Biological Problem

Tumor tissues display **spatial transcriptional gradients (STGs)**: cells at different tissue locations express different gene programs due to local microenvironmental signals (oxygen gradients, pH, metabolites, cell-cell signaling). This gradated variation is a major source of intratumoral heterogeneity (ITH) and is fundamentally distinct from discrete cell type variation — a boundary region cell is not simply "tumor" or "normal" but transitions continuously between states.

Standard single-cell analysis ignores spatial position entirely. Spatial domain analysis assigns cells to discrete niches, losing the gradient signal. Neither approach can answer: *where does a gradient exist, in what direction, and what pathway drives it?*

#### Limitations of Existing Methods

- **Trajectory inference** (reviewed in Heumos et al. — *Nat Rev Genet* 2023; Luecken & Theis — *Mol Syst Biol* 2019): assumes pseudotime continuity along a transcriptional axis; designed for single-cell, not spatial data; cannot detect both the existence and direction of a local gradient simultaneously
- **STew** (ref [28] in paper, journal unverified from truncated reference list): finds global spatially-informed canonical vectors; infers one global gradient per CCA dimension; prone to overfitting in complex mixed tissues
- **CopyKat** (*Nat Biotechnol* 2021): tumor annotation only; no gradient detection
- **Spatial domain methods** (BayesSpace, BANKSY): assign discrete labels; cannot represent continuous variation

#### What LSGI Contributes

1. **Simultaneous detection of gradient existence AND direction** — first method to answer both questions without prior annotation
2. **Local linear models with sliding windows** — avoids overfitting by requiring local linear fit (R² threshold) rather than forcing a global gradient
3. **NMF-based interpretable programs** — leverages established NMF approach for biologically interpretable gene programs; enables cross-sample meta-analysis
4. **Pan-cancer meta-analysis** — systematic gradient discovery across 87 tumor ST datasets from 9 studies reveals 19 meta-programs
5. **Technology-agnostic** — works for 10X Visium, seqFISH, and any data providing spatial coordinates + expression

---

### Method Overview

LSGI uses a divide-and-conquer strategy over the spatial map:

1. **NMF factorization** (external): gene expression → $K$ programs ($H$: cell loadings, $W$: gene loadings)
2. **Sliding window construction**: $P = \lfloor N/S \rfloor$ grid centers via balanced clustering; each grid captures $Q=25$ nearest cells
3. **Local linear regression**: for each window $i$ and program $j$, fit $F_{ij} \sim \tilde{X}_i + \tilde{Y}_i$ (z-scored coords); record $R^2_{ij}$ and direction $(\beta_{X,ij}, \beta_{Y,ij})$
4. **Gradient filtering**: retain gradients with $R^2 \geq 0.6$ and program present in $\geq 5\%$ of grids
5. **Visualization**: directional arrows on spatial map; asymmetric inter-gradient distance matrix $D(F_A, F_B)$
6. **Downstream**: gene set enrichment (GO, MSigDB), tumor region annotation (CopyKat), meta-program construction across samples

Key innovation: the R² criterion distinguishes spatially explained variation from random cell-cell heterogeneity. Window size Q=25 is empirically validated to minimize false positives in shuffled-coordinate controls.

### Evaluation

#### Datasets

| Analysis | Datasets | Technology | Source |
|---|---|---|---|
| GBM single sample | UKF243_T_ST | 10X Visium | RaviGBM study (Dryad) |
| seqFISH validation | Mouse embryo spinal cord | seqFISH | Lohoff 2021 (*Nat Biotechnol*) |
| Pan-cancer meta-analysis | 87 samples, 9 studies, 9 tumor types | 10X Visium / early ST | SODB, 10X Genomics, NCBI |
| Simulation | 400 gradient + 2000 random genes | SRTSim (*Genome Biol* 2023) | Simulated |

Cancer types covered: GBM, breast cancer, liver cancer, ovarian cancer, PDAC, prostate cancer, squamous cell carcinoma, bladder cancer, intestinal cancer, UCEC.

#### Results

**GBM (UKF243_T_ST)**:
- Identified 4-5 NMF programs with R²≥0.6 gradients
- Discovered opposite-directed gradient pairs: NMF_2/4 (AC-like vs hypoxia), NMF_3/5 (neurogenesis vs autophagy)
- Consistent with prior finding (Ravi 2022 *Cancer Cell*) but discovered ab initio from ST data without prior gene knowledge

**seqFISH (mouse spinal cord)**:
- 60% of 351 genes (212 genes) showed gradients in ≥5% of grids
- Confirmed known biology: Shh (ventral), Sox2 (dorsal+ventral), Notch1 (central)
- Single-gene analysis took <1 min (vs NMF-program analysis)

**Pan-cancer meta-analysis (87 datasets)**:
- 75/87 datasets had at least one gradient with R²≥0.6
- 356 gradated NMF programs identified; 266/356 (74%) clustered into 19 meta-programs
- 6 pan-cancer meta-programs: EMT, OXPHOS, smooth muscle, ECM, immune (MHC, B cell)
- Cancer-specific: keratinization (squamous), hypoxia (GBM)
- NFKB-TNFA signaling: 4 GBM programs all in tumor-interior TRC cluster 3; consistent with GBM resistance mechanism (*Cancer Cell* 2013)

**Comparison with STew** (on GBM dataset):
- Moderate correlation between NMF programs and sCVs (RV coefficient 0.33)
- Some pairs show high correlation (sCV5↔NMF2, sCV6↔NMF8) supporting robustness
- Different algorithmic approach captures partially overlapping but distinct signals

**Parameter validation**:
- Q=10: false positive gradients in shuffled data (Fig S11); Q≥25: robust
- R²=0.4-0.6 separates true from noise for Q≥25 (Fig S12)

#### Metrics

- R² as primary gradient existence criterion (goodness-of-fit to linear spatial model)
- Tumor ratio clustering (TRC) for spatial-tumor association
- Jaccard index on top-50 genes for meta-program clustering
- RV coefficient for comparing NMF vs PCA/ICA/STew embeddings
- Delta-Shannon entropy for meta-program tumor-type specificity
- Hypergeometric test (FDR-adjusted) for functional annotation

### Reproducibility: 3/5

**Justification**: Core LSGI R package is publicly available and well-documented with vignettes. However:

**Strengths**:
- LSGI R package on GitHub with 2 complete vignettes (10X Visium + seqFISH)
- 87-dataset LSGI outputs available on Zenodo (zenodo.org/records/10626940)
- Sample visualization code provided
- Clear parameter documentation in function docs and paper

**Weaknesses**:
- **Meta-analysis pipeline is NOT in the LSGI package** — separate analysis scripts on Zenodo, not integrated
- **Two different NMF implementations**: paper uses singlet package; vignette uses RcppML — different packages, potential result differences
- anticlust version constraint (≤0.6.1) not prominently documented; newer versions will silently break grid construction
- CopyKat tumor annotation, hypeR enrichment, meta-program clustering: all separate dependencies not bundled
- 87 tumor ST datasets sourced from multiple databases (SODB, 10X, NCBI, Dryad) requiring manual download
- No containerized environment (Docker/conda) provided

**Setup notes**:
```r
# Install LSGI
devtools::install_github("qingnanl/LSGI")

# Critical: use anticlust 0.6.1 or older
install.packages("https://cran.r-project.org/src/contrib/Archive/anticlust/anticlust_0.6.1.tar.gz",
                 repos=NULL, type="source")

# Additional required packages (not bundled)
install.packages(c("Seurat", "hypeR", "RcppML", "msigdbr"))
BiocManager::install("ComplexHeatmap")
# CopyKat for tumor annotation:
devtools::install_github("navinlabcode/copykat")
```

**Common pitfalls**:
1. anticlust version mismatch causes incorrect grid generation
2. `embeddings` matrix must have rownames matching `spatial_coords` rownames
3. Scale.factor=50 in `optimize.arrow` is hardcoded for Visium pixel coordinates; may need adjustment for other coordinate scales
4. NMF must be pre-computed externally; LSGI accepts any per-cell score matrix
