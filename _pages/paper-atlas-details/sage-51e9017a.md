## SAGE 中文方法解读

### 一句话理解

SAGE 先问“哪些基因最能解释空间区域”，再问“局部邻接与远距离功能相似怎样共同决定区域”。它用 NMF topic 和空间统计筛选高空间特异性基因（HSG），构造局部空间图 SAG 与非局部特征图 FAG，分别编码后用注意力融合，并以重构、图结构与跨视图聚类一致性联合训练。

### 1. SAGE 针对的三个问题

传统空间域流程常直接用 HVG 建图。HVG 反映全局方差，却未必对应空间边界；单一空间邻接图又偏向局部连续，难以连接二维切片中分离但功能相近的区域。最后，深度嵌入虽可聚类，却不直接说明哪些基因程序驱动某个域。

SAGE 的解法是两阶段串联：第一阶段用 consensus pseudo-label、NMF topic、Moran's $I$ 和随机森林选择任务相关基因；第二阶段让空间图与 topic 特征图提供互补视角。这里的 pseudo-label 会参与 topic 重要性和图边筛选，因此不是与初始化完全无关的端到端发现。

### 2. consensus matrix 是整个流程的支点

论文在多个 Leiden resolution 或候选簇数下得到标签 $\ell^{(t)}$，定义

$$
C_{ij}=\frac{1}{r}\sum_{t=1}^{r}\mathbf 1[\ell_i^{(t)}=\ell_j^{(t)}].
$$

$C_{ij}$ 是两个 spot 跨多次聚类共同归类的频率。它一方面产生初始域标签 $L_{init}$，另一方面用于剪除 SAG 的低置信边、筛选 FAG 的候选邻居。因此后续网络不是从原始表达和坐标“白纸起步”，而是在多分辨率聚类共识之上精炼表示。

完整 $N\times N$ 共识矩阵在概念上需要二次存储；论文未给出稀疏化实现或大规模复杂度实测，不能仅根据公式断言其可扩展到任意 spot 数。

### 3. NMF topic 怎样变成 HSG

SAGE 对非负表达矩阵做

$$
X\approx ZH,
$$

其中 $Z$ 给出 spot 的 topic 活性，$H$ 给出基因对 topic 的贡献。论文默认 30 个 topic。筛选分三层：

1. 用 Moran's $I$ 去除缺少空间自相关的 topic（阈值 0.2）；
2. 用随机森林从 topic 活性预测 $L_{init}$，去掉重要性最低的 20%；
3. 在保留 topic 中按贡献排名与 topic 内 z-score（阈值 1.96）提取 TSG，再与 HVG 合并并用空间自相关/跨 topic 排名精炼，得到 HSG。

HSG 因而是“全局高变异基因 + topic 特异基因 - 低空间特异基因”的混合集合。随机森林只衡量对 pseudo-label 的判别力，不证明基因是组织形成的因果驱动；topic z-score 也是 NMF 权重的相对标准化，不是差异表达检验的显著性 z-statistic。

论文用 $\tau_l$、$\tau_u$、$\theta_{mri}$、$\theta_s$ 描述若干经验阈值，但正文没有给出全部数值。缺少代码时无法确认实际数据集是否共享一套阈值。

### 4. 两张图分别看什么

SAG 从物理坐标的 k-NN 开始，再删除 $C_{ij}<0.2$ 的边，目标是保留局部连续并减少跨边界消息传播。

FAG 从 topic 向量的 cosine similarity 与 consensus 邻居共同筛选候选，允许空间上较远但 topic 相近的 spot 相连。它表达的是模型定义的功能相似性；“远距离边”是否正确仍依赖 NMF topic 与初始共识，不能直接等同于真实生物通信或解剖连接。

### 5. dual-view GNN 和注意力融合

SAG、FAG 各进入一个两层编码器。第一层为各视图独立参数，第二层投影参数共享，使两种 embedding 落入可比较的潜在空间：

$$
E^{(v_1)}=\operatorname{Enc}(X_{HSG},A_{SAG}),\qquad
E^{(v_2)}=\operatorname{Enc}(X_{HSG},A_{FAG}).
$$

每个 spot 学习两个注意力权重 $\alpha_i^{1},\alpha_i^{2}$，融合为

$$
E_i^{(att)}=\alpha_i^1E_i^{(v_1)}+\alpha_i^2E_i^{(v_2)}.
$$

三条解码路径分别从两个单视图 embedding 和融合 embedding 重构 $X_{HSG}$，避免某一分支完全失去信息。注意力值表示模型在当前目标下对两视图的相对使用量，不应解释成某个 spot 的“空间作用百分比”或机制贡献。

### 6. 四项训练目标

论文总目标为

$$
\mathcal L=\lambda_1\mathcal L_{rec}+\lambda_2\mathcal L_{graph}
+\lambda_3\mathcal L_{SwAV}+\lambda_4\mathcal L_{att},
$$

初始权重写为 $\{10,10,5,1\}$。表达重构保证 embedding 保存 HSG 信息；图重构要求融合 embedding 恢复 SAG/FAG；SwAV 通过两个视图对共享聚类中心的 assignment 一致性避免逐点负样本；attention 正则抑制单视图塌缩。

论文只说训练中采用 staged dynamic weighting，没有公开完整调度、epoch、隐藏维度和更新频率。现有工作区也没有实现代码，因此旧文档中关于“具体阶段如何改变权重”“哪些 Python 类/变量对应公式”的内容都只能算推测，不能作为已验证实现。

### 7. 最终域标签仍需要外部聚类规则

网络输出融合 embedding 后，论文用 Mclust 或 Leiden 得到域标签。已知人工标签时，比较实验把目标簇数设为人工标注簇数；未知时才在 resolution 0.1–2.5、步长 0.001 上以 Calinski–Harabasz score 选 resolution。Visium 还可做 25-NN outlier correction。

因此 benchmark 不是完全 blind model selection：不少有标签实验利用了真实簇数。最终性能同时反映 SAGE embedding、聚类器、目标簇数与可选后处理，不能全部归因于 dual-view GNN。

### 结论

SAGE 的方法亮点是让 gene selection、局部空间拓扑和非局部 topic 相似性彼此约束：HSG 提供可解释特征，SAG/FAG 提供互补关系，attention 与 SwAV 把两视图合并。它在论文的跨平台 benchmark 中表现强，但正确解读必须保留三条边界：rank score 不是绝对准确率，已知标签实验使用真实簇数，且没有公开代码使实现忠实度和复现性目前无法验证。

### Motivation & Novelty

#### Biological Problem

Spatial transcriptomics (ST) technologies generate gene expression measurements at spatially resolved locations within tissue, enabling the mapping of cell types and functional states to their anatomical context. **Spatial domain segmentation** — assigning each location to a biologically coherent region — is a foundational task, but three persistent challenges limit existing methods:

1. **Local graph bias**: Methods such as STAGATE (*Nature Methods*, 2022), GraphST (*Nature Methods*, 2023), and SpaGCN (*Nature Methods*, 2021) construct graphs primarily from spatial proximity. This captures local domain continuity but cannot model functionally related but spatially distant regions (e.g., dorsal and ventral hippocampus in a 2D section, or dispersed tumor subpopulations). Over-smoothing from local message passing also blurs boundaries.

2. **Gene selection decoupled from domain identity**: HVGs capture global expression variance without regard for spatial structure; SVGs capture spatial patterning but are noise-prone. Neither is task-directed toward identifying the genes that define domain boundaries. Biologically essential but low-abundance markers can be missed.

3. **Interpretability gap**: GNN- and VAE-based methods (e.g., SEDR, SpaceFlow, conST) are "black boxes" — the learned embeddings cannot directly reveal which gene programs define each domain. Post-hoc differential expression is indirect.

#### Limitations of Closest Prior Work

| Method | Limitation |
|--------|------------|
| STAGATE (*Nature Communications* 2022) | Single spatial graph; no long-range functional edges |
| GraphST (*Nature Communications* 2023) | Single-graph; no task-directed gene selection |
| SpaGCN (*Nature Methods* 2021) | Incorporates histology but local graph only |
| STAMP (*Nature Methods* 2024) | Topic-based interpretability but no dual-view graph |
| GASTON (*Nature Methods* 2025) | Isodepth interpretability; no long-range modeling |
| BayesSpace (*Nature Biotechnology* 2021) | Statistical priors; restricted to Visium; homogeneity assumptions |
| BASS (*Genome Biology* 2022) | Hierarchical model; poor performance on high-resolution platforms |
| PROST (*Nature Communications* 2024) | Good marker detection; inconsistent across platforms |

#### Unique Contributions of SAGE

1. **Task-directed gene selection (HSGs)**: NMF-based topic modeling + random forest importance scoring identifies topic-specific genes (TSGs) that are both spatially coherent (Moran's I ≥ 0.2) and discriminative of spatial domains. HSGs are a principled hybrid of HVGs and TSGs.

2. **Dual-view graph with long-range edges**: SAG (spatial k-NN, pruned by consensus) + FAG (non-local connections via topically similar spots). The FAG enables connections between functionally related but spatially distant locations.

3. **Consensus-driven topology refinement**: Both graphs are filtered using a consensus matrix derived from multi-resolution clustering, removing noise-driven edges at domain boundaries.

4. **SwAV contrastive learning**: Cross-view cluster assignment consistency avoids the false-negative problem of standard contrastive learning in spatial data.

5. **Built-in interpretability**: Latent topics directly map to spatial domains; z-scores identify marker genes per topic without post-hoc testing.

### Method Overview

SAGE is a two-stage computational pipeline:

**Stage 1 — Gene Selection:**
- Multi-resolution clustering → consensus matrix $C$ → preliminary labels $L_\text{init}$
- NMF (30 topics) decomposes expression into spot-topic weights $Z$ and gene-topic weights $H$
- Topics filtered by Moran's I spatial autocorrelation ($\geq 0.2$) and random forest discriminative importance (top 80% retained)
- TSGs: high-rank AND high z-score genes from selected topics
- HSGs: union of refined HVGs and TSGs, with a net-gain constraint ensuring spatially relevant content

**Stage 2 — Dual-View Graph Neural Network:**
- SAG: spatial k-NN pruned by consensus confidence ($\tau = 0.2$)
- FAG: non-local edges from intersection of consensus-similar and topic-similar neighbors
- Two GCN branches (separate $W_1$, shared $W_2/b_2$) produce view-specific embeddings $E^{(v_1)}, E^{(v_2)}$
- Self-attention fusion: per-spot weights $\alpha_i$ from tanh→softmax → fused $E^{(v_\text{att})}$
- Three symmetric decoders reconstruct $X_\text{HSG}$ from all three embeddings
- Joint loss: $\mathcal{L}_\text{total} = 10\,\mathcal{L}_\text{recon} + 10\,\mathcal{L}_\text{graph} + 5\,\mathcal{L}_\text{SwAV} + 1\,\mathcal{L}_\text{att}$

Final clustering uses Mclust (for layer-structured tissues) or Leiden (with CH-score grid search). Optional 25-nearest-neighbor outlier correction for Visium data.

See `doc_method.md` for the paper's mathematical description. `doc_code.md` records that no implementation source was available; implementation architecture and defaults therefore cannot be verified.

### Evaluation

#### Datasets and Metrics

**34 real-world ST datasets** spanning 7 platforms:
- 10x Visium (12 datasets): DLPFC (12 slices, 3 donors), human breast cancer
- Stereo-Seq (9 datasets): mouse embryo
- BaristaSeq (3), MERFISH (5), osmFISH (1), STARmap (3+1): imaging-based mouse brain
- Additional: zebrafish melanoma, rice embryonic (germination)

**8 evaluation metrics** in 3 categories:
- **Accuracy**: NMI, HOM (Homogeneity), COM (Completeness)
- **Continuity**: CHAOS, PAS, ASW (Average Silhouette Width)
- **Marker quality**: Moran's I, Geary's C

Rank-based scoring (normalized to [0,1]) aggregated into Overall_accuracy, Overall_continuity, Overall_marker, and a Total score.

**17 competing methods**: Leiden, Louvain, BayesSpace, BASS, stLearn, SEDR, STAGATE, STAIG, GraphST, SpaGCN (with/without H&E), SpaceFlow, CCST, SCAN-IT, PROST, GASTON, STAMP, conST.

#### Key Results

| Metric | SAGE | 2nd best | Improvement |
|--------|------|----------|-------------|
| Overall_accuracy | **0.94** | BASS: 0.72 | +30.6% |
| Overall_marker | **0.83** | PROST: 0.69 | +20.3% |
| Overall_continuity | 0.69 (rank 5) | — | — |
| Total score | **2.45** (rank 1) | — | — |
| σ(NMI) (robustness) | **0.04** (lowest) | BASS: 0.18 | — |

**DLPFC** (12 slices, 10x Visium):
- Median NMI = 0.71, HOM = 0.72, COM = 0.71 (best overall)
- NMI for slice 151673 = 0.75; GraphST (2nd) = 0.73
- Davies-Bouldin index 2.18 vs GraphST 3.70

**Mouse brain** (integrated anterior + posterior sagittal):
- Forebrain: ARI = 0.429, NMI = 0.731 (vs 52 manual labels)
- Accurate recovery of CA1-CA3 vs DG hippocampal subfields

**Human breast cancer**:
- ARI = 0.64, NMI = 0.70 (best); identified an ECM-remodeling candidate activated niche in histologically normal-annotated tissue, which requires independent validation before a pre-malignant interpretation

**Zebrafish melanoma** (3 samples):
- SC = 0.26, DB = 1.28 (best); SCAN-IT: SC = 0.22, DB = 1.37
- Decomposed tumor-muscle interface into "leading edge" (Domain 10) and "stress zone" (Domain 12)

**Ablation study** (DLPFC, 12 slices):
- HSGs vs HVGs: NMI improvement = +12.9%, MRI improvement = +18.5%
- Both HSG selection and dual-view architecture independently improve performance; full SAGE best

#### Biological Discoveries

1. **DLPFC cortical layers**: 7 topics with distinct spatial gradients; top marker genes (MOBP for WM, PCP4 for L5-L6, PVALB for inhibitory interneurons) rank in top 10 within their topics
2. **Breast cancer — candidate activated niche**: Cluster 14 in histologically "Healthy_1" tissue shows ECM remodeling (COL1A1, COL1A2, BGN) and mesenchymal-transition-associated signatures. This motivates a pre-malignant-niche hypothesis but does not establish precancer or progression risk.
3. **Breast cancer — hybrid DCIS phenotype**: Topic 13 active in DCIS subtypes 1,2,5 but not 4; concurrent TFF1 (luminal), KRT6B (basal), SERPINA3 reveals luminal-basal hybrid state with pro-invasive priming
4. **Zebrafish melanoma — bipartite interface**: Two functionally distinct domains at tumor-muscle boundary: "leading edge" (Domain 10: cytoskeletal remodeling, immune infiltration) vs "stress zone" (Domain 12: skeletal muscle contraction, oxidative stress response)

### Reproducibility

**Rating: 2/5**

**Justification**:
- No public code or data repository. Data Availability Statement explicitly states "no new data were created or analyzed" with no code URL.
- 34 benchmark datasets are sourced from previously published studies — data accessibility varies per dataset.
- Key hyperparameters are stated (k in k-NN, τ=0.2, θ=1.96, λ={10,10,5,1}, 30 NMF topics, 100 RF trees)
- Critical undocumented: (1) staged dynamic weighting schedule for loss coefficients; (2) exact values of τ_l, τ_u, θ_mri, θ_s for HSG selection; (3) number of GCN training epochs; (4) d_hid and d_out for GCN; (5) frequency of K-Means re-computation in SwAV

**Environment**: Python (scikit-learn, SCANPY, PyTorch inferred), R (Mclust), gseapy; exact versions partially given (scikit-learn v1.7.0, SCANPY v1.10.2)

**Common pitfalls (inferred)**:
- Consensus matrix requires $O(N^2)$ memory — likely infeasible for $N > 50,000$ without modification
- R dependency (Mclust) for layer-structured tissues introduces cross-language complexity
- Post-processing (25-NN correction) should only be applied to coarse-resolution datasets; incorrect application to high-resolution data will over-smooth fine-grained domains

**Strengths**: Comprehensive benchmarking (34 datasets, 7 platforms, 17 methods), rank-based scoring avoids metric-specific gaming, biological validation beyond just clustering metrics, ablation study and robustness analysis (Figures S46-S52).

**Weaknesses**: No public code, scalability concerns with consensus matrix for large datasets, Mclust R dependency, staged loss weighting undocumented, HSG thresholds (τ_l, τ_u) not explicitly stated.
