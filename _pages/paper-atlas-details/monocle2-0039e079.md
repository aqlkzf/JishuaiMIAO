## Monocle 2 方法解读：用反向图嵌入学习分支轨迹

### 1. Monocle 2 想解决的核心问题

单细胞转录组一次只测到一个细胞的一个快照。轨迹推断要从不同细胞的表达状态重建一个假想的连续过程，并给细胞分配伪时间和分支。Monocle 2 的关键变化不是单纯换一种降维，而是把“低维表示”和“低维空间中的主图”放进同一个目标函数联合学习。

论文称这类方法为 reversed graph embedding（RGE，反向图嵌入）：普通降维学习从高维表达 $x$ 到低维坐标 $z$；RGE 同时要求低维图经过函数 $f_G$ 映回高维后能重建数据。这里的“反向”指从潜在图回到观测空间，不是把生物时间倒过来。

完整工作流有三层：

1. `dpFeature` 无监督选择能区分细胞状态的基因；
2. 默认用 DDRTree 联合学习低维坐标和树状主图；
3. 把细胞投影到树上，由用户指定根后，以图距离定义伪时间，并在分支处做 BEAM 表达分析。

### 2. dpFeature：轨迹先由哪些基因定义

补充说明给出的流程是：先过滤只在极少细胞中表达的基因（默认表达细胞比例至少 5%），对表达基因做 PCA，以前若干 PC 初始化 t-SNE，再在 t-SNE 空间用 density peak clustering 分群。最后比较“知道簇标签”和“不知道簇标签”的负二项广义线性模型，通过似然比检验找簇间差异基因；默认取 Benjamini–Hochberg 校正后 FDR 小于 10% 的前 1,000 个基因作为 ordering genes。

这一步没有使用已知时间或谱系标签，因此称为无监督。但“无监督”不等于无假设：过滤阈值、PC 数、t-SNE 邻域、密度聚类和差异检验共同决定哪些变化进入轨迹。若批次、细胞周期或应激是最强差异，主图也可能优先刻画这些因素。

### 3. RGE：为什么同时学表示和图

一般 RGE 希望找到潜在点 $z_i$、潜在图 $G$ 及反向映射 $f_G$，使高维数据可由图重建，同时图本身保持平滑：

$$
\min_{G,\mathcal Z,f_G}
\sum_i\|x_i-f_G(z_i)\|^2
+\lambda\sum_{i,j}b_{ij}\|f_G(z_i)-f_G(z_j)\|^2.
$$

$b_{ij}$ 是图的邻接关系，$\lambda$ 控制重建数据与图平滑之间的权衡。若只先降维再单独拟合树，前一步可能保留局部邻域却破坏后一步关心的分支结构；联合优化让潜在坐标和主图相互约束。

### 4. DDRTree：Monocle 2 默认怎样学习主树

DDRTree 使用线性投影矩阵 $W$、细胞低维坐标 $Z$、$K$ 个主点 $Y$、细胞到主点的软分配 $R$，以及主点之间的树邻接矩阵 $B$。可把目标读成三部分：

- $\|X-WZ\|^2$：低维坐标经 $W$ 返回表达空间后应重建数据；
- 主点连边的总平方长度：主点应形成短而平滑的树；
- $\sum_{ik}r_{ik}\|z_i-y_k\|^2$ 加熵正则：每个细胞靠近某些主点，但分配可保持柔软。

正交约束 $W^TW=I$ 避免投影方向冗余。软分配近似为距离的 softmax；温度参数 $\sigma$ 越小，越接近硬聚类。算法交替更新 $Z$、$Y$、$W$ 和 $B$，其中 $B$ 通过主点上的最小生成树更新，因此默认输出是连通、无环的主树。

主点数 $K$ 不等于细胞数。论文给出当 $N\ge100$ 时的次线性规则

$$
K=\frac{2\times100\times\log N}{\log N+\log100},
$$

它在 $N=100$ 时为 100，随后缓慢趋近 200。减少主点既提高可扩展性，也起到正则化作用：太少会抹平真实小分支，太多会保留噪声枝杈。

“自动发现分支”应准确理解为：在给定 ordering genes、维数和 DDRTree 树约束下，不需要预先输入分支数。它不表示算法能从任意输入中无偏恢复真实发育谱系，也不允许默认模型表达环或互不连通的过程。论文提到 SimplePPT、SGL-tree 和 L1-graph 等替代 RGE，其中 L1-graph 可表达环或多组件，但需要更多调参。

### 5. 从主树到细胞投影、根、伪时间和分支

DDRTree 先得到主点树，再把每个细胞投影到最近的树边。对树末端附近的细胞，算法允许沿末端边的延长线投影，以避免所有细胞堆在端点。随后把细胞投影点加入图中，沿树从用户指定根计算累计测地距离：

$$
\phi(c)=d_{\text{tree}}(c_{\text{root}},c).
$$

这就是伪时间。它只有相对顺序和图距离意义，不是小时、天数或真实动力学速率。根不是 DDRTree 从表达数据中自动识别的时间箭头；通常要靠采样时间、祖细胞标记或生物知识选择。选错根不会改变无根树拓扑，却会反转或重排生物叙事。

树中度数大于二的主点对应分叉。论文方法用深度优先遍历为状态/分支编号。编号本身不是可跨运行比较的生物标签；不同子采样、参数或根选择可能改变编号甚至局部拓扑。

### 6. BEAM：分支后基因表达何时分开

Branch Expression Analysis Modeling（BEAM）比较允许不同分支拥有不同平滑表达曲线的模型与共享曲线的模型，识别 branch-dependent genes。论文还用即时对数比（ILR）比较两个分支在同一伪时间处的拟合表达差异。

BEAM 的显著性回答“沿当前推断树和当前分支定义，哪些基因曲线不同”，不能单独证明该基因导致了分支。轨迹与检验使用相同表达矩阵时还存在选择依赖；候选驱动因子需要扰动、时间序列或独立组学证据验证。

### 10. 最安全的解释

Monocle 2 在选定基因构成的表达空间中联合学习低维表示和树状主图，再由人工指定根把树距离转成伪时间。它擅长给分支过程提供稳定、可检验的几何摘要，但树、方向和分支基因都依赖输入特征、树模型、维数与根选择；它重建的是与数据一致的轨迹假设，不是直接观测的细胞谱系。

## Monocle 2: Summary

**Paper:** "Reversed graph embedding resolves complex single-cell trajectories"
**Authors:** Xiaojie Qiu, Qi Mao, Ying Tang, Li Wang, Raghav Chawla, Hannah A. Pliner, Cole Trapnell
**Journal:** Nature Methods 14(10), 2017 | DOI: 10.1038/nmeth.4402
**PMCID:** PMC5764547

---

### Motivation & Novelty

#### The Problem

Single-cell RNA-seq enables the study of cell fate decisions at molecular resolution. "Pseudotemporal ordering" — assigning each cell a position along a developmental trajectory — allows researchers to reconstruct the gene regulatory cascades driving differentiation. However, biological processes rarely follow a single linear path: hematopoiesis, neurogenesis, and reprogramming all involve branching, where progenitor cells must choose between two or more distinct fates.

**Limitations of prior methods:**

- **Monocle 1** (Trapnell et al., *Nature Biotechnology*, 2014): ICA + minimum spanning tree. Only reconstructs linear trajectories.
- **Wishbone** (Setty et al., *Nature Biotechnology*, 2016): Nearest-neighbor graph + Dijkstra paths. Assumes exactly one branch point; requires user to specify structure.
- **DPT** (Haghverdi et al., *Nature Methods*, 2016): Diffusion maps + analytic pseudotime. Detects multiple branches but no automatic determination of how many are real.
- **SLICER** (Welch et al., *Nucleic Acids Research*, 2016): LLE + geodesic distances. Unstable under subsampling; performs poorly on 3-way branches.

All these methods identify branches **heuristically** — by analyzing patterns in pairwise distances — rather than explicitly modeling the trajectory as a geometric structure.

#### Unique Contributions

1. **Explicit principal graph**: Monocle 2 constructs an actual spanning tree on learned cluster centroids, directly encoding branch topology rather than inferring it post-hoc.
2. **Reversed graph embedding (RGE)**: Simultaneously learns a low-dimensional latent space and a function $f_\mathcal{G}: \mathbb{R}^d \rightarrow \mathbb{R}^D$ mapping back to gene expression space, ensuring the graph faithfully represents high-dimensional structure.
3. **DDRTree**: The default algorithm combines dimensionality reduction (orthogonal projection $\mathbf{W}$) with soft $K$-means clustering and spanning tree learning in a single joint optimization. $K$ grows sublinearly in cell count, giving near-linear runtime.
4. **Fully unsupervised feature selection (dpFeature)**: No prior knowledge of marker genes or trajectory structure required.
5. **No required user specification of branch count or cell fate number**.
6. **Cryptic branching discovery**: Can detect branches missed by methods that impose linear priors.

---

### Method Overview

Monocle 2 operates as a 3-module pipeline (detailed in `doc_method.md`):

**1. dpFeature (feature selection)**
tSNE → density peak clustering → pairwise DE tests between clusters → top ranking genes selected as ordering genes. Produces an unsupervised gene signature for the biological process.

**2. DDRTree (trajectory learning)**
Joint optimization of five variable sets: projection matrix $\mathbf{W}$ (dimensionality reduction), latent cell coordinates $\mathcal{Z}$, centroid set $\mathcal{Y}$, soft assignment matrix $\mathbf{R}$, and spanning tree adjacency $\mathbf{B}$. The objective minimizes reconstruction error + tree smoothness + soft clustering cost. Alternating optimization updates each variable block-wise until convergence.

**3. Pseudotime & Branch Assignment**
Cells are projected onto nearest tree edges; a minimum spanning tree is built on projection points. Pseudotime = geodesic distance from user-selected root. Branch assignment uses DFS traversal — nodes with degree 3 trigger a new branch segment.

**Key biological assumption:** Differentiation is a continuous process; cells at each developmental stage transition into the next via smooth changes in the transcriptome. Branching reflects genuine fate commitment, not technical variation.

**Computational assumptions:** The trajectory can be described by a low-dimensional linear subspace (from DDRTree's $\mathbf{W}^\top\mathbf{W}=\mathbf{I}$ constraint); the number of branches is finite and resolved by the K-centroid spanning tree.

### Evaluation

#### Datasets

| Dataset | Organism | N cells | Biology | Used For |
|---------|----------|---------|---------|---------|
| HSMM (myoblasts) | Human | ~1,000 | Skeletal muscle differentiation (0–72h) | Cryptic branch discovery |
| Paul et al. (*Nat Cell Biol*, 2015) | Mouse | 2,730 | Hematopoiesis: CMP→GMP+MEP+6 lineages | Benchmarking vs. Monocle1/Wishbone/DPT/SLICER |
| Olsson et al. | Mouse | ~400 | Myelopoiesis: WT + Gfi1−/− + Irf8−/− + double KO | Biological validation (KO experiments) |
| Simulation (neurogenesis) | — | — | Stochastic DE-driven neuron/astrocyte genesis | Ground-truth accuracy testing |

#### Metrics

- **Accuracy**: Pearson's Rho and Kendall's Tau between algorithm pseudotime and marker-based reference ordering; ARI (Adjusted Rand Index) for branch assignment
- **Robustness**: Pearson's Rho and ARI under 25× repeated 80% subsamples (pairwise consistency)
- **Autocorrelation**: Absolute lag-1 autocorrelation of spline-fitted marker gene kinetics (higher = smoother = more biologically coherent ordering)

#### Results

| Method | Branch ARI (Paul, accuracy) | Branch ARI (Paul, robustness) | Pseudotime Rho |
|--------|----------------------------|-------------------------------|----------------|
| **Monocle 2** | **Best** | **Best (far more consistent)** | High |
| DPT | High | Moderate | High |
| Wishbone | High | Moderate | High |
| SLICER | Low | Unstable | Low |
| Monocle 1 | — | Low | Low |

Key quantitative finding: Monocle 2's branch assignments were "far more consistent" under repeated subsampling compared to all competitors (Figure 1E). On the Paul dataset, Monocle 2, DPT, and Wishbone produced similar pseudotime orderings (all correlated with marker-based reference), but Monocle 2's branch assignments were more stable.

#### Biological Validation

1. **Myoblast cryptic branch**: Monocle 2 detected a branch in what Monocle 1 had reported as a linear trajectory. Only outcome F1 showed expression of *MYH2* (muscle contraction protein) and represented successful fusion into myotubes; F2 cells were isolated nuclei. BEAM analysis identified 887 branch-dependent genes (FDR < 10%).

2. **Myelopoiesis KO experiments (Olsson dataset)**:
   - WT: LSK progenitors at root; two branch points leading to F_E (erythroid/megakaryocyte), F_M (monocyte), F_G (granulocyte)
   - *Gfi1−/−*: granulocyte-fate activator lost → cells diverted to monocyte branch (F_M)
   - *Irf8−/−*: monocyte-fate activator lost → cells diverted to granulocyte branch (F_G)
   - Double KO (*Gfi1−/−Irf8−/−*): cells present on both branches but concentrated near the branch point, suggesting incomplete differentiation
   - Crucially, the **tree structure itself** was not altered by the KOs — only cell positions within it changed

3. **Complex haematopoiesis (Paul dataset, 10D)**: In 10 dimensions, Monocle 2 resolved 5 branch points and 6 distinct lineages (monocyte, neutrophil/eosinophil, basophil, dendritic, megakaryocyte, erythrocyte), consistent with known hematopoietic hierarchy.

### Reproducibility

**Rating: 3/5**

**Justification:**
- Code is publicly available at GitHub (`cole-trapnell-lab/monocle-release`) as an R package; no Python version
- This is Monocle 2 (the R package), distinct from Monocle 3 (which introduced `learn_graph()` function in R and is more actively maintained)
- All three datasets (HSMM, Paul, Olsson) are publicly available
- The paper specifies default parameter values but does not provide a detailed step-by-step tutorial for reproducing each figure; supplementary figures 1–20 are unavailable from PMC
- **Practical challenge**: dpFeature is implemented within the Monocle R package; the paper references supplementary notes for full details of the procedure, which were not available in the PMC version
- **Version note**: Monocle 2 is part of the `monocle` R package (BioConductor); Monocle 3 is a complete rewrite in a separate package (`monocle3`); the codebase in this workspace does not contain the original Monocle 2 code (skipped by user request)
- **Strengths**: Clear mathematical formulation of DDRTree objective; K formula is explicit; pseudotime and branch assignment algorithms are fully specified
- **Weaknesses**: dpFeature implementation details are in supplementary notes (unavailable); the BEAM method is not described in this paper (references a companion paper); simulation data is available as supplementary but the neuron-astrocyte SDE model is in supplementary notes

**Environment:**
- R package, requires BioConductor
- Key dependencies: DDRTree R package (wraps the C++ DDRTree implementation), igraph (tree layout), monocle (main package)

**Common pitfalls:**
- Choosing wrong root: pseudotime is entirely dependent on user-selected root tip; biological knowledge needed
- Default $d=2$ may miss branches visible only in higher dimensions; always examine scree plot
- Feature selection matters: dpFeature default settings may select different genes depending on clustering density threshold
