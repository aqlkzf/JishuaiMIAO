## Monae：用跨模态特征图连接无配对细胞的整合与插补

### 它面对的核心困难

RNA、ATAC、DNA methylation 等单细胞模态拥有不同特征空间，而且常由不同细胞测量，没有一一配对。Monae 同时解决两项任务：把不同模态细胞放进一个可比较的 latent space；再利用该细胞表示预测本模态 dropout 或另一个模态的整套特征。

它的关键思路是把信息分成两种视角。feature view 用基因—peak—甲基化位点之间的调控先验构成 guidance graph，学习每个特征的 embedding；cell view 用各模态自己的非对称 teacher/student 网络进行对比学习，学习细胞 embedding。最终的插补不是另训复杂 decoder，而是矩阵乘法：细胞 embedding 乘目标模态 feature embedding。

论文是 2024 年 Nature Communications 文章，DOI `10.1038/s41467-024-53355-6`。问题定义和 Fig. 1 位于本地 paper Markdown 开头，完整架构见 Fig. 2 与 Methods `paper.md:198-310`。

### Guidance graph：不同模态怎样有共同坐标系

设第 $k$ 个模态数据为 $X_k\in\mathbb R^{N_k\times |V_k|}$。所有模态特征节点的并集组成图 $G=(V,E)$。RNA–ATAC 以基因组位置建立 peak–gene 连接，通常设正号；RNA–methylation 以基因符号/调控关系连接，甲基化抑制通常设负号。初始权重为 1，符号 $s_{ij}\in\{-1,+1\}$ 保留激活/抑制方向（`paper.md:208-235`）。

Graph VAE 为每个特征学习高斯后验

$$
q(F\mid G)=\prod_i\mathcal N(f_i\mid\mu_i,\sigma_i^2),
$$

并以 feature embedding 内积重建有符号边。当前 `src/sc.py:14-56` 的 `GraphEncoder` 用 `GraphConv` 得到 location/scale，`GraphDecoder` 的 logits 为

$$
s_{ij}\langle f_i,f_j\rangle.
$$

图损失是边重构负对数似然加 KL。代码实现比论文“两层 GAT attention 公式”的表述更抽象：实际消息传递封装在自定义 `GraphConv`，不能仅凭 `GraphEncoder` 名字声称逐项复现论文 attention 系数。核心 signed inner-product decoder 是 Exact，具体 GAT 公式属于 Partial mapping。

Guidance graph 不是实验验证的调控网络。基因组邻近、motif 和符号是先验，图 VAE 学到的稠密相似性也可能反映共现而非直接调控。

### Cell view：teacher/student 不是跨模态配对

每个模态有参数不共享的 autoencoder。对同一个细胞，teacher 与 student 使用共享前部 Dense 表示，但 student 在 latent 前加入随机 dropout，模拟测序深度变化。相同细胞的 teacher/student 是 positive pair；batch 中其他细胞的两种视图都是 negatives。这个 positive 只在同一个模态内部构造，因此不要求知道 RNA cell 与 ATAC cell 的配对关系。

对比损失把同一细胞的两种增强表示拉近、其他细胞推远。不同模态通过共同的训练目标和 feature graph 间接进入统一空间，而不是依赖成对监督。训练完成后使用 teacher embedding $U_k$ 作为整合表示（`paper.md:238-269`）。

代码沿用了 GLUE/CoVEL 风格类名与 trainer 体系，模型组件分布在 `src/models.py`、`src/sc.py`、`src/train.py`；这说明仓库是研究代码演化快照，而非从头按论文术语重写的独立包。

### 自适应聚类怎样防止表示塌缩

只做 instance contrastive learning 可能把所有细胞均匀铺开，却不一定保持 cell-type cluster。Monae 加入 adaptive clustering head。代码 `src/loss.py:46-147` 的 DDC loss 用 soft cluster assignment $A$ 和 latent Gaussian kernel $K$ 最小化 cluster 间 Cauchy–Schwarz 相似度，同时约束 assignment 接近 simplex 顶点。`SelfEntropyLoss` 又调节 cluster 平均分布，避免所有样本落入同一类。

这是一种无监督结构偏好，不等同于发现真实 cell types。cluster 数、kernel bandwidth、batch composition 与初始表示会影响结果。论文把该模块解释为保留 biological heterogeneity；更准确的边界是它鼓励可分群的 embedding，生物标签需事后验证。

### 为什么矩阵乘法可以做插补

若 $U_k\in\mathbb R^{N_k\times m}$ 是第 $k$ 模态细胞 embedding，$F_k\in\mathbb R^{|V_k|\times m}$ 是目标模态 feature embedding，则

$$
\widehat X_k=U_kF_k^T.
$$

本模态 $U_kF_k^T$ 用于 intra-modal imputation；从源模态 $s$ 到目标 $t$ 用

$$
\widehat X_{s\to t}=U_sF_t^T.
$$

feature embeddings 通过跨模态 guidance graph 共享调控信息，所以即使 source/target cell 不配对，也能输出目标 feature vector。重构项约束 $\widehat X_k$ 接近输入 $X_k$。论文总目标为

$$
L=\alpha_1L_{graph}+\alpha_2L_{contrastive}+\alpha_3L_{cluster}+\alpha_4L_{imputation}.
$$

代码映射主要在 `src/models.py` 的总 loss 与 decode/inference 路径、`integration.py` 和三个 inference notebooks。矩阵乘法的简洁性带来可解释 feature score，但输出不是 NB/ZINB calibrated count distribution；负值处理、尺度变换和阈值化依赖具体 notebook。故“imputation counts”更适合解释为模型重构分数/经后处理的预测矩阵，不能无条件当作原始 UMI counts。

### Monae-E 加了什么

Monae-E 把细胞也加入 guidance graph：RNA 中基因—细胞边权来自归一化表达，ATAC 等模态的 feature–cell 边通常设 1；扩展图取消所有边符号，令 $s_{ij}=1$（`paper.md:293-301`）。Graph VAE 因而同时输出 cell nodes 与 feature nodes。Graph cell embedding 替代原始 count 作为 teacher/student 网络输入，论文报告这能加速收敛并支持 marker、motif 与 TF-target 分析。

代价是图显著变大，cell–feature 边把观测矩阵直接编码进图；得到的邻近关系不再只代表调控先验。取消负号也意味着 methylation 抑制方向在 Monae-E 中不再显式保留。TF-target 是 embedding similarity 候选网络，不是因果网络。

本地 `preprocess_1.py` 构造基础 guidance，`preprocess_2.py` 学习/初始化扩展实体表示，`integration.py` 训练；`liu/` 与 `prot/` 提供自动 guidance 和 RNA–protein 变体。README 的 TODO 仍写着“Complete training process for Monae and Monae-E”和 gene-network pipeline，说明公开仓库的稳定程度与论文完整内部流程可能不同。

### benchmark 结论的边界

论文以 SAS、omics-layer ASW、graph connectivity 评价 batch removal，以 MAP、cell-type ASW、neighbor consistency 评价 biology conservation，再组合 overall score。插补则常在 PCA 后用 AMI、ARI、homogeneity、NMI 比较 cluster structure。这些指标支持“表示可分且模态对齐”，但不是逐 feature 数值误差或校准评估。

10x Multiome、Chen-2019、Ma-2020 等本来含 paired cells，论文通过打乱或忽略配对来测试无配对训练；评估仍可利用标签/真值。Muto-2021 是真正不成对。mouse cortex 三模态检验 signed graph，human 15 organs 检验规模。结果说明方法在作者设定上有竞争力，不证明任意新模态只要构图就能可靠翻译。

### 最稳妥的使用方式

先审查 guidance graph 的边、方向和 feature coverage；整合结果同时检查 batch mixing 与 cell-type conservation；插补结果保留 source/target modality、预处理尺度和预测标记。对 marker、TF-target 或 cross-modal feature 结论，应回到配对数据、原始 peak/gene signal 或独立实验验证。Monae 的优势是让完全无配对训练成为可能，而不是消除无配对问题本身的不可识别性。

## MONAE: Modal-Nexus Auto-Encoder for Multi-Modality Cellular Data Integration and Imputation

### Publication Information
- **Title**: Modal-nexus auto-encoder for multi-modality cellular data integration and imputation
- **Authors**: Zhenchao Tang, Guanxing Chen, Shouzhi Chen, Jianhua Yao, Linlin You, Calvin Yu-Chian Chen
- **Journal**: Nature Communications (2024)
- **DOI**: https://doi.org/10.1038/s41467-024-53355-6

---

### Motivation & Novelty

#### Biological Problem
Multi-modality single-cell data (e.g., scRNA-seq + scATAC-seq) presents two fundamental challenges:
1. **Integration**: Cells measured across modalities have heterogeneous feature spaces with no pairing information, making it difficult to create unified representations
2. **Imputation**: Dropout events (zero counts due to measurement limitations) obscure true biological signals, and cross-modal imputation is needed when joint measurements are unavailable

#### Limitations of Existing Approaches
- **Projection-based methods** (Seurat, LIGER, Harmony): Directly project to shared feature space, destroying biological heterogeneity
- **Paired-data methods** (scButterfly, UnitedNet, BABEL): Require expensive cell-paired multi-modal measurements
- **Multi-task methods** (MultiVI, JAMIE): Underperform compared to dedicated integration methods on unpaired data

#### Key Innovations
1. **Modal-Nexus Graph Learning**: Uses regulatory relationships between modalities (gene-peak connections) to construct guidance graphs, enabling cross-modal information sharing
2. **Asymmetric Contrastive Learning**: Teacher-Student network architecture with adaptive clustering to preserve biological heterogeneity
3. **Unified Integration-Imputation Framework**: Cell representations from integration directly serve as basis for imputation
4. **Monae-E Extension**: Adds cells as graph nodes to accelerate convergence and enable biological discovery (TF-target network inference)

---

### Method Overview

#### Architecture Components
1. **Graph VAE** (Fig. 2a): Learns feature embeddings from cross-modal guidance graph
   - Encoder: 2-layer GAT with signed edge weights
   - Decoder: Bernoulli distribution over edge existence

2. **Asymmetric Networks** (Fig. 2b): Per-modality encoders with Teacher-Student branches
   - Shared Dense layers transform counts/embeddings
   - Student branch has random dropout for data augmentation

3. **Contrastive Learning + Adaptive Clustering** (Fig. 2c):
   - Positive pairs: Same cell from Teacher and Student branches
   - Negative samples: All other cells in batch
   - Clustering loss: Orthogonality between cluster soft labels

4. **Imputation Decoder** (Fig. 2d):
   - Simple matrix multiplication: $\hat{\mathbf{X}}_k = \mathbf{U}_k \cdot \mathbf{F}_k^\top$
   - Cross-modal: $\hat{\mathbf{X}}_t = \mathbf{U}_s \cdot \mathbf{F}_t^\top$

#### Loss Function
$$L = \alpha_1 L_{graph} + \alpha_2 L_{contrastive} + \alpha_3 L_{cluster} + \alpha_4 L_{imputation}$$

Default weights: $(\alpha_1=0.3, \alpha_2=0.25, \alpha_3=0.25, \alpha_4=0.2)$

### Evaluation

#### Datasets
| Dataset | Cells | Modalities | Technology | Pairing |
|---------|-------|------------|------------|---------|
| 10x-Multiome | 9,631 | RNA + ATAC | 10x Multiome | Paired (used as unpaired) |
| Chen-2019 | 9,190 | RNA + ATAC | SNARE-seq | Shuffled pairs |
| Ma-2020 | 32,231 | RNA + ATAC | SHARE-seq | 4 batches |
| Muto-2021 | 44,190 | RNA + ATAC | snRNA/snATAC | Unpaired |
| Mouse Cortex | Variable | RNA + ATAC + Methylation | Various | Unpaired |
| Human 15 Organs | 4.78M | RNA + ATAC | Various | Unpaired |

#### Metrics
- **Integration**: Overall score (batch removal + biology conservation)
  - Batch removal: SAS, omics layer ASW, graph connectivity
  - Biology conservation: MAP, cell type ASW, neighbor consistency
- **Imputation**: AMI, ARI, HOM, NMI (clustering quality after PCA on imputation counts)

#### Key Results
1. **Integration** (Muto-2021, unpaired):
   - Monae/Monae-E achieve best overall scores
   - Outperform both multi-task methods (MultiVI, scButterfly) and dedicated integration methods (GLUE, CoVEL)

2. **Large-scale Integration** (Human 15 Organs, 4.78M cells):
   - Monae-E converges fastest (additional biological information accelerates training)
   - Memory usage lower than CoVEL
   - Better modality alignment for specific cell types (Hepatoblasts, Cardiomyocytes)

3. **Intra-modal Imputation**:
   - PCA on imputation counts shows better cluster separation
   - Outperforms DCA, MAGIC, MultiVI on clustering metrics

4. **Cross-modal Imputation** (RNA→ATAC, ATAC→RNA):
   - Comparable or better than scButterfly
   - Preserves rare cell type discrimination (Treg, gdT)

5. **Biological Discovery** (Monae-E):
   - Correct gene-cell type associations (marker genes near corresponding cell clusters)
   - Validated TF-target networks (17/40 HNF4A targets supported by literature)
   - Peak-gene regulatory relationships validated (chr1:100719411-100719996 ↔ VCAM1)
