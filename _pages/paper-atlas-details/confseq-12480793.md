## ConfSeq 方法详解

### 先说结论

ConfSeq 是一种面向三维分子构象的序列描述语言。论文的核心想法是：在保持 SMILES 紧凑、可读的同时，把二面角、键角和伪手性等内部坐标离散成 token，于是三维构象预测、从零生成和表示学习都可以改写成 Transformer 的序列建模问题（论文预览 `paper.md:9-12`）。

需要注意证据范围：当前获取到的是 Nature 的订阅预览，包含摘要、六幅主图及图注、数据/代码可用性和参考文献，但没有完整 Methods、补充材料正文或图中所有数值。下面把论文主张、官方代码确认的行为、解释性推断和缺失证据分开写。

### 它解决什么问题？

普通 SMILES 很适合表达原子连接关系，却不能唯一表达一个分子的三维构象。若直接用点云或笛卡尔坐标训练模型，表示会受到平移、旋转和坐标系选择影响，也不容易直接接入成熟的语言模型。ConfSeq 把几何信息放回类似 SMILES 的离散序列中；论文声称这种表示具有 SE(3) 不变性，并且兼顾可读性（`paper.md:12`）。

### ConfSeq 序列是什么？

对一个带 RDKit 三维坐标的分子，代码生成两个对齐的字符串：

```text
输入序列：连接关系/顺反异构/伪手性 token + ^ |
目标序列：同样的结构 token + <整数角度> |
```

官方实现的词表包含 ASCII 可打印字符、`<-180>` 到 `<179>` 的整数角度 token，以及 `<mask>`, `<unk>`, `<sos>`, `<eos>`, `<pad>`（`ConfSeq_repo/conformation_prediction/train_model.py:16-25`）。因此角度在代码中按整数度离散；论文预览没有给出更完整的量化误差或不变性证明。

### 从三维分子编码到 ConfSeq

```text
RDKit 三维分子
    |
    +-- 测量选定单键的二面角
    +-- 计算可保留的键角
    +-- 序列化 SMILES/顺反信息
    +-- 加入伪手性标记
    +-- 输入位置写入 ^ |，目标位置写入 <angle> |
    v
(in_smiles, TD_smiles)
```

`get_ConfSeq_pair_from_mol` 会先复制分子并计算角度；随后获得基础 SMILES、二面角、伪手性和等价原子信息，过滤冲突项，加入顺反异构与伪手性标记，最后按原子 token 位置插入角度占位符/数值（`demo/ConfSeq.py:525-568`）。选取二面角的辅助函数只考虑两侧存在邻居的单键，并从 RDKit conformer 读取角度（`demo/ConfSeq.py:78-107`）。

### 从 ConfSeq 解码回三维分子

`get_mol_from_ConfSeq_pair` 的代码流程是：

1. 从目标序列提取 `<整数角度> |`，从输入序列删除 `^ |` 占位符，并清理顺反标记的空格（`shape_conditioned_generation/src/utils/ConfSeq_3_2.py:958-982`）。
2. 依据输入 SMILES 构造带伪手性的 RDKit 三维分子（`:982-986`）。
3. 重新定位角度中心原子，只对恰好有两个重原子邻居的中心设置生成的角度；连接双键氧的特殊邻居会被排除（`:987-1029`）。
4. 解析二面角并应用到 conformer；遇到闭环键时，先暂时断开最后的成环键，在无环结构上处理剩余二面角，再恢复原键型（`:996-1025`）。
5. 从输入 SMILES 恢复 isotope 信息并返回分子（`:987-997`）。

这解释了为什么“生成了一个 token 序列”不等于“得到一个有效构象”：RDKit 回映可能失败。构象预测脚本会捕获异常，只保留成功回映的分子（`conformation_prediction/run_conf_gen.py:291-300`, `374-389`）。

### 构象预测：条件式 BART

#### 训练

`train_model.py` 配置了六层 encoder、六层 decoder、每侧八个 attention heads、(d_mathrm{model}=256)、共享 embedding、最大位置长度 512 和 0.3 dropout（`conformation_prediction/train_model.py:31-59`）。训练样本来自三个增强文件；输入前置 `<sos>`，目标前置 `<sos>` 并追加 `<eos>`，batch padding 后截断到 256 token（`:91-181`）。

代码会对目标中的角度 token 注入环绕的随机扰动，且小扰动概率更高（`:70-87`, `106-111`）。训练使用忽略 `<pad>` 的交叉熵，Adam 的 `lr=1.0`、β=(0.9, 0.998)、ε=1e-9，并使用 16,000 warm-up steps 的 Noam 学习率调度；梯度范数裁剪为 2（`:208-271`）。这些是当前代码快照的确认行为，不是从缺失的论文 Methods 中推回的设置。

#### 推理

`generate_mols_from_smiles` 会校验 SMILES、选择最大片段、先生成一个起始构象、清理无效手性并随机化/增强原子顺序，然后编码为 `in_smiles`（`run_conf_gen.py:406-431`）。采样阶段请求目标数量两倍的序列，使用 temperature、top-k、top-p 和随机种子；每条序列都会尝试回映到 RDKit 分子，失败的丢弃，直到收集到所需数量（`:303-391`）。返回分数是选中 token 概率的几何平均（`:350-361`）。

### 无条件生成

`unconditional_generation/run_uncond_gen.py` 使用 causal BART。它先过采样，再把词表按索引分成两组，对两组使用不同温度，随后用 transition score 排序并重建分子（`:142-208`）。这条路径对应“从零生成分子”的任务，但论文预览没有给出发表版本的采样参数和每个基线的完整配置。

### 形状条件三维生成

`shape_conditioned_generation/run_shape_gen.py` 从参考分子构造点云和法向量，进行归一化/缓存后输入 SurfaceBART-v2；生成时可分别控制 atom token 和 angle token 的温度，之后回映分子并计算 shape/graph similarity（`:183-286`）。命令行主流程会加载本地或 Hugging Face 模型，输出 pickle、SDF、CSV、图片和 MOL 文件（`:390-467`）。图 4 的示意图与该代码路径相符，但点云采样细节和论文的具体指标公式在当前证据中缺失。

### 表示学习与形状检索

表示学习训练脚本只保留 BART encoder，用两个 ConfSeq 的 mean-pooled hidden states 做配对学习。代码计算欧氏距离 (d)，再转为 (s=1/(1+d))，以 MSE 拟合输入的相似度标签（`representation_learning/train.py:114-123`, `230-244`）。

检索脚本把一个 ConfSeq 转为 mean-pooled embedding，再通过 FAISS 搜索 PubChem 或 ZINC，输出 CSV 和 SDF 命中物（`representation_learning/run_shape_screen.py:232-248`, `573-618`）。这确认了“序列表示 -> 相似性检索”的实现，但不等于复现图 5 的全部基准结果。

论文摘要声称 ConfSeq 在多种 benchmark 上达到 state-of-the-art，并发现 STING/ALDH1B1 抑制剂（`paper.md:12`）；图 2-6 展示相应比较和实验验证。当前官方仓库确实有核心编码/解码、四类任务入口和检索工具，但没有找到论文专属 release tag、完整 Methods/补充材料、所有 checkpoint/FAISS 资产、自动化测试，或湿实验验证脚本。`SDEGen_repo` 仅用于保留论文提及的 GEOM-Drugs 数据来源，不应当被当作 ConfSeq 实现。

## ConfSeq: Bridging 3D Molecular Structures and AI with a Conformation Description Language

### Problem

SMILES are compact and readable but do not fully describe a molecule's 3D conformation. ConfSeq addresses this representation gap by encoding molecular connectivity together with discrete internal-coordinate information so that 3D molecular tasks can be expressed as token sequence modelling (`paper.md:9-12`).

### What the paper introduces

ConfSeq combines SMILES-like tokens with dihedral angles, bond angles and a pseudo-chirality descriptor. The paper claims that this preserves readability, provides SE(3)-invariant 3D information and lets standard transformer architectures handle conformation prediction, de novo generation and representation learning (`paper.md:12`). The six figures cover the representation, conformer prediction, unconditional generation, shape-conditioned generation, representation learning and an inhibitor-discovery application (`paper.md:58-85`).

### High-level method

The verified implementation follows a shared encode/model/decode pattern:

```text
RDKit 3D molecule
  -> SMILES/isomer/chirality tokens + discrete angle/dihedral annotations
  -> BART or SurfaceBART sequence model
  -> generated ConfSeq target / pooled encoder embedding
  -> RDKit 3D molecule, SDF, similarity report or retrieval hits
```

`demo/ConfSeq.py` creates aligned input and target strings, inserting `^ |` placeholders in the input and integer `<angle> |` tokens in the target (`:525-568`). Its inverse reconstructs a 3D RDKit molecule by setting angles, applying dihedrals and restoring ring bonds (`:958-1029`). The official repository also contains BART training/inference for conformer prediction, causal unconditional generation, SurfaceBART-v2 shape-conditioned generation and encoder/FAISS screening; direct code evidence and limitations are detailed in `doc_code.md` and `doc_method.md`.

### Evaluation and application claims

The abstract reports state-of-the-art performance across diverse benchmarks and novel STING and ALDH1B1 inhibitors with half-maximal inhibitory concentrations of 0.338–3.51 μM (`paper.md:12`). Fig. 2-5 visually compare ConfSeq with baselines for conformation, molecular-distribution, shape-generation and representation tasks; Fig. 6 shows a screening funnel, candidate structures, dose-response curves and western-blot-style validation. Exact panel values, benchmark definitions, baseline settings and experimental protocols are not available in the acquired publisher preview, so these remain paper claims rather than locally reproduced results.

### Reproducibility

The official code repository is `ConfSeq_repo` at commit `39ab3e360765732fa2ffad666313a23b6ab6803b`; the paper states that code and processed data are available through GitHub and Zenodo (`paper.md:95-104`). The snapshot provides task scripts and configuration files, but pretrained checkpoints, large embedding/index assets and some datasets are external.

Reproducibility is therefore **medium**: the core representation and task entry points are inspectable and have direct source anchors, but the acquired preview omits full Methods/equations and supplementary results, no paper-specific release tag was found, no automated tests were found, and the experimental inhibitor-validation workflow is absent from the official code snapshot.

### Main limitations and open gaps

- Full Methods, equations, supplementary legends and panel-level numerical results were not present in the acquired publisher preview; only links to them were available (`paper.md:273-280`).
- Exact paper-to-code version correspondence is partial because the analyzed official repository commit is not identified as a publication tag.
- External checkpoints, FAISS indices and processed datasets must be downloaded before the task runners are complete.
- Code verifies shape-based retrieval but not compound triage, biological assays or western-blot validation behind Fig. 6.
