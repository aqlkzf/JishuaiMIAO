## VIS-seq：把遗传变异身份与数百万张单细胞图像连接起来

### 方法要解决的问题

传统 deep mutational scanning 常把每个变异压缩成一个生长、丰度或活性分数，但同一蛋白变异可能同时改变蛋白丰度、亚细胞定位、聚集、信号通路和细胞形态。VIS-seq（variant in situ sequencing）要在 pooled 实验中保留这种多维表型：每个细胞既知道表达了哪个变异，又保留可复查显微图像和数百至上千个形态特征。

本文对约 3,000 个 LMNA/PTEN 变异分析约 1,140 万张细胞图像。LMNA 在 U2OS LMNA-KO 细胞中研究核纤层、聚集和核形态；PTEN 在 iPS 与 NGN2 neuron-like cells 中研究丰度、pAKT 活性和核/胞质定位。核心是一条“变异文库 → 圆形 RNA barcode → 图像 → 原位测序 → 细胞分割 → feature matrix → variant profile”的链条。

### 1. 圆形 RNA barcode 解决 pooled imaging 的身份问题

每个 piggyBac cassette 一条启动子表达 protein variant，另一条表达含 12-base variant barcode 的 circular RNA。低 multiplicity of integration 尽量使一个细胞只携带一个变异。细胞固定后，barcode 被 reverse transcribe、padlock capture 和 rolling-circle amplify，再逐轮原位测序；同时可用抗体、RNA FISH 与细胞器染料获得 phenotype images。

线性 RNA barcode 在大量细胞中只有 0–1 个 read；圆形 barcode 使 93% 表达细胞具有至少 2 个 reads，reads/cell 较全体细胞提高约 13 倍。圆化提升局部可测分子数，不会自动消除 sequencing error、multiple integration 或 cell-boundary assignment error，因此仍需 barcode quality 和多 barcode 过滤。

表达 cassette 加入 insulators、ubiquitous chromatin opening element、intron 和 viral regulatory element，以抵抗 iPS 及分化细胞中的 transgene silencing。这是平台跨 U2OS、iPS 和 neuron-like context 的前提；不同细胞类型中的表达仍需单独 QC。

### 2. STARCall 将显微图像变成 genotype–phenotype 单细胞表

STARCall 是独立但直接服务 VIS-seq 的图像管线。它用 Snakemake 串联 microscope input、tile stitching、跨 cycle alignment、read detection/base calling、cell/nucleus segmentation、phenotyping 和 output merging。大图被切成 grid tiles 以控制内存并行处理；phenotype 与 sequencing cycles 可在不同倍率下采集，再统一配准。

输出以 cell 为行，包含 barcode/read identity、位置、QC、segmentation 和 CellProfiler features。该工作区实际含两个互补代码快照：`starcall-workflow/` 负责原始图像到 genotyped cells×features matrix；`visseq/` 负责该矩阵到 variant-level morphology profiles、KS/EMD、聚类和论文分析。

两者都是论文所需代码，但不是同一仓库；本次合同将 code source 设为 VISseq 工作区根目录，并分别记录 primary VISseq 与 auxiliary STARCall，避免把 STARCall commit 冒充 VISseq commit。

### 3. 从图像提取单细胞 morphology features

LMNA 图像包含 mEGFP-lamin A、DAPI、phalloidin、WGA 和 mitochondrial RNA FISH；PTEN 包含 mEGFP-PTEN、pAKT、细胞结构/核染色等。CellProfiler 在 nucleus/cell/object 上计算强度、纹理、granularity、radial distribution、shape、通道相关性和共定位指标。

代码将 intensity features 细分为 integrated、mean、median、min/max、standard deviation、quartile、mass displacement 和 edge；radial features 分 FracAtD/MeanFrac/RadialCV；correlation features 分 Costes、Manders、overlap、RWC 等（`visseq/analysis_tools/utils.py:3719-3827`）。这说明 profile 不是一个黑箱 image embedding，而是大量可解释且有冗余的 engineered features。

LMNA 初始每细胞 1,077 个可重复 features，覆盖约 660 万细胞和 1,767 个变异。坐标、方向等非生物 features 被 blocklist 去除。分割错误会同时污染强度、shape 和 localization，因此 STARCall/CellProfiler QC 是所有下游统计的共同上游边界。

### 4. 为什么每个 feature 同时用 median 和 EMD

对变异 $v$ 和 feature $f$，median 描述典型细胞：

$$m_{vf}=\operatorname{median}\{x_{if}:i\in v\}.$$

但相同 median 的两个变异可能一个均匀、另一个含强烈亚群。Earth Mover's Distance 比较 variant 与 WT 的完整分布：

$$W_1(P_{vf},P_{WT,f})=\int_0^1|F^{-1}_{vf}(q)-F^{-1}_{WT,f}(q)|dq.$$

median 捕获位置偏移，EMD 同时对分布形状和 heterogeneity 敏感。`perform_KS_test.py` 对 variant×feature 做 KS test 和 EMD；`generate_profiles.py` 合并 median/EMD，并用 25 组 WT bootstrap 估计 EMD 背景、MAD normalization 和 IQR threshold 筛除不稳定 feature。

最低 cells/barcode 和 barcodes/variant 门槛减少单个整合位点或小样本偶然性。许多 cell 共享同一 barcode 并不等同于独立变异重复，barcode-level replication 很关键。

### 5. Feature selection 与 morphological profile

LMNA 删除 745 个低方差、高相关或 EMD 复现性差的 features，保留 332 个 selected features。pycytominer 做 variance、correlation 和 blocklist 过滤，再按 synonymous variants（LMNA）或全体 variants（PTEN）z-score。每个变异的 median+EMD 向量就是 morphological profile。

另有 407 个 hit features，定义为跨 variants 最稳定受扰动的 feature，用于解释而不是训练唯一 score。selected 与 hit 集合目标不同：前者避免冗余并建立 profile；后者帮助回答哪些结构最常被改变。

feature selection 使不同通道/feature family 较平衡，但 threshold 和 normalization reference 会改变距离结构。以 synonymous 作 reference 隐含同义变异总体接近 WT 的假设。

### 6. 两种总分回答不同问题

Morphological impact score 汇总 variant profile 到 WT profile 的距离，表示总体改变幅度；论文使用 cosine-based dissimilarity。它回答“整体偏离 WT 多远”，但方向相反的不同机制可能有相似幅度。

Distinguishability score 为每个 variant 单独训练 gradient-boosted tree，在 single-cell features 上区分 variant 与 WT，并以 held-out AUROC 表示。高 AUROC 意味着存在稳定可辨的细胞表型，即使 variant population 内部复杂；它不是临床 pathogenicity probability。

LMNA 两个分数跨重复高度一致，并能区分 aggregating/ClinVar pathogenic controls；control separation 不能保证对所有 VUS 或不同细胞环境同样校准。

### 7. LMNA：从 profile cluster 到结构机制

LMNA profile 先 PCA（约 70% variance），再 cosine UMAP；Louvain 得到 10 个 clusters。四个 landmark features 帮助解释：nuclear lamin A intensity、nuclear-boundary intensity、granularity 和 nuclear circularity。

Clusters 8–10 富集已知 aggregating variants，表现为 boundary abundance 下降、granularity 上升和 circularity 降低；clusters 2–4 是较轻的 abundance/localization 缺陷。cluster 1 变异反而增加 nuclear circularity 和 nuclear-interior lamin A，提示 gain-of-function-like mechanism。将效应映射到 lamin A rod-domain 结构后，linker/coil 位置与聚集或核形态方向关联。

聚类是表型相似性摘要，不代表唯一机制；同一 cluster 内仍有异质 effects，结构相关也需生化/力学实验确认。

### 8. PTEN：分开丰度、活性和定位

PTEN profile 在 iPS 和 induced neurons 中比较 mEGFP abundance、pAKT pathway activity、nuclear/cytoplasmic distribution 及形态。三者相关但不等价：低 abundance 常降低功能，却有 variants 在 abundance 尚可时发生 nuclear mislocalization。

作者用 kernel ridge regression 预测 localization feature，再以 residual 构造 mislocalization score，以提取不由 abundance/activity 解释的定位异常。残差依赖回归形式和 covariate 完整性，并非定位的直接纯化真值。

PTEN profiles 对 ASD/developmental delay 与 PTEN hamartoma tumor syndrome variants 呈不同组合。三分类 SVC 用 stratified 5-fold CV 区分 gnomAD、ASD/DD、PHTS。临床 variants 来自人工和 LLM-assisted literature curation；标签异质性与 ascertainment bias 是模型边界。

### 10. 代码覆盖与复现边界

`starcall-workflow` 覆盖图像输入、stitching/alignment、sequencing/read calling、segmentation、CellProfiler phenotyping 和 merge；`visseq/analysis_tools` 覆盖 aggregate、KS/EMD、profile generation，论文 notebooks/Zenodo 衍生数据用于 LMNA/PTEN figures。variant AUROC classifier 在另一个 `fisseqtools` repo，不在本地；完整实验还依赖 CellProfiler pipeline、原始多轮显微图和 barcode–variant map。

`visseq/analysis_tools/utils.py` 很大且包含许多辅助/绘图函数，不能视为端到端入口。入口分别是 STARCall Snakemake target 与 `generate_profiles.sh` / `generate_metrics.sh`。可靠复现应分层：先用 STARCall example dataset 检查 cell/read output，再对公开 Zenodo 数据运行 variant summary，最后才尝试全原始图像。

最强结论是：VIS-seq 能在 pooled 条件下为数千变异生成可重复的多维图像表型，并揭示单一 abundance/activity assay 看不到的 mechanism continuum。它不应被简化为 pathogenicity classifier；分数和 clusters 是特定细胞、染色 panel、feature pipeline 下的表型测量。

## VIS-seq Summary

### Motivation & Novelty

#### Biological Problem
Genetic variants in disease genes produce complex, multidimensional phenotypic effects. For genes like *LMNA* and *PTEN* — where the same gene harbors variants causing completely different diseases — understanding *which* molecular phenotype is disrupted is essential for clinical interpretation. Current deep mutational scanning assays measure only one-dimensional readouts (cell growth, protein abundance), missing protein mislocalization, organelle disruption, nuclear morphology changes, and cell-type-specific effects.

#### Limitations of Prior Approaches
- **Deep mutational scanning** (Findlay et al., *Nature* 2018; Olvera-León et al., *Cell* 2024): measures cell growth in cancer cell lines; most disease genes are not growth-essential; no mechanistic insight
- **VAMP-seq / abundance assays** (Matreyek et al., *Nat. Genet.* 2018; Beltran et al., *Nature* 2025): measures steady-state protein abundance; misses mislocalization and catalytic defects
- **Arrayed imaging** (Lacoste et al., *Cell* 2024): measures mislocalization in one cell type; not pooled; ~3,000 variants maximum; one readout at a time
- **Yeast fitness DMS** (Mighell et al., *Am. J. Hum. Genet.* 2018): not a human cell context; measures only activity
- **Existing pooled CRISPR imaging screens** (Feldman et al., *Cell* 2019; Funk et al., *Cell* 2022): designed for gene knockouts, not protein-coding variant libraries; linear RNA barcodes fail in iPS cells
- **Transcriptomic screens** (Ursu et al., *Nat. Biotechnol.* 2022): missense variants often don't alter transcriptomes strongly; miss protein-level effects

#### Key Innovations
1. **Circular RNA barcode** (Lalanne et al., *Nat. Methods* 2024; Litke & Jaffrey, *Nat. Biotechnol.* 2019): 13× more in situ sequencing reads per cell than linear RNA; enables reliable barcode calling in iPS cells
2. **Anti-silencing expression cassette (PBv2)**: UCOE + EF1a promoter + HBB intron 2 + IRES + WPRE + cHS4 insulators; sustains transgene expression for 14+ days in iPS cells and 56 days in cardiomyocytes
3. **STARCall**: simultaneous stitching + alignment + read calling across phenotyping and sequencing cycles; eliminates need for sub-pixel pre-registration; novel ZNCC-based edge filtering + L1 global position solve
4. **Multidimensional morphological profiles**: captures protein abundance, localization, aggregation, organelle state, and cell architecture simultaneously from one experiment

---

### Method Overview

VIS-seq is a pooled, image-based platform for measuring variant effects on molecular and cellular phenotypes simultaneously. A library of mEGFP-tagged protein variants in the PBv2 expression cassette is integrated at low MOI via piggyBac transposition into appropriate knockout cells. Cells are fixed, barcodes are amplified by rolling-circle amplification, and cells are imaged with a panel of fluorescent stains (Cell Painting approach). After dye removal, barcodes are sequenced in situ using reversible-terminator chemistry. STARCall stitches and aligns images, calls bases, and maps barcodes to variants. CellProfiler extracts ~1,000–3,200 morphological features per cell. The cells×features matrix is then processed to generate **morphological profiles** (selected z-scored feature medians + EMDs) and two summary scores: a **morphological impact score** (cosine distance from synonymous median) and a **distinguishability score** (AUROC of an XGBoost classifier trained to distinguish variant from WT at single-cell level).

**Applied to ~3,000 variants**:
- *LMNA* rod domain (aa 178–273): 1,767 variants expressed in U2OS LMNA-KO cells; stained with DAPI, phalloidin, WGA, mitoprobe; ~6.6M cells
- *PTEN* catalytic domain (aa 112–172): 1,228 variants expressed in PTEN-KO iPS cells and NGN2-induced neurons; stained with DAPI, phalloidin/MAP2, ConA, anti-pAKT antibody; ~5M cells

#### Key Results

**LMNA**:
- Synonymous vs. missense distinguishability: impact scores significantly lower for synonymous (Mann-Whitney p < 0.001)
- Aggregating control detection: distinguishability AUC = 0.99; impact score AUC = 0.94
- ClinVar P/LP detection: distinguishability AUC = 1.0; impact score AUC = 0.88
- Louvain clustering: 10 clusters with distinct biological interpretations; 90% of synonymous variants in WT-like clusters (5/6/7)
- Linker 12 subdomain enrichment in cluster 1 (high nuclear circularity): Fisher exact q < 0.001 — supports flexible linker structural model
- Multimer-facing positions: 100% aggregation-sensitive; dimer-facing positions: 67% abundance-sensitive (χ² p < 0.001)
- Variant effect predictor correlation with LMNA impact: Spearman ρ = 0.27–0.35 (poor)

**PTEN**:
- Replicate correlation: impact scores r = 0.88/0.89 (iPS/neurons); impact scores r = 0.95 between cell types
- Clinical variant performance: VIS-seq distinguishability AUC = 0.94–0.97 (ClinVar); BETTER than AlphaMissense (0.74), EVE (0.90–0.95)
- ASD/DD vs. PHTS discrimination: VIS-seq 3-class SVC macro-AUC = 0.92; AlphaMissense = 0.76; EVE = 0.76
- Key finding: ASD/DD-associated variants have nuclear mislocalization as dominant phenotype; PHTS-associated variants have stronger pAKT activity effects
- 43/72 (72%) variants at membrane-binding positions (163-164) have high mislocalization with WT-like activity
- Cell-type-specific effects: 43% variants alter PTEN abundance in iPS vs. 52% in neurons (χ² p < 0.001); localization more affected in iPS (67%) than neurons (48%)

### Reproducibility Rating: **4/5**

**Justification**:
- ✓ Full analysis code available (visseq + starcall-workflow GitHub repos)
- ✓ All variant scores deposited in MaveDB (urn:mavedb:00001243-a, 00001244-a/b)
- ✓ Feature-level data available on Zenodo (record 15787685)
- ✓ Image data + CellProfiler pipelines available in BioImage Archive (S-BIAD3095)
- ✓ Plasmids deposited in Addgene (252243, 252244, 252245)
- ✓ Snakemake workflow (starcall-workflow) with clear config and rules
- ~ XGBoost classifier training code in separate fisseqtools repo (not cloned here; referenced in README)
- ~ Some analysis in Jupyter notebooks rather than script form; requires Zenodo data download to run
- ✗ In situ sequencing requires specialized microscopy setup (Nikon Ti2-E with specific light engine); 3+ days per 12-bp barcode read

**Practical notes**:
- **Environment**: conda environment with Python 3.11 + requirements.txt (pycytominer 1.2.1, XGBoost 3.0.1, scikit-learn 1.5.2)
- **Entry point**: Download Zenodo data → run notebooks directly for figures 2–6; for upstream pipeline, use starcall-workflow Snakemake
- **Common pitfall**: pAKT channel bleed-through from ConA must be corrected before feature extraction (PTEN experiments only)
- **Common pitfall**: Edit distance thresholds differ between genes (≤1 LMNA, ≤2 PTEN) — must be set correctly in aggregate_features.py
- **Common pitfall**: EMD normalization by MAD (not mean) before IQR thresholding; using wrong normalization will change feature selection
- **Scale**: Full re-run from images requires substantial compute (11.4M cells, parallel CellProfiler, parallel XGBoost training for ~3,000 classifiers)

**Strengths**: Extremely well-documented; multiple data deposition venues; reproducibility verified in two biological replicates for each gene; Snakemake workflow enables HPC deployment

**Weaknesses**: Manual in situ sequencing is labor-intensive (~1h/base → 12 days for 12-bp barcode); XGBoost classifier training code in separate repo not included in primary analysis repo; some platform-specific microscopy requirements
