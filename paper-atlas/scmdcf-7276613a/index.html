scMDCF 中文方法解读

核心结论

scMDCF 整合同一细胞配对测量的 RNA+ADT 或 RNA+ATAC。两个模态先经独立编码器；IIC 风格的跨模态损失在群体层面对齐两个潜表示并用熵项避免坍缩；两个表示再拼接、非线性投影成共同潜空间。共同表示既被解码回两个输入，又以 DEC 风格 Student-t 软分配和自训练目标强化簇结构。

下文以较新的 scMDCF/ 为 code source。

1. 输入和预处理

输入是按细胞一一配对的 $X_{omic1}\in\mathbb R^{n\times m_1}$、$X_{omic2}\in\mathbb R^{n\times m_2}$。论文对 CITE-seq 选择 1000 个高变基因并保留全部 ADT；RNA+ATAC 选择 2500 个高变特征。教程对两个 AnnData 都调用 normalize()：过滤零计数特征、按细胞归一化、log1p、HVG 和标准化。

论文说 ATAC 遵循 episcanpy 流程，而教程使用共享 Scanpy 风格函数，二者不能视作完全一致。更严重的是，utils.py::read_data() 的 .h5 分支把 RNA 和第二模态都从键 X1 读取，像复制错误；使用默认 SNARE spleen_lymph.h5 前必须检查 HDF5 键。双 .h5ad 文件路径不走这个分支。

2. 两个模态编码器

每个网络块为

\[h^{l+1}=\operatorname{ReLU}(\operatorname{BN}(h^lW^l+b^l)).\]

源码对每一层（含最后层）都追加 Linear、BatchNorm1d、ReLU。CITE-seq 编码层为 RNA {1000,512,64,8}、ADT {n_ADT,512,64,8}；SNARE 两个编码器为 {2500,512,64}，fusion {128,32,8} 才产生 8 维公共表示。

前向顺序是关键：先用未经 softmax 的 $z_{RNA},z_{other}$ 拼接并融合，之后才分别 softmax。融合和重建使用连续预激活特征；softmax 输出只用于跨模态损失。

3. “对比学习”实际比较潜在维度

源码不使用 InfoNCE，也不构造正负细胞对。对 softmax 后的两个 $n\times k$ 表示，它计算

\[P_{ab}\propto\sum_i z^{(1)}_{ia}z^{(2)}_{ib},\]

对称化、归一化成 $k\times k$ 联合分布，再最小化

\[\mathcal L_{cl}=-\sum_{a,b}P_{ab} [\log P_{ab}-(\lambda+1)\log P_a-(\lambda+1)\log P_b].\]

它最大化两个模态潜在维度的统计依赖，并以边缘熵避免质量集中到少数维度。$P$ 是 latent-feature 联合表，不是 cell-cell 对应矩阵。教程 lamb：CITE 0.5、SNARE 10。

4. 融合、重建和聚类

\[Z=f_{fusion}([Z_{RNA}\|Z_{other}]).\]

CITE fusion {16,8} 一层，RNA+ATAC {128,32,8} 两层。两个解码器只读取同一个 $Z$，分别以 MSE 重建两种预处理矩阵。模型没有缺失模态 mask，要求完整配对输入。

对 $z_i$ 和簇中心 $\mu_j$，Student-t 软分配为

\[q_{ij}\propto(1+\|z_i-\mu_j\|^2/\alpha)^{-(\alpha+1)/2}.\]

目标分布

\[p_{ij}\propto q_{ij}^2/\sum_iq_{ij}\]

强调高置信分配，并以 $KL(P|Q)$ 自训练。簇数由外部数据/标签提供，不是模型自动选择；真实标签只用于 NMI/ARI 等评估，不进入梯度。

5. 两阶段训练和 paper-code 差异

主教程导入 train.py。预训练使用 Adam+AMSGrad、学习率 $10^{-2}$、200 epoch：

\[\mathcal L_{pre}=\mathcal L_{RNA}+\mathcal L_{other}+0.1\mathcal L_{cl}.\]

随后在 $Z$ 上用 KMeans (n_init=20) 初始化可学习簇中心，再以 Adadelta、学习率 $10^{-3}$、200 epoch 优化源码硬编码目标：

\[\mathcal L_{alt}=0.1\mathcal L_{RNA}+10\mathcal L_{other} +\mathcal L_{KL}+5\mathcal L_{cl}.\]

论文写 Adadelta $\rho=0.95$，源码是 rho=.8，这是明确差异。每 10 epoch 重跑 K-means仅用于监控与最终 y_pred，没有把中心重新写回 cluster_layer，所以 DEC 分配与监控 K-means 是并行路径。

仓库另有 train_param.py：其预训练 contrastive 项被注释，且最后以 argmin(q) 取簇标签；主教程不调用它。复现必须指定 train.py，不能混用两个分支。

6. 其他实现陷阱

  • nn.Softmax() 未显式指定 dim，依赖 PyTorch 的旧推断行为。
  • self.gamma 是未使用的可学习参数；聚类权重来自 args.gamma。
  • 论文熵系数与代码 lamb 对应，而 Student-t 的自由度参数使用 alpha；符号不要混淆。
  • 教程把整矩阵一次送进 GPU，不是 mini-batch；大数据扩展受显存限制。
  • 代码未设随机种子，K-means 和网络初始化会产生运行间差异。
  • 损失第二模态权重 10 同时用于 CITE/ATAC，不能只解释为补偿 ATAC 稀疏性。

7. 图和生物学结论的边界

图 2–4 是模型聚类、批次整合、超参数和消融证据，应逐数据集逐指标阅读，不能概括为所有指标均第一。图 4 同时承担调参，不能当独立外部验证。

图 5–8 的 peak-gene、motif、CellChat、trajectory、GSVA、ELF1 regulon 等并非网络直接输出，而是以 scMDCF 分群为入口，再调用 Seurat、Signac/ArchR、CellChat、Monocle3、RcisTarget 等工具。scMDCF 支持“给出用于下游分析的表示/簇”，不能把所有生物发现归因于 contrastive loss。

AD 案例中的 ELF1 是计算候选关联，未构成因果生物标志物验证。ligand-receptor probability、pseudotime 和 peak-gene linkage也各自依赖下游模型假设。

8. 复现边界

可直接确认作者 repo、两个快照 commit、主教程参数、网络结构、两阶段训练、损失权重、$\rho$ 差异和本地数据。仍缺少锁定环境、随机种子、论文数字对应的确切 commit、GPU/运行日志、数据校验和，以及 .h5 键错误的作者预期。当前未重跑论文全部 benchmark 和下游生物流程。

scMDCF Summary

Paper: Aligned cross-modal integration and regulatory heterogeneity characterization of single-cell multiomic data with deep contrastive learning Journal: Genome Medicine (2026) DOI: 10.1186/s13073-025-01586-7 Authors: Yue Cheng, Yanchi Su, Yi Fan, Yuning Yang, Xingjian Chen, Fuzhou Wang, Ka-Chun Wong, Xiangtao Li Code: https://github.com/DARKpmm/scMDCF

Motivation & Novelty

Biological problem: Single-cell multi-omics technologies (SNARE-seq, CITE-seq) simultaneously measure two molecular layers per cell — RNA + chromatin accessibility (ATAC) or RNA + surface proteins (ADT). Integrating these modalities is essential for understanding cell identity, regulatory mechanisms, and disease-specific heterogeneity. However, the modalities differ dramatically in scale (RNA: ~20k genes; ATAC: ~500k peaks; ADT: ~100-300 proteins), sparsity, and biological meaning.

Limitations of existing approaches:

  • BREM-SC (Nucleic Acids Res., 2020) and MOFA+ (Genome Biol., 2020): Statistical methods assuming positive correlations or specific distributional forms (Dirichlet, Gaussian). Fail when modalities capture uncorrelated or negatively correlated processes.
  • CiteFuse (Bioinformatics, 2020) and Seurat V4 (Cell, 2021): Linear similarity matrix fusion. Cannot capture nonlinear manifold structures; distorts geometry of high-dimensional sparse data.
  • GLUE (Nat. Biotechnol., 2022) and scCross (Genome Biol., 2024): Require curated regulatory priors (gene-peak graphs) that may be incomplete or unavailable.
  • scMDC (Nat. Commun., 2022): Concatenates raw omics before encoding — loses modality-specific features.
  • Cobolt (Genome Biol., 2021), totalVI (Nat. Methods, 2021), MultiVI (Nat. Methods, 2023): VAE-based joint probability models. “Black-box” latent variables; difficulty interpreting biological relevance.

Unique contributions:

  1. Cross-modality contrastive learning without negative sampling: Uses IIC-style mutual information maximization between modality-specific representations, avoiding biologically inappropriate negative pairs.
  2. Entropy regularization for modality-specific heterogeneity: Explicitly preserves unique information in each modality via information entropy maximization.
  3. Two-phase training: Pre-training for representation learning, then alt-training with KL-divergence clustering loss — prevents premature cluster collapse.
  4. Automatic cluster number estimation: Louvain + silhouette score for datasets without ground truth labels.
  5. Minority cell population detection: Demonstrated on Alzheimer’s disease dataset (105k cells) identifying Microglia (3%) and Endothelial cells (0.24%).

Method Overview

scMDCF is a deep autoencoder with contrastive learning for scMulti-omics integration. The pipeline has six stages:

  1. Preprocessing: Library size normalization → log1p → HVG selection (1000 for CITE-seq, 2500 for SNARE-seq) → z-score scaling
  2. Modality-specific encoding: Independent MLP encoders (Linear+BatchNorm1d+ReLU blocks) compress each omics to a shared latent dimension
  3. Cross-modality contrastive learning: IIC loss maximizes mutual information between softmax-transformed encoder outputs while entropy regularization prevents collapse
  4. Feature fusion: Concatenated encoder outputs projected through a nonlinear MLP to 8-dimensional common latent space
  5. Reconstruction decoding: Symmetric decoders reconstruct each modality from the common latent
  6. Self-optimizing clustering: Student-t soft assignments + KL divergence loss refines cluster structure; K-means initialization after pre-training

Key biological assumptions:

  • Paired cells from the same biological entity should have consistent representations across modalities
  • Modality-specific features (e.g., ATAC accessibility patterns unique to a cell type) should be preserved, not collapsed
  • The 8-dimensional common latent is sufficient to capture cell type structure

See doc_method.md for full mathematical derivations and doc_code.md for implementation details.

Evaluation

Datasets:

  • 4 labeled scRNA+ATAC datasets: pbmc 10k, multiome bmmc, human brain 3k, pbmc 10x public
  • 4 unlabeled scRNA+ATAC datasets: GSM4949911, nextgem chromium, mouse brain 5k, hpap
  • 3 CITE-seq datasets: inhouse (1,372 cells), GSE128639 (30,672 cells), spleen lymph (16,282 cells, 2 batches)
  • Large-scale: 647,366-cell Sanger multiome (scalability test)
  • Application: GSE171964 (113,897 cells, post-vaccination CITE-seq), GSE214979 (105,332 cells, AD snMultiome)

Metrics: NMI, ARI, AMI, V-measure, Homogeneity (labeled); ASW, DB, CH (unlabeled); iLISI, cLISI, batchKL (batch effect, R-only)

Comparative results:

  • Highest NMI, AMI, HOM, V-measure across all 4 labeled RNA+ATAC datasets vs scMDC, scCross, scMoMaT, Seurat-V4 WNN, MOFA+, Cobolt, GLUE, MultiVI, FigR, scDeepCluster, scziDesk, SCALE
  • Highest AMI, NMI, V-measure across all 3 CITE-seq datasets vs scMDC, Seurat-V4, MOFA+, BREMSC, totalVI, MultiVI, scDeepCluster, scGAE
  • Lowest DB, highest CH on 3/4 unlabeled datasets
  • Fastest runtime among GPU-accelerated methods; scales to 300k+ cells (claimed; mini-batch not in released code)

Biological validation:

  • SNARE-seq: Identified 8 PBMC cell types; peak-gene linkages consistent with known marker genes (GZMB→NK, IFITM3→CD8+ T); BHLHE40 motif in CD8+ T cell peaks
  • CITE-seq (GSE128639): 10 bone marrow cell types; IL-2 signaling pathway in Treg differentiation via CellChat
  • Post-vaccination CITE-seq: 4 B cell subpopulations; MIF signaling via CXCR4/CD44/CD74 in memory B cells
  • Alzheimer’s disease: ELF1 as novel TF biomarker in Microglia; GTPase regulator activity enrichment; ELF1 regulon genes (DOCK4, ELMO1, etc.) downregulated in AD vs healthy Microglia

Reproducibility

Rating: 3/5

Justification: Core model and training code are clean and well-organized. Tutorial scripts reproduce the main CITE-seq and SNARE-seq results. However, several gaps reduce reproducibility:

Strengths:

  • Python package on PyPI (pip install scMDCF==1.1.3)
  • All datasets available on Zenodo (https://zenodo.org/records/11019640)
  • Tutorial scripts for CITE-seq and SNARE-seq with exact hyperparameters
  • Benchmark scripts for all competing methods

Weaknesses:

  • Batch training not implemented: Paper claims scalability to 300k+ cells via “batch training strategy” but tutorials load all data to GPU at once. Reproducing the scalability benchmark requires unreleased code.
  • Rho discrepancy: Paper says Adadelta rho=0.95, code uses rho=0.8 — minor but affects exact reproducibility.
  • Downstream analysis is R-only: Peak-gene association (ArchR), motif enrichment (Signac), cell-cell communication (CellChat), trajectory (Monocle3) — all R packages. No Python equivalents provided.
  • Batch effect metrics R-only: iLISI, cLISI, batchKL require the R lisi package.
  • Auto-K not wired in tutorials: The Louvain+silhouette auto-K strategy is in utils.py:GetCluster() but not called in main_CITE.py or main_SNARE.py.
  • h5 format bug: utils.py:43-44 reads both RNA and ATAC from key ‘X1’ — copy-paste error.
  • Large dataset results: AD and vaccination datasets (100k+ cells) require substantial GPU memory and are not directly reproducible from tutorials.

Environment: Python 3.9.16, PyTorch 2.2.1, CUDA 12, Ubuntu 18.04. Setup: pip install scMDCF==1.1.3.
