PRP-TCR：用深度肽识别谱训练 TCR 特异性模型

一句话理解

PRP-TCR 不是只靠 TCR 序列猜抗原，而是先用酵母展示为每个 TCR 实验测量一张覆盖海量肽的“识别指纹”——peptide recognition profile（PRP），再用这些密集的阳性/阴性配对微调蛋白语言模型。模型学到的是某一个 TCR 或一组相近 TCR 对肽序列的经验识别规则，随后才被用于人蛋白组候选自身抗原筛选。

论文的关键贡献因此是一个闭环：深度实验测量产生监督信号，模型把有限筛选结果外推到未测肽，细胞、四聚体和晶体结构实验再验证候选。它不是一个仅凭预训练语言模型零样本预测所有 TCR–肽相互作用的通用系统。

研究问题与证据范围

同样的 CDR3 序列可能有不同功能，不同序列也可能收敛识别相同肽，因此“序列距离近”不能可靠代表“功能距离近”。论文选取 16 个与强直性脊柱炎（AS）和急性前葡萄膜炎（AAU）有关、受 HLA-B*27:05 限制的 TCR，利用这个结构上由 CDR3β 主导肽接触的窄 TCR 家族，研究三件事：

  1. 怎样实验测出单个 TCR 的大规模肽识别谱；
  2. 怎样把 PRP 训练成可预测未测肽的模型；
  3. 怎样判断模型对一个新 TCR 是否仍可信。

主文 paper.md:15-37 给出总体问题与平台，Figure 1a–c 展示“酵母筛选—模型—TCR/PRP 双层空间”。结论的外推边界是这个 HLA、固定锚点的 9-mer 库以及 β 链主导的疾病相关 TCR 家族。

第一阶段：把一个 TCR 的识别偏好测成 PRP

实验把 9-mer 肽、β2-microglobulin 和 HLA-B*27:05 重链连成单链三聚体，展示在酵母表面。肽库固定 P2 的精氨酸和 P8 的脯氨酸，其余关键位置变化，理论规模约 $10^9$。每个可溶性 TCR 对该库进行四轮选择；富集酵母经过测序后，得到肽序列在各轮的计数（paper.md:31-35,1527-1547）。

监督标签来自明确阈值：round 4 计数 $\geq5$ 为阳性；round 2–4 均为 0 为阴性（paper.md:1549-1551）。所以 PRP 不是所有肽的物理亲和力连续曲线，而是由特定展示体系、筛选浓度和计数规则得到的密集结合标签与序列偏好。

Figure 1a 把单个 TCR 对海量 HLA-B*27:05 肽库的筛选画在实验端；Figure 2c 显示不同 TCR 得到的阳性肽从数百到 6,000 余个，说明识别广度本身也存在明显差异。

PRP 为什么比 TCR 序列距离更有信息

对两个 TCR，论文把各肽位点的氨基酸分布用 Jensen–Shannon 距离比较，再在可比较位置上求平均：

\[d_{JS}(p,q)=\frac1{|I|}\sum_{i\in I} \sqrt{\frac{D_{KL}(p_i\|m_i)+D_{KL}(q_i\|m_i)}2}, \qquad m_i=\frac{p_i+q_i}{2}.\]

Methods 排除 P2、P8、P9，因为这些位置受到 MHC anchor 或建库固定设计限制（paper.md:1623-1635）。Figure 2d 和 Extended Data Figure 3 表明按 PRP 聚类得到的功能邻域与 CDR3β edit distance 并不等价：序列不同的 135.1、135.3、135.8 可以形成紧密识别簇，序列相近者也可有不同 PRP。

这里的 JS 距离是实验 PRP 之间的功能距离，不是模型训练损失。公共仓库没有提供完整的 motif/JS 分析流水线，论文说明其使用 SciPy、MoDec 与自定义脚本（paper.md:1595-1599）。

第二阶段：TCRPNet 如何从两条序列得到一个结合分数

模型输入是 CDR3β 氨基酸序列和 9-mer peptide，输出是一个未经过 sigmoid 的 binding logit。核心路径可分成四步。

1. 同一个 ESM2 分别编码 TCR 与肽

论文使用 ESM2-650M。代码的 DiscriminativePL.forward() 对 TCRβ 和 peptide 分别调用同一个 ESM encoder，提取第 33 层逐位置表示（source/trainer_esm.py:61-95）。

有效 residue mask 排除 padding、<cls> 和 <eos>，对逐位置向量做 masked mean，得到两个 1280 维 sequence-level embedding（trainer_esm.py:97-106）。代码随后去除特殊 token，并给每个残基的 1280 维 ESM 表示拼接 20 维 one-hot，形成 1300 维逐位置输入。传给 PyTorch attention 前还要反转 mask，因为数据 collater 的 True 表示有效位置，而 MultiheadAttention 的 True 表示忽略（trainer_esm.py:108-116；source/data.py:202-269）。

2. 两个独立 Transformer 汇总位置模式

TCRβ 和 peptide 各自通过一个六层、十头的 Transformer encoder。每层含自注意力、前馈、残差和 LayerNorm；最后从 1300 投影到 1280，并在长度维上 masked mean pool（source/transformer.py:137-212）。

因此 Transformer 分支返回的不是残基×残基接触图，而是 TCR 和肽各一个 1280 维向量。论文 Figure 1b 用“position-wise encoding → Transformer → feature fusion”表达这条路径，Methods paper.md:1601-1603 给出架构描述。

3. 两类向量各做外积，形成两个通道

代码分别对原始 ESM mean-pooled 向量和 Transformer-pooled 向量做外积：

\[M^{ESM}=z_{TCR}^{ESM}(z_{pep}^{ESM})^T,\qquad M^{Tr}=z_{TCR}^{Tr}(z_{pep}^{Tr})^T.\]

每张图是 $1280\times1280$，再堆成两个通道（source/TCRPNet.py:89-141）。这是一张“表示维度之间的成对组合图”，不能直接把像素解释为某个 TCR residue 与某个 peptide residue 的物理接触。

代码用 Python 循环逐样本计算外积，效率不如批量 einsum，但证据上非常直接。公共快照只实现 β-only 的 input_channels=2 主模型；论文提到的 α+β 模型会需要四通道，但该路径与相应配置并未出现在当前 TCRPNet 类中。

4. CNN 把成对表示压成 binding logit

两个 $1280\times1280$ 通道进入三层 2D CNN，通道数依次为 32、64、128。每层使用 $5\times5$ convolution、$5\times5$ max pooling、ReLU 和 InstanceNorm（TCRPNet.py:54-76）。空间尺寸按

\[1280\rightarrow255\rightarrow50\rightarrow9\]

逐层缩小，最后 flatten 成 $9\times9\times128$，经 10368→128→1 MLP 得到 logit（TCRPNet.py:78-87,140-146）。硬编码的 9×9 来自 1280 维表示和当前卷积配置；如果更换 encoder 维度或卷积参数，分类器不能自动适配。

模型怎样训练

第一步在 VDJdb 的 MHC-I TCR–epitope 配对上预训练：真实 cognate pair 为正例，每个 epoch 从 peptide pool 动态生成等量 noncognate negatives；Adam 学习率 $10^{-6}$，validation patience 为 10（paper.md:1605-1607）。

第二步对每个 PRP 单独 fine-tune。每个 TCR 的数据按 70/15/15 切分为 train/validation/test。负例远多于正例，因此训练入口按 $N_{neg}/N_{pos}$ 计算 pos_weight，Lightning wrapper 使用

\[\mathcal L=\operatorname{BCEWithLogitsLoss}(s,y;w_+).\]

见 scripts/train.py:32-75 和 source/trainer_esm.py:28-54,119-194。模型输出不先做 sigmoid，因为 BCEWithLogitsLoss 内部以数值稳定方式完成 sigmoid 与交叉熵。

论文称包括 ESM2 在内的所有参数都微调；代码通过 freeze_encoder 控制，论文对应配置应为 false（trainer_esm.py:46-54）。公共仓库能支撑单 TCR 训练、测试集推断和蛋白组推断主路径，但完整原始测序处理、所有论文模型配置和全部 checkpoint 不在工作区。

从预测到自身抗原发现

作者先用 NetMHCpan-4.1 从人参考蛋白组筛 HLA-B*27:05 9-mer：得到 293,467 个候选，再保留 P8 为脯氨酸的 12,357 个肽。每个单 TCR 模型打分，分数 >0.95 视为该模型的高分候选，再选至少被 5 个 TCR 命中的肽，最终测试排名前 15（paper.md:1617-1621）。

这条漏斗很重要：模型没有直接扫描所有任意长度的人类肽，也没有单凭一个 TCR 的分数宣布自身抗原。候选同时受 HLA 结合、P8 先验、跨 TCR 高分和实验验证约束。

Figure 3b 显示单 TCR held-out yeast data 上 AUROC >0.95、AUPRC >0.66；Figure 3d–e 展示蛋白组筛选和 15 个交叉反应候选。随后 Figure 4 形成独立验证链：

  • K-562 呈递肽给表达目标 TCR 的 SKW-3，以 CD69 上调判定激活；
  • 模型预测与多 TCR 激活相关，并优于 AlphaFold3/tFold-TCR 的结构分数；
  • PSG5 在虹膜色素上皮细胞中表达；
  • 6 名 HLA-B27+ AS/AAU 与 6 名健康对照的四聚体实验显示 PSG5-specific CD8 T cell 频率差异，$P=0.0087$；
  • PSG5–HLA-B27:05–TCR 19.2 晶体结构验证其与 YEIH 类似的结合方式。

Figure 4g 的 residue attribution 配色与晶体结构接触方向一致，但公共仓库中未找到生成 gradient attribution 的代码，因此图是论文证据，不是当前代码可复现输出。

新 TCR 上何时能相信模型

论文用 leave-one-TCR-out（LOO）训练检查跨 TCR 泛化。结果不是“CDR3β 越相似，模型越可靠”，而是 held-out TCR 的 PRP 与训练 TCR PRP 越接近，AUPRC 越高；Figure 6e 报告约 $\rho=-0.78$。

问题在于，新 TCR 尚未做 PRP 时无法知道真实 JS 距离。作者因此在 ESM sequence embedding 空间定义 Mahalanobis distance：

\[d_{Mah}(x,\mu)=\sqrt{(x-\mu)^TS^{-1}(x-\mu)},\]

其中 $\mu$ 和 $S^{-1}$ 来自训练 TCR 表示，协方差逆使用 Moore–Penrose pseudoinverse（paper.md:1635-1641）。Figure 6f 显示它与实验 PRP functional distance 正相关（图中 $\rho=0.59$），因此可作为 out-of-distribution 警报，而不是概率校准保证。

公共仓库没有 Mahalanobis、LOO 管理和 Figure 6 相关性分析代码。不能把论文公式误写成已经封装在推断脚本里的“自动置信度”；当前 inference_proteome.py 只返回结合 logits。

使用和解释的边界

  1. PRP 标签测的是特定 yeast-display 构建和筛选条件下的结合富集，不等于细胞激活、致病性或体内免疫优势；论文通过后续 CD69、四聚体和结构实验逐层补证。
  2. 肽库固定 R@P2、P@P8，蛋白组筛选又保留 P8-Pro，因此模型证据覆盖的是受约束的 HLA-B*27:05 空间，而非所有 MHC、长度和 anchor 组合。
  3. β-only 有结构和 α-swap 数据支持，但只在这个 β-dominant TCR 家族中成立；不能推广为所有 TCR 都不需要 α 链。
  4. Figure 4 的 PSG5 结果支持 disease association 和 candidate autoantigen 身份，不单独证明 PSG5 是 AS/AAU 的唯一病因。
  5. Mahalanobis 大表示模型空间中远离训练 TCR，适合作为拒绝或谨慎解释信号；它不把错误率转换成严格置信区间。

最简心智模型

可以把这项工作理解为：PRP 是每个 TCR 的实验“训练教材”，ESM2+Transformer 把 TCR 和肽分别翻译成表示，outer-product+CNN 学习两者的组合规则；蛋白组筛选负责提出候选，激活、患者样本和结构负责验证。模型的可信范围由训练 PRP 的功能邻域决定，而不是由 CDR3 序列相似度单独决定。

PRP-TCR Summary

Motivation & Novelty

Biological Problem

T cell receptors (TCRs) drive adaptive immunity by recognizing peptides presented on MHC molecules. Understanding which peptides a TCR recognizes is central to immunology — from vaccine design to autoimmune disease etiology. In diseases like ankylosing spondylitis (AS) and acute anterior uveitis (AAU), strongly associated with HLA-B*27:05, disease-associated TCRs are thought to aberrantly recognize self-peptides, but the causative autoantigens remain unidentified decades after the HLA-B27 association was discovered.

Why Existing Methods Fall Short

Sequence-based methods (GLIPH [Nature 2017], TCRdist [Nature 2017]) cluster TCRs by CDR3 sequence similarity but cannot resolve fine-grained specificity within dense clonotype families where nearly identical sequences can recognize completely different peptides.

Structure-based methods (AlphaFold3 [Nature 2024], tFold-TCR [bioRxiv 2025]) predict TCR-pMHC complex structures and use the interface pTM (ipTM) score to rank interactions, but these static structural metrics fail to reliably predict functional T cell activation — particularly for novel peptides.

Prior high-throughput display screens (yeast/mammalian display) can map peptide binding landscapes but lacked the computational framework to generalize these datasets to unseen peptides and proteome-scale antigen discovery.

Novel Contributions

  1. PRP technology: First systematic deep profiling of individual TCRs against ~10⁹-peptide libraries, generating quantitative peptide recognition profiles (PRPs) that capture the full binding landscape of each TCR.

  2. TCRPNet architecture: A fine-tuned protein language model (ESM2-650M) coupled to a dual-encoder + outer product + CNN architecture that learns TCR-peptide binding specificity from empirical PRP data.

  3. Functional clustering: Demonstration that PRPs cluster TCRs by recognition pattern rather than sequence, revealing convergent specificity among sequence-dissimilar TCRs.

  4. PSG5 autoantigen discovery: Computational prediction and experimental validation of PSG5 as a novel HLA-B27-restricted autoantigen expressed in iris pigment epithelial cells — providing a mechanistic link to AAU pathology.

  5. Generalization principles: Formal characterization that predictive accuracy depends on functional distance (PRP divergence), not sequence similarity — shifting how model applicability should be assessed.

  6. Mahalanobis uncertainty metric: A model-intrinsic confidence score computed from ESM embeddings that quantitatively estimates prediction reliability for novel TCRs without requiring additional experiments.

Method Overview

Algorithmic Framework

PRP is a two-phase approach:

Phase 1 (Experimental): High-throughput yeast surface display selection of a 9-mer peptide library (~10⁹ variants) against HLA-B*27:05 single-chain trimers, using individual TCRs as selectors across 4 rounds of MACS enrichment. Positive binders defined as count ≥ 5 in round 4; negatives as count = 0 in rounds 2–4. 16 disease-associated TCRs from AS/AAU patients profiled.

Phase 2 (Computational): Fine-tuned protein language models trained on PRP data. The TCRPNet model combines:

  • A single ESM2-650M encoder for both CDR3β and peptide sequences
  • Position-wise and pooled sequence representations concatenated with one-hot encodings (d_model = 1300)
  • Separate 6-layer transformer encoders for CDR3β and peptide
  • Outer product pairwise interaction maps (2 channels: pooled + transformer-encoded)
  • 3-layer 2D CNN (2→32→64→128 channels) + MLP head → binding logit

Training Strategy

Two-stage training: (1) VDJdb pretraining on broad MHC-I TCR-epitope pairs; (2) per-TCR fine-tuning on disease-specific PRP data (70/15/15 split; weighted BCE for class imbalance; Adam lr=1e-6; early stopping patience=10). All ESM2 parameters are fine-tuned.

For antigen discovery: 16 per-TCR models score 12,357 NetMHCpan-filtered human proteome 9-mers with proline at P8, selecting the top 15 cross-reactive candidates (predicted to bind ≥5/16 TCRs).

Biological Assumptions

  • CDR3β is the dominant determinant of peptide specificity for this HLA-B*27:05-restricted TCR family (structurally verified; α-chain swap experiments confirm)
  • Fixed library anchors (R@P2, P@P8) capture the functionally relevant peptide space for HLA-B*27:05
  • yeast display binding enrichment is a proxy for functional pMHC presentation

See doc_method.md for mathematical details and doc_code.md for implementation.

Evaluation

Datasets

  • Training/testing: 16 PRP datasets (each with thousands of positive peptides and matched negatives); 70/15/15 split
  • Activation validation: 15 top-predicted cross-reactive peptides × 16 TCRs in CD69 T cell activation assay (K-562/SKW-3 coculture)
  • Structural validation: Crystal structures of TCR 19.2 complexes with YEIH (PDB 9PBG) and PSG5 (PDB 9PBH)
  • Clinical validation: PSG5-HLA-B27 tetramer staining of PBMCs from n=6 HLA-B27+ AS/AAU vs n=6 healthy controls

Comparative Results

Figure 4d shows PRP models substantially outperform both AlphaFold3 and tFold-TCR on T cell activation prediction. High-affinity MHC binders selected by NetMHCpan (top 20) activate zero TCRs (Supplementary Fig.7), confirming that MHC binding alone is insufficient for TCR activation and validating the added value of PRP-trained models.

Biological Validation

  • PSG5: 13/16 TCR models predicted binding (Fig.3e); 8/10 tested TCRs activated in coculture (Fig.4b); crystal structure confirms conserved docking geometry with YEIH (Fig.4g); spatial transcriptomics shows expression in iris pigment epithelium (Fig.4e); PSG5-specific CD8 T cells significantly elevated in AS/AAU patients (P=0.0087; Fig.4f)
  • PRPF3: Second most cross-reactive predicted autoantigen; activates multiple TCRs including 19.2 neighborhood variants (Fig.5e)

Reproducibility Rating: 3.5/5

Justification

What is available:

  • Full code repository on GitHub (https://github.com/akds/PRP-TCR-Specificity) with clean, well-documented PyTorch Lightning implementation
  • YAML configs for all 22 model variants (16 disease TCRs + 5 19.2 mutants + 1 joint)
  • Pretrained VDJdb checkpoint and fine-tuned model checkpoints available via Google Drive
  • Processed PRP datasets (peptide sequences + enrichment counts) deposited on Dryad (https://doi.org/10.5061/dryad.h70rxwdzk)
  • Crystal structures deposited in PDB (9PBG, 9PBH)
  • T cell activation binary labels in data/activation_binary.csv

Practical limitations:

  • Requires ESM2-650M weights (~2.5GB) downloaded separately
  • Multi-GPU training (2× GPU with bf16) needed for full fine-tuning of ESM2 in reasonable time
  • LOO models and Mahalanobis distance computation not in public code — the key uncertainty metric from Fig.6 cannot be reproduced from available code alone
  • Gradient saliency attribution (Fig.3c) code not provided
  • The full yeast display raw sequencing data and processing pipeline are not in the code repo (only processed PRP datasets on Dryad)
  • α+β model configs not included (only β-only)
  • Environment dependencies are pinned but require a GPU with CUDA 12.1+

Practical Notes

  • Install conda environment from environment.yml (Python 3.9, PyTorch 2.3.1, PyTorch Lightning 2.4.0)
  • Download ESM2-650M and VDJdb checkpoint per README instructions
  • Training runs successfully from scripts/train.py with any of the 22 provided configs
  • Inference on test sets and proteome panel is fully scripted
  • Key unresolvable gap: the Mahalanobis confidence metric (central Fig.6 finding) requires custom code to compute Moore-Penrose pseudoinverse covariance from training ESM embeddings — this is not provided and would need to be reimplemented
