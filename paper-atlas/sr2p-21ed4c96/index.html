SR2P

SR2P: an efficient stacking method to predict protein abundance from gene expression in spatial transcriptomics data

Code

SR2P 方法中文解释

这篇论文要解决什么问题？

SR2P 要解决的是空间转录组中的“缺失蛋白模态”问题：很多空间转录组数据只有 RNA 表达和空间坐标，没有同一位置的蛋白丰度测量。但在免疫微环境、肿瘤分型、治疗反应等问题中，蛋白尤其是细胞表面蛋白往往比 RNA 更直接反映细胞状态。论文强调，RNA 和蛋白之间存在转录后调控、翻译调控、蛋白降解等多层差异，空间微环境也会影响蛋白丰度，因此不能简单地把 RNA 当作蛋白的替代物 (paper.md:12-24)。

因此，SR2P 的任务是：给定空间位置上的基因表达矩阵 X_{n x g}，预测同一批空间位置上的蛋白丰度矩阵 Y_{n x p}。这里 n 是空间 spot 数量，g 是基因数量，p 是蛋白数量。这个输入输出关系在 Figure 1 的流程图中直接画出 (paper.md:36-38; local figure_01.jpg)。

为什么已有方法不够？

论文讨论了几类相关方法的限制：

  • 单细胞 RNA 到蛋白预测方法，例如 sclinear，理论上可以用于空间数据，但缺少空间场景下的系统验证 (paper.md:21)。
  • GNN 方法可以天然建模空间邻接关系，例如 GAT、GraphSAGE、DGAT，但论文结果显示，在这些数据集上，单靠空间消息传递并不总是能超过带空间特征的树模型 (paper.md:44-52, paper.md:58-75)。
  • 传统机器学习方法如 PLS、XGBoost、LightGBM、CatBoost 本身不利用空间结构；如果只输入中心 spot 的 RNA，就会丢失邻域组织结构信息 (paper.md:145-148)。

SR2P 的思路不是押注单一模型，而是用 stacking 把多种模型的互补预测合并起来。

SR2P 的核心思想

SR2P 是一个两层 stacking 集成框架。第一层是 11 个 base learners，第二层是 ExtraTrees meta learner。

训练数据：RNA + 蛋白 + 空间坐标
        |
        v
预处理：RNA 归一化 / 蛋白 CLR / 坐标整理
        |
        v
构造两类输入特征
  1. 原始 RNA 特征
  2. 空间扩展 RNA 特征 = 中心 spot + 4 个邻居 spot
        |
        v
11 个 base learners 产生预测
        |
        v
五折 out-of-fold 预测组成 meta-feature matrix
        |
        v
ExtraTrees meta learner
        |
        v
最终蛋白丰度预测

论文中的 11 个 base learner 配置包括：PLS、XGBoost、LightGBM、CatBoost 四个非空间模型；它们各自的空间增强版本 PLS-Spatial、XGBoost-Spatial、LightGBM-Spatial、CatBoost-Spatial；以及 GAT、GraphSAGE、DGAT 三个 GNN 模型 (paper.md:121-160)。

空间特征是怎么构造的？

对于非 GNN 模型，SR2P 显式把空间邻域信息拼接到输入特征中。论文描述的做法是：对每个 spot，找到西、北、东、南四个固定方向的邻居；如果因为边界或组织形状不规则导致某些邻居不存在，就用空间上最近且尚未选中的邻居补上；最后把中心 spot 的 RNA 向量和四个邻居的 RNA 向量按固定顺序拼接起来 (paper.md:145-154)。

代码中可以直接看到这个机制：

  • make_expand_fn_within_sample_fixed_neighbours 固定要求 self + 4 neighbors，输出维度是原始特征的 5 倍 (SR2P/sr2p/data/spatial_construction.py:11-60)。
  • 它按 sample_id 分组，为每个样本单独建立坐标查找表和 KNN 模型，不跨样本找邻居 (SR2P/sr2p/data/spatial_construction.py:77-95)。
  • 它先用固定坐标偏移找邻居，再用同一样本内的 KNN 补齐缺失邻居 (SR2P/sr2p/data/spatial_construction.py:97-201)。

需要注意：论文写的是 west, north, east, south，代码里是基于 x/y 偏移的顺序 (-x,+x,-y,+y)；如果没有明确坐标约定，不能把两者强行判定为完全一致。因此这里是“机制匹配”，但方向命名仍保留不确定性。

stacking 是怎么做的？

论文没有给出显式数学公式，但流程很清楚：每个 base learner 在训练集上做五折交叉验证，生成 out-of-fold predictions。这样每个训练 spot 的 base prediction 都来自一个没有见过该 spot 的模型。然后把 11 个 base learners 的预测拼接起来，形成 meta-feature matrix，再用 ExtraTrees 作为 meta learner 训练最终预测器 (paper.md:157-160)。

可以写成下面的直观形式：

第 m 个 base learner 对 spot i 的预测：
  B_m(X_i) -> yhat_i,m

spot i 的二层输入特征：
  Z_i = concat(yhat_i,1, yhat_i,2, ..., yhat_i,11)

最终预测：
  ExtraTrees(Z_i) -> yhat_i

代码层面，BaseLearnerRunnerConfig 默认五折、shuffle、随机种子 42 (SR2P/sr2p/stacking/base_learner.py:21-29)；BaseLearnerRunner.run 会分 fold 训练、保存验证集预测、平均测试集 fold 预测，并把不同 base learner 的预测列拼接成 meta feature (SR2P/sr2p/stacking/base_learner.py:130-302)。ExtraTreesMetaModel 则对每个蛋白单独训练一个 ExtraTreesRegressor (SR2P/sr2p/models/meta/extratrees.py:24-138)。

不过，当前仓库的高层 StackingPipeline 和底层 runner/spec API 不完全对齐：pipeline.py 使用 x_kind、meta_prefix、run_oof_and_predict_test，但当前 BaseModelSpec 和 BaseLearnerRunner 暴露的是 feature_kind 和 run (SR2P/sr2p/stacking/pipeline.py:127-154; SR2P/sr2p/stacking/base_learner.py:71-96,130-145)。所以代码可以证明 SR2P 的组件实现，但不能直接证明这个高层 pipeline 在当前快照中开箱即用。

GNN 部分做了什么？

GAT 和 GraphSAGE 代码会在每个样本内部，根据空间坐标建立 KNN 图，然后用 torch-geometric 模型训练 RNA 到蛋白的预测 (SR2P/sr2p/models/base/gnn_utils.py:32-103; SR2P/sr2p/models/base/gat.py:79-242; SR2P/sr2p/models/base/gs.py:63-232)。

DGAT 更进一步，建立两个图：

  • 空间图：基于 spot 坐标的 KNN；
  • 表达图：基于 RNA 表达相似性的 KNN。

模型中有空间图和表达图两套 GAT 层，并通过可学习 gate 融合；损失包含蛋白预测误差和 RNA 重构误差 (SR2P/sr2p/models/base/gnn_utils.py:106-180; SR2P/sr2p/models/base/dgat.py:45-102,161-279)。

论文如何评估？

论文使用六个 paired RNA+protein Visium CytAssist 样本：乳腺癌、胶质母细胞瘤、Tonsil 1、Tonsil 2、HNSCC A1、HNSCC D1 (paper.md:226-238)。另外，论文还用 8 个只有 RNA 的 HNSCC Visium 样本做生物应用 (paper.md:241-244)。

评估分三类：

  • within-sample validation：对单个样本的空间坐标做 k-means，构造 10 个空间连续 fold，每次留出一个空间区域做测试 (paper.md:41-44, paper.md:169-172)。
  • within-tissue validation：同一组织类型内，一个样本训练，另一个样本测试，例如 Tonsil 1/Tonsil 2 或 HNSCC 样本之间互换 (paper.md:175-178)。
  • cross-tissue validation：按组织类型留出测试集，用其他组织类型训练，测试跨组织泛化能力 (paper.md:181-184)。

指标包括 Spearman correlation、Pearson correlation 和 RMSE，其中 Spearman 是主要展示指标；比较空间/非空间非 GNN 模型时使用 Wilcoxon signed-rank test (paper.md:193-223)。

主要结果怎么理解？

Figure 2 显示 within-sample 任务中，SR2P 和空间增强的树模型能够较好保留 CD163、PTPRC、EPCAM、VIM 等 marker 的空间模式；点图和箱线图也显示 SR2P 整体表现强且方差较低 (paper.md:41-52; local figure_02.jpg)。

Figure 3 说明跨样本/跨组织泛化更难。训练和测试在同一组织类型中通常更稳定；跨组织后，多数模型性能下降，说明 RNA-蛋白关系具有明显组织特异性 (paper.md:58-75; local figure_03.jpg)。

Figure 4 是 HNSCC 应用：论文用 HNSCC paired RNA+protein 样本训练 SR2P，再预测 8 个 RNA-only HNSCC 样本中的 31 个蛋白 marker。预测蛋白和 RNA 结合后，可以恢复更多 macrophage-enriched 区域，并观察 responder/non-responder 之间的免疫 marker 差异 (paper.md:81-92, paper.md:253-256; local figure_04.jpg)。

Figure 5 展示测试阶段推理时间。论文报告 SR2P meta learner 推理约 2.19 秒，是图中第三快；但论文也说明，因为 SR2P 是 stacking，总推理时间还应加上 base learners 的预测时间 (paper.md:95-103; local figure_05.jpg)。

代码复现需要注意什么？

代码与论文的匹配程度是 medium。仓库确实包含 SR2P 的核心组件：预处理、空间特征拼接、七类 base model、OOF stacking、ExtraTrees meta learner。但以下关键复现材料没有在当前代码快照中找到：

  • 没有 supplementary markdown；Supplementary Methods 和 Supplementary Figures 无法直接核对。
  • 没有找到 within-sample 空间 10-fold k-means split 的源码。
  • 没有找到 within-tissue / cross-tissue benchmark orchestration 脚本。
  • 没有找到 Spearman/Pearson/RMSE/Wilcoxon 的论文指标计算脚本。
  • 没有找到 HNSCC DECLUST 应用和 responder/non-responder 分析脚本。
  • 11 个 base learners 的“论文级完整 benchmark wiring”没有直接脚本证据；只看到 package exports 和 tutorial 级示例。

因此，如果研究者想复现论文图表，需要在现有 SR2P 组件基础上补齐 split、metrics、统计测试和绘图流程；如果只想理解或使用 SR2P 的核心模型思想，当前代码已经提供了主要 building blocks。

SR2P Summary

Problem

SR2P targets spatial transcriptomics datasets that have RNA expression and spatial coordinates but lack direct protein measurements. The paper argues that RNA-only spatial data miss protein-defined immune states and signaling, especially in tumor microenvironments where RNA-protein discordance is common (paper.md:12-24). The goal is to infer spot-level protein abundance from spatial RNA profiles.

Proposed Method

SR2P is a stacking-based framework for spatial protein prediction. It takes a spot-by-gene spatial RNA matrix X_{n x g} and predicts a spot-by-protein matrix Y_{n x p} (paper.md:36-38). The method combines 11 base learner configurations:

  • PLS, XGBoost, LightGBM, and CatBoost on raw RNA features.
  • PLS-Spatial, XGBoost-Spatial, LightGBM-Spatial, and CatBoost-Spatial on spatially expanded RNA features.
  • GAT, GraphSAGE, and DGAT as graph neural network models (paper.md:121-160).

The spatial tabular models concatenate each spot’s RNA vector with four directional neighbor vectors, using exact coordinate-offset neighbors first and nearest-neighbor fallback for missing boundary neighbors (paper.md:145-154). The stacking layer uses five-fold OOF predictions from all base learners as meta features and trains an ExtraTrees meta learner to produce the final SR2P prediction (paper.md:157-160).

Evaluation

The paper evaluates SR2P on six paired Visium CytAssist spatial RNA+protein samples: breast cancer, glioblastoma, tonsil 1, tonsil 2, and two HNSCC samples (paper.md:226-238). It reports three validation settings: within-sample spatial 10-fold validation, within-tissue validation, and cross-tissue validation (paper.md:163-184). Metrics are Spearman correlation, Pearson correlation, and RMSE, with Spearman as the primary visualized metric (paper.md:193-217).

Main reported results:

  • In within-sample validation, SR2P and spatially enhanced tree/tabular models preserve marker-specific spatial patterns; Figure 2 shows SR2P among the high-performing and low-variance models across six datasets (paper.md:41-52; local figure_02.jpg).
  • Spatial feature augmentation improves non-GNN models in several datasets, while GNNs are not consistently better than spatial tree-based models (paper.md:44-52, paper.md:109-115).
  • In within-tissue and cross-tissue validation, performance is tissue-dependent; cross-tissue transfer degrades in many cases, but SR2P remains competitive, with spatial CatBoost/LightGBM also strong in several tissues (paper.md:58-75; local figure_03.jpg).
  • The HNSCC application predicts 31 protein markers in eight RNA-only Visium samples, supporting macrophage-enriched region recovery and responder/non-responder immune marker comparisons (paper.md:81-92; local figure_04.jpg).
  • Runtime analysis reports SR2P meta-learner inference at 2.19 seconds under the cross-tissue breast cancer test setting, though total SR2P inference also includes base learner prediction time (paper.md:95-103; local figure_05.jpg).

Code And Reproducibility

The paper lists the software at https://github.com/Qingyueee/SR2P (paper.md:259-262). The acquired snapshot is commit 66280229d146653442f11c0d897e7cb176b5f604.

Code-paper fidelity is medium. The repository contains reusable components for the core method: preprocessing helpers, fixed-neighbor spatial feature construction, PLS/XGBoost/LightGBM/CatBoost/GAT/GraphSAGE/DGAT wrappers, OOF stacking helpers, and an ExtraTrees meta learner (doc_code.md:20-47). The code directly supports the method’s conceptual architecture.

Major reproducibility gaps remain:

  • No supplementary markdown was acquired, even though the paper references Supplementary Methods and multiple supplementary figures.
  • No source was found for the paper’s within-sample spatial 10-fold k-means split construction.
  • No source was found for within-tissue/cross-tissue benchmark orchestration, metric/statistical testing, HNSCC DECLUST analysis, or Figure 5 timing.
  • Exact paper benchmark wiring for all 11 base learners is not verified beyond package exports and tutorial examples.
  • The high-level StackingPipeline source appears stale relative to the current BaseModelSpec / BaseLearnerRunner API, so users may need to use lower-level components or adapt the package before end-to-end reproduction (doc_code.md:32-35).

Practical Takeaway

SR2P is best understood as an ensemble strategy for RNA-to-protein spatial prediction: it combines complementary tabular and graph models, explicitly augments spatial context for non-GNN methods, and learns an ExtraTrees meta model from base-learner predictions. The paper’s biological message is that same-tissue or related-tissue training is more reliable than broad cross-tissue transfer, and that inferred proteins can add useful immune-marker structure to RNA-only spatial data. The released code is useful for the model components, but the exact paper benchmark and downstream analysis workflows are incomplete in the acquired repository.
