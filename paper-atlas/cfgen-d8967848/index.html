CFGen

Multi-Modal and Multi-Attribute Generation of Single Cells with CFGen

Open paper Code

CFGen 方法解读：在连续潜空间中运输，再以离散分布生成细胞

任务边界

CFGen 是条件单细胞生成与批次校正模型，不是轨迹/命运推断方法。它生成 RNA counts，或成对 RNA 与 ATAC，并按细胞类型、供体、组织、批次等属性控制；dynamics_fate_trajectory 是历史归档位置，不代表模型输出发育轨迹。

两阶段设计

第一阶段训练自动编码器。各模态编码到潜空间，可选 joint layers 融合。RNA decoder 输出基因比例，与 library size 相乘并用 negative binomial 训练。论文 ATAC 路径针对二值可及性使用 Bernoulli；代码在 is_binarized=False 时还提供 Poisson，是实现扩展。

第二阶段冻结预训练 encoder，在潜空间训练 flow matching。数据潜变量 $z_1$ 与高斯噪声 $z_0$ 由概率路径连接；速度网络接收 $z_t$、时间、library size 和属性嵌入，以 MSE 拟合条件流速度。可选 minibatch OT 先耦合噪声/数据样本。

若没有 encoder_ckpt，CfgenEstimator 会使用新初始化 encoder 并置为 eval，却不显式冻结；这不是论文可用流程，正确运行需要预训练 checkpoint。

多属性组合引导

训练通过随机丢弃条件学习无条件与单属性速度。推断使用

\[\tilde u_t(z\mid y)=u_t(z)+\sum_k\omega_k[u_t(z\mid y_k)-u_t(z)]\]

组合多个属性方向。公式依赖条件独立近似；较大 guidance weight 会增强目标属性信号，但可能降低多样性，不能保证未观察属性组合一定生物可行。

回到离散细胞与批次校正

生成从高斯噪声出发，用 Neural ODE 积分到数据潜空间，再由 decoder 输出参数并采样 NB/Bernoulli（代码可选 Poisson）。所以“保留离散性”指最终观测模型，而非 flow 在离散空间运行。

批次校正把真实潜变量反向积分至噪声，再保留细胞类型、改用统一参考批次正向积分。它是模型依赖的反事实运输；UMAP 混合不单独证明生物信号无损。

CFGen: Multi-Modal and Multi-Attribute Generation of Single Cells

Executive Summary

Reproducibility Rating: 3/5

CFGen (Conditional Flow Generation) introduces latent flow matching with discrete likelihood decoders for generating realistic single-cell RNA-seq and multi-modal (RNA + ATAC) data. The method achieves state-of-the-art performance on data augmentation for cell type classification (up to 15% improvement) and batch correction tasks.

Key Innovation: First method to combine continuous flow matching in latent space with modality-specific discrete decoders (Negative Binomial for RNA, Poisson/Bernoulli for ATAC), preserving the inherent count nature of single-cell data.

Strengths:

  • Complete, well-documented codebase with Hydra configuration
  • Pre-trained checkpoints available on FigShare
  • Preprocessed datasets on Zenodo
  • Multi-modal support (RNA + ATAC)
  • Multi-attribute conditioning with classifier-free guidance

Limitations:

  • Requires SLURM for training scripts (needs adaptation for local use)
  • arXiv HTML and five main figures are now stored locally; appendix numerical results remain paper-reported
  • Pre-trained checkpoints must be downloaded from FigShare separately

Motivation and Novelty

Biological Problem

Single-cell genomics faces critical challenges in data scarcity and batch effects that limit downstream analyses. Existing datasets often lack diversity in cell types or experimental conditions, hindering robust model training for cell type classification. Additionally, batch effects confound biological signals, requiring sophisticated correction methods.

Limitations of Existing Approaches

Method Limitation
scVI Continuous VAE output loses discrete count nature
scGAN Mode collapse on rare cell types
VAE-based Limited multi-modal support
Direct flow matching Cannot handle discrete count data

Unique Contributions

  1. Latent Flow Matching + Discrete Decoders: First approach combining continuous flows in latent space with discrete likelihood decoders
  2. Multi-Attribute Generation: Novel classifier-free guidance for simultaneous control over cell type, batch, and other attributes
  3. Multi-Modal Architecture: Unified framework for RNA-seq and RNA+ATAC generation
  4. Minibatch Optimal Transport: Enhanced flow matching training with OT-based coupling

Method Overview

Two-Stage Generative Framework

Stage 1: Autoencoder Training
Raw Counts (X) --> Encoder --> Latent (z) --> Decoder --> NegBin/Poisson params --> Loss

Stage 2: Flow Matching Training (Fixed Encoder)
Noise (z_0) --> Flow ODE --> Latent (z_1) --> Decoder --> Discrete Sampling --> Synthetic Counts

Core Technical Components

1. Modality-Specific Autoencoders

RNA Decoder: Negative Binomial distribution \(P(X = k) = \frac{\Gamma(k + \theta)}{\Gamma(k + 1)\Gamma(\theta)} \cdot \left(\frac{\theta}{\mu + \theta}\right)^\theta \cdot \left(\frac{\mu}{\mu + \theta}\right)^k\)

ATAC Decoder: Poisson (counts) or Bernoulli (binarized) \(P(X = k) = \frac{e^{-\lambda} \lambda^k}{k!} \quad \text{or} \quad P(X = 1) = p\)

2. Flow Matching with Optimal Transport

Probability Path: \(x_t = t \cdot x_1 + (1-t) \cdot x_0 + \sigma \cdot \epsilon\)

Flow Matching Objective: \(\mathcal{L}_{FM} = \mathbb{E}_{t, x_0, x_1, \epsilon}\left[\|v_\theta(x_t, t, c) - u_t\|^2\right]\)

where $u_t = x_1 - x_0$ (with OT coupling)

3. Classifier-Free Guidance
\[v_{guided} = v_{uncond} + w \cdot (v_{cond} - v_{uncond})\]

Biological Validation Summary

CFGen demonstrates:

  1. Data Augmentation: Up to 15% improvement in cell type classification using CFGen-augmented training data
  2. Batch Correction: Successful removal of batch effects on C. elegans and NeurIPS datasets while preserving biological signals
  3. Multi-Modal Coherence: Generated RNA and ATAC profiles maintain cross-modal regulatory relationships
  4. Marker Gene Preservation: Cell type-specific marker gene expression patterns conserved in synthetic cells
