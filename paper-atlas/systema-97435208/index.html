Systema: a framework for evaluating genetic perturbation response prediction beyond systematic variation

Systema 方法解读：别把“所有扰动都像”误当成“模型懂得每个扰动”

一句话抓住这篇论文

Systema 不是新的扰动响应预测模型，而是一套重新审视预测结果的评估框架。它指出：如果许多被扰动细胞都沿着相似的方向偏离对照细胞，那么模型即使只预测这个共同方向，也可能在常用的 Pearson Delta 指标上得高分。Systema 因此把参考点从对照细胞中心移到扰动细胞中心，并加入“质心准确率”和粗粒度生物学查询，专门检查模型是否真的恢复了不同扰动之间的差异。

这一区分很重要。论文并不是说 CPA、GEARS 或 scGPT 完全没有学到生物学，而是说：仅凭以对照为参考的高相关系数，不能证明模型学到了未见扰动的特异效应。

1. 问题出在哪里：常用分数混合了两类信号

设基因表达空间中，对照细胞的中心为 $\mu_{\mathrm{ctrl}}$，扰动 $X$ 的真实细胞中心为 $\mu(X)$。常规评估比较真实和预测的差异向量：

\[\Delta_X = \mu(X)-\mu_{\mathrm{ctrl}}, \qquad \widehat{\Delta}_X = \widehat{\mu}(X)-\mu_{\mathrm{ctrl}}.\]

随后计算 Pearson 相关、余弦相似度，或者只在差异最大的 20 个基因上计算 Pearson Delta20。直觉上，这似乎是在问“模型是否预测了扰动 $X$ 的响应”。但如果所有扰动都包含一个很强的共享位移 $s$，那么可以近似写成：

\[\Delta_X = s + u_X,\]

其中 $s$ 是许多扰动共有的系统性变化，$u_X$ 才是扰动 $X$ 相对于其他扰动的特异部分。当 $\lVert s\rVert$ 远大于 $\lVert u_X\rVert$ 时，一个对所有测试扰动都输出相同 $s$ 的模型，也会与真实 $\Delta_X$ 高度相关。

论文用十个单细胞遗传扰动数据集说明这种现象并非纯粹的数学假设。扰动与对照之间可能存在细胞周期、应激、细胞死亡或染色体不稳定性等广泛差异。Fig. 2 展示 Norman 和 Replogle 数据中对照/扰动细胞的整体分离、通路分数和细胞周期变化；Fig. 3 则把这种共享方向量化，并显示标准 Pearson Delta 表现会随数据集的系统性变化程度上升。

因此，分数高可能有两种完全不同的解释：模型正确预测了 $u_X$；或者模型主要抓住了共同的 $s$。Systema 的目标就是把二者拆开。

2. 两个简单基线为何是论文的关键诊断工具

2.1 Perturbed mean：所有测试扰动都预测同一个中心

“扰动均值”基线把训练集中所有非对照细胞取平均：

\[\mu_{\mathrm{pert}} = \frac{1}{N_{\mathrm{pert}}} \sum_{i:\,c_i\neq\mathrm{ctrl}} x_i,\]

然后对每个测试扰动都输出 $\mu_{\mathrm{pert}}$。代码 systema/src/run_nonctl-mean.py 的执行方式非常直接：先按 split 划分训练与测试数据，取训练集 control == 0 的表达均值，再把同一个 pert_mean 写入每个测试条件的预测行。

这个基线没有使用测试扰动的基因身份。若它仍能在标准指标上接近复杂模型，说明指标很可能主要奖励“像一个一般的被扰动细胞”，而不是“像这个特定扰动”。Fig. 1 的核心作用正是展示这一反常结果：perturbed mean 在多个数据集上能与 CPA、GEARS、scGPT 相近，甚至更好。

2.2 Matching mean：组合扰动可由已见单基因中心拼出来多少

对双基因组合 $X+Y$，matching mean 分别寻找训练集中 $X$ 和 $Y$ 的单基因扰动中心：

\[\mu_{\mathrm{matching}}(X,Y) =\frac{\mu(X)+\mu(Y)}{2}.\]

若某个单基因扰动未在训练中出现，代码就用所有训练扰动细胞的均值 $\mu_{\mathrm{pert}}$ 代替。systema/src/run_matching-mean.py 逐个拆分 condition.split('+')，检查 g+ctrl 或 ctrl+g，最后对找到的两个向量求平均。因此：

  • 两个成分都未见时，matching mean 退化为 perturbed mean；
  • 只见一个成分时，预测是已见单基因中心与全局扰动均值的平均；
  • 两个成分都见过时，预测是两个单基因中心的平均。

Fig. 1d 按 0-seen、1-seen、2-seen 分组展示 Norman 双扰动结果。matching mean 的竞争力说明，组合任务中的高分有相当部分可以由“记住单基因平均效应并线性拼接”解释。它不等于真正学会了非线性遗传互作。

3. Systema 如何量化系统性变化

论文首先计算所有扰动特异质心的平均：

\[\bar{\mu}_{\mathrm{pert}} = \frac{1}{|\mathcal P|} \sum_{X\in\mathcal P}\mu(X).\]

这里要注意，它是“每个扰动质心等权平均”，不是把所有非对照细胞直接混在一起求均值。这样不会让细胞数更多的扰动获得更大权重。平均扰动位移为：

\[\bar{\Delta}=\bar{\mu}_{\mathrm{pert}}-\mu_{\mathrm{ctrl}}.\]

对每个扰动 $X$，Systema 计算其对照参考位移 $\Delta_X$ 与平均位移 $\bar{\Delta}$ 的余弦相似度：

\[\mathrm{SV}(X)= \cos\left(\mu(X)-\mu_{\mathrm{ctrl}}, \bar{\mu}_{\mathrm{pert}}-\mu_{\mathrm{ctrl}}\right).\]

若许多 $\mathrm{SV}(X)$ 都很高，说明各扰动从对照出发时大致朝向同一方向。systema/evaluation/eval_utils.py 中，average_of_perturbation_centroids() 逐条件求中心再平均；compute_shift_similarities() 计算 avg_shift，并分别收集 control reference 与 perturbed reference 下的余弦、两两余弦和向量范数。

这一量不是“批次效应检测器”，也不能告诉我们共享方向的唯一因果来源。系统性变化可以是技术混杂，也可以是真实但非特异的生物反应。论文的论点更克制：无论来源是什么，只要它对多数扰动共享，就可能主导常规评估分数。

4. 核心修正：把参考点移到扰动质心

Systema 使用 $\bar{\mu}_{\mathrm{pert}}$ 作为替代参考，定义：

\[\Delta_X^{\mathrm{Systema}} =\mu(X)-\bar{\mu}_{\mathrm{pert}},\] \[\widehat{\Delta}_X^{\mathrm{Systema}} =\widehat{\mu}(X)-\bar{\mu}_{\mathrm{pert}}.\]

然后再对二者计算 Pearson 或余弦类分数。几何上，原来所有箭头都从对照中心指向各扰动中心；新参考点位于扰动群体中央，箭头改为描述每个扰动相对于“典型扰动”的偏离。共同位移 $s$ 被大幅抵消，剩下的更接近 $u_X$。

Fig. 4 从左到右给出完整证据链：

  1. 示意图显示参考点从对照中心移动到扰动中心；
  2. 以扰动中心为参考后，各扰动位移与平均方向的余弦分布更接近零；
  3. 单基因测试上的 Pearson 类分数显著下降，许多接近零或为负；
  4. 双基因任务中，0-seen 组合尤其困难；
  5. 新分数与数据集系统性变化的相关性明显减弱，论文报告跨方法平均相关约为 0.21。

分数下降不是新指标“变差”，而是评价问题变严格了：它不再允许模型主要靠共同的 perturbed-versus-control 位移得分。论文据此得出的主要结论是，泛化到未见遗传扰动的特异响应，远比传统分数暗示的困难。

5. Centroid accuracy：预测是否认出了正确扰动

改变参考点仍然属于基于差异向量的评价。Systema 进一步提出 centroid accuracy，直接询问：预测中心更接近正确扰动的真实中心，还是更接近其他扰动的中心？

设测试扰动集合为 $\mathcal P$，距离函数为欧氏距离。扰动 $X$ 的质心准确率为：

\[\mathrm{CA}(X)=\frac{1}{|\mathcal P|-1} \sum_{Y\in\mathcal P,\,Y\neq X} \mathbf 1\left[ d\bigl(\widehat{\mu}(X),\mu(X)\bigr) <d\bigl(\widehat{\mu}(X),\mu(Y)\bigr) \right].\]

若分数为 1，预测中心比任何其他扰动中心都更接近正确目标；若接近随机水平，则预测没有可靠重建扰动景观。systema/evaluation/centroid_accuracy.py 用 cdist(..., metric='euclidean') 建立预测到所有真实中心的距离矩阵，再统计其他中心距离大于正确中心距离的比例，和公式完全对应。

Fig. 5b 的关键不是只看绝对 CA，而是把模型的逐扰动 CA 与 perturbed mean 的 CA 对照。落在对角线附近的点说明复杂模型并未超越“所有扰动都预测平均扰动中心”的基线；明显高于对角线才是额外的扰动特异信息。跨十个数据集，平均表现通常只略高于简单基线，但 fine-tuned scGPT 在部分数据集和特定功能基因群上表现更好，尤其涉及翻译、核糖体、基因表达和 DNA 复制的扰动。

6. 从精确身份到粗粒度生物学查询

预测不一定能精确复原每个基因扰动，却可能足以回答更粗的下游问题。Systema 因此把真实扰动按已知表型分组，构建类别原型中心，再用预测中心到这些原型的距离产生分类分数和 ROC 曲线。

代码 systema/evaluation/centroid_reference_scores.py 的流程是：根据真实 post-perturbation profiles 计算类别 prototype；对每个预测取到 prototype 的负距离作为相似分数；再用类别分数差绘制 ROC。论文以染色体不稳定性等表型为例，fine-tuned scGPT 在 CIN driver 查询上达到 AUC 0.73，而其他方法多在接近随机到中等水平。

这里的解释边界也很清楚：粗类别可预测，不代表完整转录响应已经准确；但它说明评估可以围绕实际生物问题设计，而不必把全基因表达重建当作唯一终点。

7. 从代码看完整数据流

仓库是脚本与 notebook 组合，而不是一条完全封装的命令行流水线：

  1. systema/src/data.py 加载处理后的数据，并沿用 GEARS 的 simulation split 形成训练/测试扰动；
  2. run_cpa.py、run_gears.py、run_scgpt.py 以及两个均值基线，对每个测试条件导出真实 post-gt.csv 与预测 post-pred.csv；
  3. evaluation/benchmark_all.ipynb 汇总十个数据集、三个随机种子和多种方法，计算 control-reference 与 perturbed-reference 指标；
  4. eval_utils.py 提供扰动质心、位移、余弦和范数计算；
  5. centroid_accuracy.py 和 centroid_reference_scores.py 分别完成扰动身份与粗类别查询。

论文中的主评估逻辑与代码总体匹配，但需要注意三个复现边界。第一，完整汇总主要存在于 notebook，不是单个可重复执行的 CLI。第二，run_all.sh 默认只覆盖 Norman2019，且 scGPT 路径被注释，不能把它当作十数据集全复现实验。第三，独立文件 pearson_delta_reference_metrics.py 使用了未进入函数签名的 top20_de_idxs，与 README 示例不同；主 benchmark notebook 才是当前更可靠的实现依据。

仓库还包含 run_gears_residuals.py：它在训练前减去训练扰动中心，在预测后再加回，用残差化方式减少共享方向的影响。这是有启发性的代码实验，但并非论文主方法列表中的核心 Systema 评估组件，不能与“改变评估参考点”混为一谈。

8. 怎样正确阅读论文的结论

结论一：简单基线不是为了取代所有模型

perturbed mean 和 matching mean 是负对照。它们的价值在于暴露指标究竟奖励了什么。复杂模型若只与这些基线持平，说明需要更针对性的证据才能宣称模型理解了扰动机制。

结论二：换参考点也不是万能指标

论文明确讨论了 reference-sensitive metrics 的限制。弱扰动的位移范数很小，方向容易受少量细胞影响；余弦和 Pearson 对幅度不敏感；参考点选择本身会改变分数，某些重合情形甚至使相关系数无定义。因而 perturbed reference 应与 MSE、质心准确率、任务级评价和不确定性一起使用，而不是成为新的单一排行榜。

结论三：系统性变化不等于“错误数据”

共享变化可能是真实的细胞状态反应。Systema 关心的是它是否掩盖了“扰动之间的差异”。研究者应分别报告一般扰动响应和扰动特异响应，避免用一个分数同时承载两种解释。

结论四：最有意义的终点可能是下游任务

论文最后主张按生物学用途评价预测：预测是否帮助识别功能相近基因、染色体不稳定性、细胞状态或其他可验证表型。表达向量是中间表示，不一定是最终目标。

9. 一个小型数值直觉

假设只看二维表达，控制中心为 $(0,0)$，三个真实扰动中心分别为 $(10,1)$、$(10,-1)$、$(10,2)$。三者共享很强的 $(10,0)$ 位移，而特异差别只在第二维。若模型对三者都预测 $(10,0)$：

  • 以控制为参考时，预测向量与三个真实向量几乎平行，相关或余弦分数会很高；
  • 扰动质心约为 $(10,2/3)$，重新参考后，三个真实向量主要沿第二维分开，而相同预测无法同时命中三个方向；
  • centroid accuracy 还会发现，相同预测没有可靠辨认正确扰动中心。

这正是 Systema 试图修正的排行榜错觉：模型掌握了“被扰动”这一共同属性，不等于掌握了“被哪个基因扰动”。

10. 实践中的评估清单

在新的扰动预测项目中，可以按以下顺序使用 Systema 的思想：

  1. 必须报告 perturbed mean；组合扰动还应报告 matching mean；
  2. 画出各扰动相对 control 的位移与平均位移的余弦分布；
  3. 同时报告 control reference 和 perturbed-centroid reference 指标；
  4. 将相关/余弦类指标与 MSE 等幅度敏感指标并列；
  5. 用 centroid accuracy 检查逐扰动身份恢复，并与 perturbed mean 逐点比较；
  6. 设计至少一个有生物意义的粗粒度查询；
  7. 按扰动强度、0/1/2-seen 组件和数据集系统性变化分层，而不是只报总平均；
  8. 对 notebook、外部检查点、数据预处理和随机划分保留明确的复现边界。

Systema

Paper

Systema: a framework for evaluating genetic perturbation response prediction beyond systematic variation

  • Journal: Nature Biotechnology
  • Year: 2025
  • DOI: 10.1038/s41587-025-02777-8
  • Code: https://github.com/mlbio-epfl/systema

Motivation

Perturbation-response models are meant to predict how single cells will respond transcriptionally to genetic perturbations not observed during training. This is biologically important because exhaustive perturbation screening is impossible, especially for combinations of genes.

The paper argues that common benchmarks overestimate progress. Many perturbation datasets contain systematic variation: broad, shared differences between perturbed and control cells caused by perturbation-panel design, confounders, or real but nonspecific biology such as cell-cycle arrest and stress response. A model can score well by predicting this shared perturbed-cell direction without recovering perturbation-specific biology.

Contribution

Systema is an evaluation framework, not a new perturbation-response predictor. It contributes three linked ideas:

  1. A quantification of systematic variation as the cosine alignment between perturbation-specific shifts and the average perturbation effect.
  2. A re-referenced evaluation strategy that uses the perturbed centroid instead of the control centroid, reducing the reward for shared perturbed-vs-control effects.
  3. Centroid accuracy and coarse phenotype ROC analyses, which ask whether predicted profiles recover perturbation identity or downstream biological classes.

Method Overview

The framework starts from processed single-cell perturbation datasets with expression matrices, perturbation labels, and controls. It evaluates CPA, GEARS, scGPT, fine-tuned scGPT, perturbed mean, and matching mean across held-out perturbations.

The perturbed mean baseline predicts the average of all perturbed training cells for every test perturbation. Matching mean predicts combinatorial perturbations by averaging matching single-gene centroids when observed and falling back to the perturbed mean otherwise.

Systema then compares true and predicted perturbation centroids under several references. Standard metrics use the control centroid. Systema’s main re-reference uses the average of perturbation-specific centroids, so the metric emphasizes variation among perturbations rather than the broad shift away from controls. Finally, centroid accuracy checks whether a predicted centroid is closer to the correct perturbation centroid than to other perturbation centroids.

Evaluation

Datasets: Adamson 2016, Norman 2019, Replogle K562, Replogle RPE1, Tian CRISPRa, Tian CRISPRi, Xu 2024, and Frangieh control/co-culture/interferon conditions.

Compared methods: CPA (Molecular Systems Biology, 2023), GEARS (Nature Biotechnology, 2024), scGPT (Nature Methods, 2024), fine-tuned scGPT, perturbed mean, and matching mean. Prior context also includes scGen (Nature Methods, 2019), chemCPA (NeurIPS, 2022), and recent perturbation-benchmark studies.

Metrics: Pearson Delta, Pearson Delta20, RMSE, RMSE20, Jaccard similarity, systematic-variation cosine similarity, perturbed-reference Pearson metrics, centroid accuracy, and ROC AUC for coarse biological classes.

Key results:

  • Under standard Pearson Delta/Pearson Delta20 metrics, perturbed mean often matches or outperforms deep models on unseen one-gene perturbations.
  • Matching mean is strong on Norman two-gene perturbations, especially when component single-gene perturbations appear in training.
  • Dataset-level systematic variation correlates strongly with standard Pearson-style performance, including reported correlations of 0.91 for fine-tuned scGPT and 0.95 for GEARS under Pearson Delta.
  • Re-referencing to the perturbed centroid lowers scores substantially, showing that unseen perturbation-specific prediction is much harder than standard metrics imply.
  • Fine-tuned scGPT retains useful signal for some coherent biological groups, including translation/ribosomal perturbations and a CIN classification task with ROC AUC 0.73.

Code Reproducibility

The public repository contains method runners, dataset loaders, evaluation utilities, notebooks, and plotting helpers. The core Systema metrics are implemented clearly: perturbed centroid reference, systematic-variation cosine similarity, centroid accuracy, and class-centroid ROC scoring.

Important caveats:

  • Full paper reproduction is notebook-centered and depends on external data and model/checkpoint setup.
  • run_all.sh is only a Norman2019 demo in the cloned commit and comments out scGPT, despite the README saying it executes all baselines for every dataset.
  • The standalone Pearson Delta utility has a stale signature bug; the benchmark notebook contains the reliable metric implementation.
  • Some biological analyses for Fig. 2 and supplements are notebook workflows rather than packaged scripts.

Reproducibility rating: 3/5. The repository is useful and implements the main framework, but end-to-end reproduction of all paper results requires external data, notebooks, environment management, and manual coordination.

Main Limitations

  • Systema improves evaluation, but it does not solve perturbation-response prediction.
  • Reference-sensitive metrics remain unstable for weak perturbations and ignore perturbation strength when based on vector orientation.
  • The perturbed centroid reference can still be influenced by the perturbation panel composition.
  • The public code does not provide a single fully automated reproduction workflow for every figure and dataset.

Bottom Line

Systema shows that high perturbation-response benchmark scores can reflect systematic dataset structure rather than perturbation-specific prediction. Its most useful contribution is a stricter evaluation lens: ask whether predicted profiles separate perturbations from one another and support biological downstream queries, not only whether they match control-referenced shifts.
