HFGPI：按“基因—蛋白—组织形态”层级融合的癌症生存预测

核心判断

HFGPI 是一个论文提出、但当前没有公开代码快照的三模态生存模型。每位患者需要匹配的 bulk RNA-seq、RPPA 蛋白表达、病理 WSI 与生存/删失标签。模型不把三种模态一次性拼接，而是先让蛋白从基因表示中读取信息，再让蛋白引导病理 patch 构成超图，最后预测离散时间 hazard。

“基因→蛋白→形态”是有用的架构先验，但不等于模型恢复了真实生物因果链。GRPF 的 attention 和 PGHL 的相似 patch 是学习到的关联；它们可用于生成假设，不能单独证明某基因调控某蛋白或某蛋白造成某种组织形态。

输入和输出

对患者 $k$，输入可写成

\[I^{(k)}=(Y^{(k)},X_g^{(k)},X_p^{(k)},c^{(k)},t^{(k)}),\]

其中 $Y$ 是 WSI patch 特征，$X_g$ 与 $X_p$ 是基因和蛋白 token，$c$ 是删失/事件指示，$t$ 是离散生存时间。输出是各时间区间的 hazard $h(t\mid I)$；生存概率为

\[S(t)=\prod_{u=1}^{t}(1-h(u\mid I)).\]

因此模型预测的是风险分布，不是治疗效果或疾病机制。

第一步：Molecular Tokenizer

基因 token

论文选取跨队列方差最高的 2,000 个基因。Gene2Vec 为每个基因提供 200 维、患者无关的 identity embedding $g_i$；患者 $k$ 的表达标量 $e_i^{(k)}$ 对它逐元素缩放：

\[X_g^{(k)}=e^{(k)}\odot G.\]

直观上，$g_i$ 回答“这个基因在预训练共表达空间里是谁”，$e_i$ 回答“它在当前患者中有多活跃”。表达先做 $\log_2(x+1)$，再跨样本 z-score。

蛋白 token

RPPA 提供约 200 个癌症相关蛋白/磷蛋白的丰度，并非全蛋白组。论文用 LLM 根据蛋白名生成“功能、亚细胞定位、H&E 形态关联”的文本描述，再用 CONCH text encoder 得到 512 维 identity embedding $p_i$，最后用患者蛋白丰度 $q_i^{(k)}$ 缩放：

\[X_p^{(k)}=q^{(k)}\odot P.\]

这里 CONCH 很关键：后续病理 patch 也由 CONCH image encoder 表示，因此文本蛋白描述和图像位于同一对比学习空间。可是，LLM 生成的“形态关联”可能含先验偏差或事实错误；论文没有发布逐蛋白描述文件与生成调用记录，无法逐项审计。

病理 token

WSI 在 $20\times$、约 $0.5\,\mu m$/pixel 下做组织分割，切成不重叠的 $512\times512$ patch。每张片通常得到 1,000–10,000 个 patch，再由 CONCH image encoder 变成 512 维 $Y$。

第二步：GRPF，让蛋白从基因中读取信息

分子图

论文根据静态 identity embedding 的 cosine similarity 分别建立 gene kNN 图和 protein kNN 图，默认 $k_g=100$、$k_p=20$。GCN 在图上更新 token：

\[X_g\leftarrow\operatorname{GCN}(X_g,A_g),\qquad X_p\leftarrow\operatorname{GCN}(X_p,A_p).\]

图拓扑是患者无关的；患者差异来自表达对 identity embedding 的缩放。

有方向的 cross-attention

蛋白作为 query，基因作为 key/value：

\[Q=X_pW_Q,\quad K=X_gW_K,\quad V=X_gW_V,\] \[T=\operatorname{softmax}\left(\frac{QK^T}{\sqrt d}\right) \in\mathbb R^{N_p\times N_g}.\]

$T_{ij}$ 表示第 $i$ 个蛋白 token 从第 $j$ 个基因 token 读取多少信息。随后残差融合：

\[X_p^{\mathrm{regulated}}=X_p+TV.\]

方向性来自设计选择“protein queries genes”，并非从纵向干预数据学习。bulk RNA 与 RPPA 还混合了多种细胞类型，因此 attention 可能反映细胞组成或共同预后信号，而非直接调控。

结构保持损失

作者希望 attention 映射后的蛋白结构与基因结构相容：

\[L_{\mathrm{struct}}=\frac{1}{N_gN_p} \left\|C_g-T^TC_pT\right\|_F^2,\]

其中 $C_g=1-A_g$、$C_p=1-A_p$。这是 Gromov–Wasserstein 风格的结构约束，不是已知基因—蛋白反应网络监督。它鼓励拓扑一致，但不能识别转录后调控、磷酸化或真正的直接靶点。

第三步：PGHL，让蛋白连接形态 patch

论文计算 CONCH patch 与 gene-regulated protein 的 cosine similarity：

\[S=\operatorname{sim}(Y,X_p^{\mathrm{regulated}}) \in\mathbb R^{M\times N_p}.\]

每个蛋白选择 top-32 个 patch，形成一条超边；一个 patch 可以进入多个蛋白超边，所以自然表示多对多关系：

\[H_{ji}=1\quad\text{若 patch }j\text{ 属于 protein }i\text{ 的 top-k}.\]

超图卷积为

\[Z=\sigma(D_v^{-1/2}HW_eD_e^{-1}H^TD_v^{-1/2}YW_p).\]

从左到右看：patch 先汇集到蛋白超边，经过超边权重，再从共享蛋白超边传播回 patch。随后按超边聚合得到蛋白驱动的形态表示：

\[E=H^TZ/\deg(\mathcal E),\qquad F=E+X_p^{\mathrm{regulated}}.\]

$F$ 的每个 token 因而同时含基因读取后的蛋白信息与相关 patch 的形态信息。

一个小例子：若某蛋白与 5 个 patch 的相似度为 $(0.8,0.1,0.7,0.3,0.6)$，假设 top-k=2，则超边只连接 patch 1 和 3。它不表示蛋白只存在于这两个区域，而是模型用当前 embedding 选它们作为最相关形态证据。

第四步：从融合 token 到生存风险

$F$ 先进入 Transformer encoder，让不同蛋白级融合 token 交换信息；gated attention pooling 再聚合为患者表示 $h$，MLP 输出离散 hazard。总目标为

\[L=L_{\mathrm{surv}}+0.3L_{\mathrm{struct}}.\]

$L_{\mathrm{surv}}$ 是处理右删失的离散时间负对数似然。训练报告使用 AdamW、学习率 $10^{-4}$、weight decay $10^{-5}$、20 epochs、batch size 1，并以 16 步梯度累积形成有效 batch。评估为 5-fold cross-validation 的 C-index。

结果该怎样解释

  • 五个 TCGA 队列要求同一患者同时有 RNA-seq、RPPA 和 WSI：BLCA 340、BRCA 833、GBMLGG 878、LUAD 368、UCEC 122。完整 HFGPI 平均 C-index 为 0.753；去除任一模态降到 0.708–0.713。
  • 把 GRPF 换成普通 cross-attention，平均 C-index 降至 0.730；把 PGHL 换成 cross-attention 降至 0.735；去掉结构损失为 0.737。这支持组件的预测增益，但没有证明其生物解释唯一正确。
  • Fig. 2 的 PCNA 面板显示 top genes 为 RFC4、FEN1、LIG1、CCNA2、RFC5、CDC7、CHEK2、BIRC5，所选 patch 多为高细胞密度区域。名单是跨 BRCA 样本平均 attention 的排序，不是基因调控实验。
  • 补充 CD31 图实际列出 ANGPT1、ANGPT2、BDNF、CD83、EDN1、FLI1、HCK、PDGFA。部分与血管/内皮生物学一致，但不能把整张名单改写成“均为直接血管调控基因”。
  • Kaplan–Meier 图显示模型划分的高低风险组在五队列中分离；这是同一评估数据上的风险分层证据，仍需外部队列验证临床泛化。

一句话记忆

HFGPI 用蛋白 token 作为中间枢纽：先从基因 token 读取信息，再以蛋白语义选择并连接病理 patch，最后预测生存；这种层级设计有预测与可视化优势，但没有公开代码时，所有“调控”和“形态机制”都必须保留为模型关联而非因果结论。

HFGPI Summary

Motivation & Novelty

Biological Problem

Cancer prognosis requires integrating heterogeneous data types that capture different aspects of tumor biology. Whole slide images (WSIs) capture tissue morphology and microenvironment but lack molecular resolution. Gene expression profiles reveal molecular dysregulation but cannot account for post-translational modifications. The proteome is the missing bridge: proteins are the direct executors of cellular function and the primary determinants of histopathological phenotypes.

The HER2/ERBB2 example illustrates this: clinical oncology decisions for breast cancer depend on HER2 protein status (via IHC staining), not ERBB2 mRNA levels — because the protein (not the transcript) drives the membranous staining patterns visible in histopathology. This exemplifies why genomics alone cannot fully explain morphological observations.

A second critical limitation of prior work is flat fusion: existing methods (MCAT [ICCV 2021], MOTCat [ICCV 2023], SurvPath [CVPR 2024], CMTA [ICCV 2023], MMP [arXiv 2024], PIBD [arXiv 2024], MoME [MICCAI 2024]) integrate modalities at the same hierarchical level, ignoring that biological information flows through a cascade: genes → proteins → tissue morphology. Even three-modality methods PS3 [arXiv 2025] and ICFNet [arXiv 2025] treat all modalities equally.

A third limitation: gene and protein expression profiles are treated as scalar vectors without encoding intrinsic molecular identity, functional annotations, or co-expression relationships.

What HFGPI Contributes

  1. Proteomics integration: First multimodal survival framework to explicitly use proteomics (RPPA) as the biological intermediate between genomics and histopathology.

  2. Hierarchical fusion respecting biological hierarchy: Explicitly models the gene→protein→phenotype cascade rather than flat fusion. Proteomics is positioned as the causal bridge.

  3. Molecular Tokenizer: A novel encoding strategy that integrates molecular identity (Gene2Vec for genes, LLM+CONCH semantic descriptions for proteins) with patient-specific expression levels. This creates biologically rich representations that capture what each molecule is and how much it is expressed.

  4. Gene-Regulated Protein Fusion (GRPF): Graph-aware cross-attention that models the directional gene→protein regulatory flow with structure-preserving alignment (Gromov-Wasserstein inspired constraint) to enforce topological coherence.

  5. Protein-Guided Hypergraph Learning (PGHL): Models many-to-many protein-morphology relationships through hypergraph convolution, where each protein defines a hyperedge connecting semantically relevant WSI patches.

Method Overview

HFGPI is a hierarchical fusion framework that processes three data modalities through sequential stages:

Feature Extraction (Molecular Tokenizer):

  • Genomic: Gene2Vec 200-dim embeddings (identity) × log-normalized z-scored expression → $\mathbf{X}_g \in \mathbb{R}^{N_g \times d_g}$ ($N_g=2000$ HVGs)
  • Proteomic: CONCH text encoder on LLM-generated protein descriptions × RPPA expression → $\mathbf{X}_p \in \mathbb{R}^{N_p \times d}$ (512-dim)
  • Histopathological: CONCH image encoder on 512×512 patches at 20× → $\mathbf{Y} \in \mathbb{R}^{M \times d}$

GRPF (Gene→Protein hierarchy):

  • $k$-NN graphs from identity embeddings ($k_g=100$ genes, $k_p=20$ proteins)
  • GCN refinement propagates functional network context
  • Cross-attention where proteins query regulatory information from genes → attention matrix $\mathbf{T} \in \mathbb{R}^{N_p \times N_g}$
  • Structure-preserving alignment loss ($\lambda=0.3$) enforces topological coherence
  • Gene-regulated protein representations: $\mathbf{X}_p^{\text{regulated}} = \mathbf{X}_p + \mathbf{T}\mathbf{V}$

PGHL (Protein→Image hierarchy):

  • Cosine similarity between patch embeddings and regulated protein embeddings
  • Hypergraph construction: each protein defines a hyperedge over top-$k=32$ patches
  • Hypergraph convolution enables patches to aggregate from other protein-associated patches
  • Fusion: $\mathbf{F} = \mathbf{H}^T\mathbf{Z}/\text{deg}(\mathcal{E}) + \mathbf{X}_p^{\text{regulated}}$

Survival Prediction: Transformer encoder + gated attention pooling → patient embedding → MLP hazard prediction.

Training: AdamW, lr=1e-4, 20 epochs, batch 1 with 16-step gradient accumulation. Loss combines NLL survival loss + structure-preserving alignment loss.

For mathematical details, see doc_method.md.

Evaluation

Datasets

Five TCGA cancer cohorts requiring matched genomics (RNA-seq) + proteomics (RPPA) + WSIs:

  • BLCA: n=340 (Bladder Urothelial Carcinoma)
  • BRCA: n=833 (Breast Invasive Carcinoma)
  • GBMLGG: n=878 (Glioblastoma + Lower Grade Glioma)
  • LUAD: n=368 (Lung Adenocarcinoma)
  • UCEC: n=122 (Uterine Corpus Endometrial Carcinoma)

Evaluation: 5-fold cross-validation, C-index (concordance index) with mean ± std.

  • Three-modality methods consistently outperform two-modality (+1.1% to +5.4%) — validates proteomics integration

Survival Stratification (Figure 3 / Supplementary)

Kaplan-Meier analysis across all five cohorts shows statistically significant risk stratification (log-rank test), with HFGPI achieving the lowest p-values compared to baselines. The GBMLGG and UCEC cohorts show the most dramatic risk group separation.

Biological Interpretability

Three case studies validate that attention mechanisms learn biologically meaningful relationships:

  • PCNA in BRCA: Top regulatory genes (RFC4, FEN1, LIG1, CCNA2) are all mechanistically involved in DNA replication where PCNA functions
  • EGFR in BLCA: Top genes (ARAF, NRAS, FGF7, STAT5A) are canonical EGFR signaling pathway components
  • CD31 in GBMLGG: Top genes (ANGPT1, ANGPT2, FLT1, PDGFB) are all angiogenesis/vascular remodeling regulators — consistent with CD31’s endothelial function

Reproducibility

Rating: 2/5

Justification:

The paper presents a methodologically clear framework with well-specified hyperparameters, ablation studies, and parameter sensitivity analyses. However, reproducibility is severely limited by:

  1. No public code: No GitHub repository or code release accompanies this arXiv preprint.

  2. GPT-5 as LLM: The paper specifies “GPT-5” for generating protein descriptions. As of 2025, GPT-5 had not been publicly released, making exact reproduction of the protein identity embeddings impossible. However, Table 3(b) shows that alternative LLMs (DeepSeek, Qwen-3, Claude-3.7) achieve only 0.6–1.0% lower C-index, suggesting LLM choice is not critical.

  3. Data accessibility: All five TCGA datasets are publicly available through UCSC Xena (genomics/proteomics) and NCI GDC (WSIs) — good.

  4. Clear hyperparameters: N_g=2000, k_g=100, k_p=20, k=32, λ=0.3, lr=1e-4, 20 epochs, batch=1 with 16-step accumulation, NVIDIA RTX 3090 — well-specified.

  5. CONCH accessibility: CONCH is a published, publicly available foundation model [Lu et al., Nature Medicine 2024] and Gene2Vec is a published tool [Du et al., BMC Genomics 2019] — backbones are reproducible.

  6. Transformer/attention architecture details missing: The paper does not specify the number of Transformer layers, heads, hidden dimensions, or the exact gated attention pooling implementation. This requires reverse-engineering from references [9, 34].

Practical notes for reimplementation:

  • Use an alternative LLM (e.g., GPT-4, Claude) for protein descriptions — expected ~1% C-index degradation
  • RPPA data from UCSC Xena requires careful cohort matching with RNA-seq and WSI data
  • Patch extraction at 20× magnification using standard tissue segmentation (e.g., CLAM toolbox)
  • Gated attention pooling implementation is available in the ABMIL/CLAM codebases [Chen et al. ICCV 2021; Lu et al. Nature Biomed Eng 2021]
