MISO

Resolving tissue complexity by multimodal spatial omics modeling with MISO

MISO 方法详解：用模态内结构与模态间交互解析空间组织

1. MISO 要解决什么问题？

多模态空间组学在同一批组织位置上同时测量多种信息，例如 RNA、蛋白质、染色质可及性、代谢物和 H&E 组织学图像。真正困难的部分不是分别聚类每一种数据，而是把这些模态整合成一个共同表示，使最终空间区域同时反映分子状态和组织形态。

论文指出，已有方法通常存在几类限制：有些忽略空间相关信息；有些只针对两个模态或特定实验类型；有些需要较多超参数调节；有些容易受低质量模态影响。MUSE（Nature Biotechnology, 2022）主要面向转录组与形态图像，SpatialGlue（Nature Methods, 2024）主要整合成对的空间组学，且不原生接收组织学图像（paper.md:24,376-377）。

MISO（MultI-modal Spatial Omics）的目标是：给定任意数量、位置一一对应的模态特征矩阵，学习每个位置的联合低维表示，再用 KMeans 得到空间域。它的核心创新不是简单拼接，而是显式构造每对模态之间的外积交互特征。

2. 输入、输出与基本假设

设共有 $n$ 个模态：

\[X_1,\ldots,X_n,\]

其中 $X_m\in\mathbb{R}^{N\times d_m}$，第 $i$ 行对应同一个组织位置 $i$。输出是 $N$ 个位置的聚类标签。

必须注意：核心 Miso 类假设所有矩阵已经按位置对齐。它不接收空间坐标，也不负责条形码匹配、配准或跨模态行顺序检查（miso/miso/model.py:34-47）。因此，MISO 的“空间性”主要来自两点：观测本身位于组织空间中，以及输入特征（尤其是组织学特征）具有空间结构。

论文称 RNA、蛋白和 ATAC 原始计数可借助 Scanpy 预处理，而代谢组和组蛋白修饰数据应预先处理；每个模态之后进行 $z$-score 标准化（paper.md:166-169）。代码中确有独立的 preprocess 辅助函数，但它没有被 Miso 自动调用，也没有从包顶层导出（miso/miso/utils.py:12-38; miso/miso/__init__.py:1-2）。实际使用时，应把它理解为“先在外部准备好各模态矩阵，再传入 MISO”。

4. 第一步：为每个模态建立相似度图

MISO 先在每个模态内部定义位置之间的相似性。对模态 $m$：

\[{A}^{m}={\left[\exp \left(\frac{-{\Vert {x}_{i}^{m}-{x}_{j}^{m}\Vert }_{2}^{2}}{2{\sigma }^{2}}\right)\right]}_{i,\,j}.\]

$x_i^m$ 是位置 $i$ 在模态 $m$ 中的预处理特征。论文所有分析使用固定尺度 30（paper.md:184-190）；代码的 calculate_affinity 默认 sig=30，先计算两两欧氏距离，再使用相同形式的高斯核（miso/miso/utils.py:41-45）。

普通版本需要保存 $N\times N$ 矩阵，内存复杂度是二次的。大数据版本只保留每个位置的 $k$ 个近邻：

\[{A}_{i,j}^{m}=\begin{cases} \exp\!\left(-\dfrac{\Vert x_i^m-x_j^m\Vert_2^2}{2\sigma^2}\right), & j\in {\rm KNN}(i),\\ 0, & \text{其他情况}. \end{cases}\]

默认 $k=100$（paper.md:226-235）。代码通过 sparse=True 启用这一模式，并转成 PyTorch 稀疏张量（miso/miso/model.py:41-55; miso/miso/utils.py:46-50）。

5. 第二步：学习每个模态的 32 维表示

每个模态先标准化，再在原始维度超过 128 时做 PCA。随后，MISO 为每个模态训练一个独立网络。论文把它描述为带 32 节点瓶颈的自编码器（paper.md:193-205）。代码中的有效路径是：输入维度 → 32 → 正交参数化的 32×32 线性层 → 输入维度（miso/miso/nets.py:24-51）。虽然类中定义了激活函数，但有效 forward 中的激活调用已被注释，因此当前实现本质上是线性的。

5.1 谱聚类损失

论文给出的损失为：

\[{L}_{\rm SC}^{m}=\sum_{i,j}{A}_{i,j}^{m}\left\Vert y_i^m-y_j^m\right\Vert_2^2.\]

含义很直观：如果两个位置在原始模态中相似，即 $A_{ij}^m$ 较大，那么它们的低维表示也应该接近。论文还要求整个表示矩阵 $Y^m$ 正交，以避免所有位置坍缩为相同向量（paper.md:193-200）。

但代码与公式只有部分一致：

  • 代码使用的是未平方的欧氏距离；
  • 稠密模式只取上三角；
  • 最后取平均值，而不是公式中的求和；
  • 代码只对一个 32×32 权重矩阵做正交参数化，没有直接约束样本表示矩阵满足 $Y^{m\top}Y^m=I$。

直接证据见 miso/miso/model.py:68-77 和 miso/miso/nets.py:27-50。因此，代码保持了“相似样本在潜空间中接近”的思想，但没有逐字实现论文数学式。

5.2 重构损失与总损失

论文的重构损失为：

\[{L}_{R}^{m}=\sum_i\left\Vert z_i^m-\hat z_i^m\right\Vert_2^2,\]

其中 $z_i^m$ 是 PCA 后特征，$\hat z_i^m$ 是解码结果。总损失写为：

\[{L}^{m}={L}_{\rm SC}^{m}+\alpha {L}_{R}^{m}.\]

论文报告 $\alpha=1$，每个模态训练 1,000 轮，Adam 学习率 0.001（paper.md:202-211）。代码使用 MSE、1,000 轮 Adam 和 1e-3 学习率，但没有暴露 alpha，而是固定 loss = reconstruction + spectral（miso/miso/model.py:80-91）。由于论文实验使用 $\alpha=1$，两项等权与报告设置一致；不过，用户无法像论文描述的那样调整 $\alpha$。

6. 第三步：用外积显式表达模态间交互

如果只拼接两个 32 维向量，模型只知道“模态 A 有哪些特征、模态 B 有哪些特征”，却没有显式表示“A 的第 $p$ 个潜变量与 B 的第 $q$ 个潜变量共同出现”的关系。MISO 对每一对模态计算：

\[{y}_{i}^&#123;&#123;m}_{1}\otimes {m}_{2}} ={y}_{i}^&#123;&#123;m}_{1}}\otimes {y}_{i}^&#123;&#123;m}_{2}}.\]

两个 32 维向量的外积得到 32×32 矩阵，共 1,024 个二阶交互项。MISO 将其展平，再对每一对模态的交互矩阵提取前 32 个主成分（paper.md:214-223）。代码通过广播乘法、reshape 和 torch.pca_lowrank(..., q=32) 实现（miso/miso/model.py:94-98）。

如果保留 $n$ 个单模态项以及全部无序模态对，最终表示的维度为：

\[32n+32\binom{n}{2}.\]

这个步骤是 MISO 最具辨识度的计算设计：它以低成本加入二阶跨模态关系，而不需要训练一个大型联合深度网络。

7. 第四步：处理低质量模态

MISO 不会自动判断哪个模态质量差。论文要求用户根据图像伪影、UMI/基因数、蛋白空间变化、ATAC TSS enrichment、代谢物组织/背景分布等指标做二元判断（paper.md:238-244）。

代码中：

  • ind_views 决定保留哪些单模态表示；
  • combs 决定保留哪些模态交互；
  • 默认 'all' 表示全部保留（miso/miso/model.py:57-64）。

一个容易忽略的细节是：从 ind_views 去掉某模态，并不会在 combs='all' 时自动去掉它的交互项。这反而允许论文中提到的策略——低质量模态不以单模态项进入聚类，但仍通过与其他模态的交互提供信息；同时也要求用户显式协调两个参数。

8. 第五步：拼接并聚类

代码先分别标准化选中的单模态表示和交互表示，再拼接为 self.emb（miso/miso/model.py:99-108）。最后：

clusters = KMeans(n_clusters, random_state=100).fit_predict(self.emb)

见 miso/miso/model.py:110-113。聚类数由用户指定，代码和论文都没有给出自动选择聚类数的方法。

源代码隐含的调用顺序是：

model = Miso(features, ...)
model.train()
labels = model.cluster(n_clusters=...)

但本地快照中没有教程 notebook 或可执行示例验证完整输入组装流程。另一个工程细节是 Miso.train() 覆盖了 PyTorch 通常用于切换训练模式的 nn.Module.train(mode=True)，而这里它执行整个优化与融合过程（miso/miso/model.py:66-108）。

9. H&E 图像特征为什么是 576 维？

论文采用 HIPT 层次视觉 Transformer（paper.md:172-175）：

  1. 把全切片图像分成 4,096×4,096 区域；
  2. 再把每个区域分成 256×256 图块；
  3. 局部 ViT 为 16×16 patch 提取 384 维特征；
  4. 全局 ViT 在更大范围内聚合，产生 192 维上下文；
  5. 拼接成 $384+192=576$ 维；
  6. 对落入每个组学位置的 patch 求平均或取样。

代码确实实现了局部/全局路径（miso/miso/hist_features.py:265-385,529-562; miso/miso/hipt_4k.py:13-82），但当前工作区缺少 Git LFS 中的两个 .pth 权重文件，因此无法仅凭本地快照重跑 H&E 特征提取。代码还存在两个值得注意的实现细节：get_features 不传递自己的 pretrained 参数，而是固定使用 True；平滑后的字典被赋给 embs，但最终返回值由原始 emb_cls/emb_sub 变量构造（miso/miso/hist_features.py:548-562）。

10. 论文如何评估？

论文使用生物学标记、病理标注、MERFISH 参考、F1、ARI 和模态内 ICC 等证据。ICC 定义为：

\[{\rm ICC}_{i}^{(k)}=\frac{\sigma_m^2}{\sigma_i^2+\sigma_m^2},\]

其中 $\sigma_i^2$ 是簇内方差，$\sigma_m^2$ 是簇均值之间的方差。ICC 越高，说明该模态在簇内越一致（paper.md:247-256）。本地代码中 Not found ICC 实现。

主结果包括：

  • 膀胱癌 TLS 中，MISO 的 HEV 假阳性超像素为 10 和 6，SpatialGlue 为 289 和 381；MUSE 未形成对应 HEV 的簇（paper.md:61-67）。
  • 胃癌 Xenium 数据含 696,314 个细胞，CRC Visium HD 含 545,913 个 bin；论文称 MUSE 和 SpatialGlue 因内存限制无法分析（paper.md:73-96）。
  • E13 ATAC–RNA 数据中，MISO 区分了 ventricular zone、subpallium stratum 与 pallium stratum，并由 SOX2、GAD2、TBR1 的 RNA/ATAC 模式支持（paper.md:99-119）。
  • 三模态海马分析中，MISO 是比较方法中唯一准确定位小型 CA2sp 亚区的方法（paper.md:122-139）。
  • 扁桃体 RNA+蛋白+图像分析的 germinal-center F1 为 0.90；MISO 两模态组合平均 F1 为 0.87，MUSE 为 0.78，SpatialGlue 为 0.68（paper.md:142-145）。

11. 如何理解 MISO 的优点？

MISO 的优势来自“分而治之”：

  • 每个模态独立学习表示，降低不同数据类型直接混合的困难；
  • 相似度图让潜空间保留模态内邻域结构；
  • 外积加入跨模态二阶关系；
  • 用户可删去低质量单模态项，同时选择性保留交互；
  • 稀疏 KNN 图让方法扩展到数十万位置。

它不是端到端学习所有任务的巨大模型，而是一个结构清楚、超参数较少的表示构建与聚类框架。

12. 局限、缺口与复现判断

论文自身承认：原始图像提取仅适用于 H&E；聚类后需要人工赋予生物学含义；不能量化各模态贡献；不能自动发现低质量模态；不能联合分析多个样本（paper.md:154-160）。

代码审查进一步发现：

  • 论文谱损失公式与实现不完全一致；
  • 样本表示矩阵的正交约束没有直接实现；
  • alpha 不可配置；
  • 原始组学预处理没有接入公共 Miso API；
  • 本地快照中 Not found 教程、测试、ICC/实验/绘图脚本；
  • H&E 预训练权重缺失；
  • 完整 16 数据集评估需要外部数据与未随快照提供的流程知识。

因此，本工作区的复现性评价为 3/5：核心组学表示与融合代码可以理解和重建，但不能只依靠当前快照完整复现论文的图像流程与全部实验。

MISO: multimodal spatial-omics integration and clustering

Problem

Multimodal spatial assays measure aligned molecular and image information, but useful spatial domains may be defined jointly by several modalities rather than by any one data type. Existing approaches described by the paper are narrower: MUSE (Nature Biotechnology, 2022) integrates transcriptomics with morphology, while SpatialGlue (Nature Methods, 2024) targets selected two-omics assay designs and does not natively accept histology images (paper.md:21-27,376-377). Both are also reported to be sensitive to modality weighting or unable to scale to the largest datasets evaluated here.

MISO (MultI-modal Spatial Omics) addresses this by learning a fused representation from an arbitrary number of aligned omics and imaging modalities, then applying k-means to identify spatial domains. It is intended to require little hyperparameter tuning and to let users exclude low-quality modality-specific terms while retaining informative cross-modality interactions.

Method in brief

For each modality, MISO:

  1. preprocesses and z-scores the input, retaining at most 128 PCs;
  2. constructs a dense Gaussian affinity matrix or a sparse 100-neighbor graph for large datasets;
  3. trains a separate 32-dimensional reconstruction network for 1,000 Adam steps/epochs using reconstruction plus graph-weighted latent-distance losses;
  4. computes every selected pairwise outer product between modality embeddings, flattens each 32×32 interaction and reduces it to 32 PCs;
  5. standardizes and concatenates selected individual and interaction features; and
  6. runs k-means on the fused embedding.

For H&E input, a hierarchical pretrained ViT combines 384-dimensional local patch information with 192-dimensional long-range context to create 576-dimensional spot-level image features (paper.md:166-235,286-334).

The repository implements the core pipeline at commit 1252c6f4b280a0fd303c2a3e131e68b379acb3a6: affinity construction, PCA, modality-specific training, outer-product fusion, manual term selection and k-means are directly present in miso/miso/model.py:34-113, nets.py:24-51 and utils.py:41-50. The tutorial shows the intended get_features -> preprocess -> Miso -> train -> cluster call order.

Main evaluation evidence

The paper evaluates 16 datasets spanning RNA, protein, ATAC, histone modification, metabolomics and histology, including spot-, cell- and subcellular-resolution platforms (paper.md:27,47-157). The main figures visually support several distinct claims:

  • Fine structure: in two bladder-cancer TLS regions, MISO produced only 10 and 6 non-HEV false-positive super-pixels, compared with 289 and 381 for SpatialGlue; MUSE did not yield an HEV-like cluster.
  • Histology adds information: in gastric cancer, mucosa and carcinoma have similar ERBB2 patterns but distinct morphology and MISO image-feature maps. In Visium HD colorectal cancer, a MISO subcluster colocalized with SPP1⁺ macrophages despite broad CEACAM6 expression.
  • Cross-omics integration: in E13 mouse telencephalon, MISO separated ventricular, subpallial and pallial regions supported by SOX2, GAD2 and TBR1 RNA/ATAC patterns.
  • Three modalities: in mouse hippocampus, MISO alone localized the small CA2sp subfield when integrating RNA, metabolite and image information.
  • Quantitative localization: in human tonsil, all-three-modality MISO reached F1=0.90 for germinal centers. Mean two-modality F1 was 0.87 for MISO, 0.78 for MUSE and 0.68 for SpatialGlue.
  • Scale: the paper reports analyses of 696,314 Xenium cells and 545,913 Visium HD bins, which MUSE and SpatialGlue could not process because of memory constraints.

Extended Data Fig. 1 shows higher MISO ICC for most displayed modality/dataset combinations. The visible exception is hippocampus RNA (SpatialGlue 0.47 versus MISO 0.42), consistent with the paper’s statement that low-quality RNA-specific terms were excluded while RNA interactions remained.

Important limitations

  • Modality quality is not detected automatically; users make a binary inclusion decision for individual and interaction terms.
  • The H&E extractor does not directly support other stains or microscopy modalities.
  • The number of clusters is user-specified, and biological interpretation remains manual.
  • Dense affinity storage is quadratic; sparse kNN mode is needed for large inputs.
  • The active repository network is linear, despite the paper’s broader deep-autoencoder terminology.
  • The implemented spectral loss is a Partial match: code weights unsquared latent distances, whereas the Methods equation uses squared distances.
  • The paper’s main loss equation places $\alpha$ on reconstruction loss, while its pseudocode places $\alpha$ on spectral loss; the released code exposes no $\alpha$ and hard-codes equal weighting. This ambiguity is immaterial for the reported $\alpha=1$ runs but matters for extension.

Reproducibility assessment: 3/5

Strengths:

  • public GitHub snapshot with captured commit provenance;
  • install metadata, bundled pretrained histology checkpoints and a tutorial notebook;
  • core method, sparse scaling path and feature-selection controls are readable and substantially match the paper.

Gaps:

  • overall code-paper fidelity is medium: Exact 7, Partial 4, Notebook 1 and Not found 2 in doc_code.md;
  • experiment-specific pipelines, baseline execution, ICC/F1/ARI calculations and statistical-test scripts are Not found;
  • no automated tests are present;
  • tutorial inputs are downloaded from external Google Drive storage;
  • Python 3.7 and tightly pinned 2021–2022 dependencies may complicate modern installation;
  • supplementary Markdown is MISSING. The main article links a supplementary PDF, but supplementary figures, Supplementary Table 1 and supplementary-only details were not verified from a converted source.

Overall, MISO’s central idea is well represented in the released package and visually supported across diverse datasets, but exact reproduction of the paper’s reported benchmarks requires substantial unavailable analysis code and careful handling of the documented paper-code differences.
