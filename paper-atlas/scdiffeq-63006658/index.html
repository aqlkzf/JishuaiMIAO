scDiffEq：用神经随机微分方程同时学习细胞命运的“方向”与“随机性”

一句话抓住方法

scDiffEq 不把单细胞时间序列理解为“每个早期细胞都有一个可观测的后继细胞”，而把每个时间点的细胞看成一个群体分布：从早期群体采样细胞，在低维表达空间中用神经随机微分方程（neural SDE）向前模拟，再让模拟群体逼近后续时点的真实群体。模型同时学习确定性的漂移 $f(z)$ 与依赖细胞状态的扩散 $g(z)$，因此既能表示分化的平均方向，也能表示同一祖细胞附近可能产生多种结局的随机性。

这个区分是论文的核心。传统漂移—扩散模型常把扩散设为全数据共享的常数；scDiffEq 则让 $g(z)$ 由神经网络给出，因而扩散强弱可随细胞状态改变。论文用 LARRY 谱系追踪数据检验命运预测、缺失时间点插值和扰动响应，并进一步把漂移与扩散的大小映射回细胞和基因动态。

1. 问题、输入与输出

1.1 为什么不能做普通的监督回归

scRNA-seq 会破坏被测细胞。即使实验在第 2、4、6 天分别测量，也通常不知道“第 2 天的细胞 A”在第 4 天具体变成了哪一个细胞。因此训练信号不是成对的 $(x_t,x_{t+1})$，而是多个时点的细胞集合。LARRY 条形码提供克隆和命运信息，适合做外部验证，但模型的群体匹配目标仍然面向分布。

1.2 模型真正接收什么

论文主分析先对表达量缩放，再投影到 50 维 PCA 空间。记单个细胞状态为 $z\in\mathbb{R}^{50}$。训练还需要：

  • 细胞的时点或用于构造模拟时间的标签；
  • 初始群体（例如 LARRY 第 2 天细胞）；
  • 后续时点的观测群体；
  • 可选的生长权重，用来调整最优传输中的细胞质量。

本地代码的公开入口默认 use_key="X_pca"、latent_dim=50、dt=0.1，训练/验证划分为 0.9/0.1，批量大小为 2,048（scDiffEq/src/scdiffeq/core/_scdiffeq.py:210-265）。这些是当前快照的 API 默认值，不应自动等同于论文每个任务和每个大型变体的精确配置。

1.3 输出分成三层

  1. 动力学模型：给任一状态 $z$ 计算漂移向量 $f(z)$ 和扩散 $g(z)$。
  2. 模拟轨迹/群体：从指定初始细胞反复采样布朗运动，得到一组可能轨迹与终点命运分布。
  3. 解释量：每个细胞的漂移、扩散及其 L2 范数，嵌入空间中的速度场，以及基因扰动前后终末命运比例的变化。

2. 核心方程：方向与不确定性是两张不同的图

连续形式为

\[d z_t=f_\theta(z_t)\,dt+g_\phi(z_t)\,dW_t.\]

论文图 1b 用离散近似直观展示：

\[\hat z(t+\Delta t)=z_t+f_\theta(z_t)\Delta t+g_\phi(z_t)\Delta W(t).\]

从左到右读这条式子：

  • $z_t$ 是当前细胞在 PCA 空间的位置；
  • $f_\theta(z_t)\Delta t$ 是有方向的平均位移，代表确定性调控趋势；
  • $g_\phi(z_t)\Delta W(t)$ 是随机位移，$\Delta W$ 来自布朗运动；
  • 两项相加产生下一时刻的一次随机样本，而不是唯一预测。

例如某个祖细胞的漂移把它推向中性粒细胞方向，但该处扩散较大。重复模拟 100 次时，大部分轨迹可沿漂移方向前进，少部分会进入单核细胞等邻近分支。这里的“多命运”来自条件分布，而不是给每个细胞贴一个确定标签。

关键点是 $g_\phi(z)$ 随 $z$ 变化。若把它替换成常数，模型只能在所有细胞状态施加相同强度、相同结构的噪声，无法表示多能祖细胞与已承诺细胞之间不同的随机性。论文的恒定扩散消融使命运预测准确率下降 11.1%，交叉熵约增大 3.4 倍；这是论文分析结果，不是当前包内一个可直接运行的独立 ablation 类。

3. 模型如何训练

3.1 从初始群体向前积分

训练批次提供初始状态 batch.X0 和时间网格 batch.t。本地实现调用 integrate(Z0, t, dt)，底层通过 torchsde.sdeint 或 sdeint_adjoint 积分（core/lightning_models/base/_base_lightning_diffeq.py:153-176）。当前 API 配置的是 Itô SDE、general noise、一个 Brownian 维度（core/_scdiffeq.py:282-285）。漂移和扩散网络本体由外部依赖 neural-diffeqs 构建，因此这个仓库保存了组装参数和训练流程，却没有完整复制该依赖的网络内部实现。

3.2 不要求细胞一一对应，而要求群体分布接近

模拟得到 $\hat Z_t$ 后，模型用去偏 Sinkhorn divergence 比较预测与观测点云：

\[L_S=\sum_{t\in T_{obs}} S_\varepsilon(\hat\mu_t,\mu_t).\]

$\hat\mu_t$ 是模拟细胞分布，$\mu_t$ 是该时点真实细胞分布。Sinkhorn divergence 是熵正则最优传输距离的去偏形式，允许两组细胞没有逐点配对。代码把预测与真实的权重、坐标传给 geomloss，默认 blur=0.1、scaling=0.7、debias=True（core/lightning_models/base/_sinkhorn_divergence.py:9-19）。

若提供 KEGG 生长权重，代码对经过时间进行指数变换并归一化，使不同增殖/死亡倾向改变群体质量匹配（core/lightning_models/base/_batch_processor.py:162-168）。论文比较了有无 KEGG 权重的结果，但这类权重不是由 scDiffEq 在当前包内从表达矩阵自动推断出来的。

3.3 为什么还需要漂移/扩散比正则

只优化群体距离时，扩散网络可能把模拟细胞广泛撒到流形上，以较低代价“覆盖”目标群体，却没有学到清晰的调控方向。论文因此约束漂移和扩散对位移的相对贡献。当前实现先计算

\[r_f=\operatorname{mean}\|f(\hat Z)\|_2\,dt, \qquad r_g=\operatorname{mean}\|g(\hat Z)\|_2,\]

再施加

\[L_R=E\left(R_{target}-\frac{r_f}{r_g}\right)^2, \qquad L=L_S+L_R.\]

代码中的默认值为 $R_{target}=2.5$、$E=100$（core/_scdiffeq.py:223-227）；_compute_magnitude_f 显式乘以 dt，而扩散项没有同样的乘法，随后平方差并与 Sinkhorn loss 相加（core/lightning_models/mix_ins/_regularized_velocity_ratio_mix_in.py:66-153）。因此代码中的比值是离散训练代理量，不能简单解释成连续时间里两个网络原始输出的无量纲比。

论文筛选显示 1–5 较稳定，2.5 附近最好；这是一条经验起点，不是跨数据集的生物常数。补充说明也明确指出，不同可塑性、技术噪声和发育阶段可能需要重新选择。

3.4 优化参数与版本边界

当前公开 API 默认训练 2,500 epochs，RMSprop、学习率 $10^{-4}$、批量大小 2,048，漂移隐藏层 [512,512]、扩散隐藏层 [32,32]，两者默认 dropout 为 0.1（core/_scdiffeq.py:239-278）。论文 Methods 中部分任务写的是无 dropout，并给出任务特定网络；图 2 的 scDiffEq-XL 又来自额外超参数搜索。论文结果段的排版将 XL 描述为漂移两个 2,048 单元隐藏层、扩散两个 256 单元隐藏层。故应区分：

  • 论文任务配置：产生论文表格和图中的数值；
  • 当前包默认配置：本地 commit c91e10e499f2d05aad047a33100fe0260d2fed2b 的可调用默认值；

不能仅运行当前默认构造器，就宣称复现了 XL 的 58.5% 或插值任务的 3,200 万参数模型。

4. 训练后如何得到命运、插值和扰动结论

4.1 命运预测

从早期祖细胞重复模拟多条轨迹，把每条轨迹终点用邻近真实细胞的状态标签注释，再统计各终末类型的比例。这个比例是预测的命运分布，最高比例对应 dominant fate。包内 tools/_simulation.py 提供重复模拟，tools/_annotate_cell_fate.py 从终点标签计数。

论文 LARRY benchmark 使用谱系条形码构造近似真值与平行孔训练/测试划分。图 2d 报告 scDiffEq-XL dominant-fate accuracy 为 $58.5\pm1.8\%$，PRESCIENT+KEGG 为 $50.7\pm1.2\%$，静态线性回归为 $61.9\pm0.2\%$。静态模型数值更高并不意味着它学会了轨迹；它只做判别预测，而 scDiffEq 还要生成中间状态和完整群体动态。

4.2 时间插值

训练只给第 2、6 天群体，把第 4 天藏起来。模型从第 2 天向第 6 天模拟，在中间时间取出预测群体，与未参与训练的第 4 天细胞比较 Sinkhorn distance。图 2e 中 scDiffEq 的训练/测试距离为 13.74/24.56，PRESCIENT 为 14.94/25.85。图 2f 进一步画出模拟群体到各实测时点的距离随模拟时间变化：早期接近第 2 天，中期接近第 4 天，后期接近第 6 天。这比只看终点距离更能排除“直接跳到终点”的假动态。

4.3 扰动预测

包内扰动流程先在表达空间对指定基因施加变化，再把 control 与 perturbed 初始细胞分别向前模拟，注释终末命运，计算命运比例的 log fold change 和统计量（tools/_perturb.py、tools/_fate_perturbation_experiment.py、tools/_fate_perturbation_screen.py）。论文把预测与 CRISPR 扰动造血数据比较。

这里要保留两层边界：包提供通用扰动—模拟—注释机制；具体基因集合、预处理、重复数和论文图的统计汇总属于分析脚本级配置。当前仓库还把部分变换委托给外部 cell-perturb 依赖。

5. 漂移和扩散怎样解释成生物学

5.1 先解释细胞状态，不把扩散直接叫成“生物噪声真值”

包内 model.drift() 与 model.diffusion() 在细胞位置前向计算网络输出，并把向量和 L2 范数写入 AnnData（core/_mix_ins/_state_characterization_mix_in.py:40-120）。漂移向量可投影到 UMAP 形成流线；扩散 L2 范数可着色显示“模型在该状态需要多强的随机项”。

图 2b 的箭头是学习到的漂移场，颜色是扩散 L2 范数。它支持“模型学到状态依赖的随机分量”，但不能单独证明扩散全部来自内源转录噪声：采样误差、未观测协变量、批次差异和模型失配也可能被扩散吸收。可靠解释需要与谱系、扰动、已知标记基因和跨种子稳定性共同验证。

5.2 多能性与随机性的关系是结果，不是硬编码

论文比较不同 fate multiplicity 的祖细胞，报告从 mono-fate 到 multi-fate 时扩散范数由 $2.9\pm0.5$ 增至 $4.7\pm0.2$，漂移范数由 $53.1\pm1.3$ 增至 $60.7\pm0.6$。这说明模型在更具多能性的区域同时学到更强的确定性变化和随机性；不是简单的“漂移低、扩散高”。这些数值依赖训练尺度与正则，跨模型比较前需保持表示空间、dt 和比值定义一致。

5.3 基因层解释来自轨迹上的相关与动态，而非网络权重直读

论文沿模拟的 GMP—中性粒/单核细胞轨迹查看转录因子动态与漂移/扩散相关性。合理的阅读方式是：先选择与真实流形一致的轨迹，再看某基因表达随时间的变化是否与扩散峰值或漂移方向稳定对应，最后用已知调控关系或扰动结果验证。神经网络某个权重本身不等价于基因调控边。

doc_code.md 的 Match Assessment 给出了更细的文件和行号表。最重要的结论不是“有代码所以论文完全可复现”，而是：核心可复用包是存在的；论文级实验编排、XL 精确配置、消融与部分指标在 companion analysis 层。

8. 一条可操作的使用流程

  1. 对多个时点的 AnnData 做一致预处理，建立 PCA 表示，并保留时点/数据划分键。
  2. 明确初始群体与观测时间，不把伪时间无条件当真实天数。
  3. 构造 scDiffEq，显式记录网络大小、dropout、dt、比值目标、种子和依赖版本，不依赖隐式默认值。
  4. 训练时同时查看训练与验证 Sinkhorn loss、速度比正则、轨迹是否离开数据流形。
  5. 用多个种子重复模拟；以独立时点、谱系或扰动作为验证，而不是只看训练损失。
  6. 命运结论报告完整概率分布及不确定性，不只报告 dominant fate。
  7. 解释漂移/扩散时检查对表示空间、dt、正则目标和种子的敏感性。

9. 最容易误读的地方

  • 扩散不是测得的分子噪声。 它是给定模型、表示与数据后学到的随机项。
  • UMAP 箭头不是 SDE 的训练空间。 模型主要在 PCA 空间训练；UMAP 是投影视图。
  • 分布拟合不保证单细胞真实路径。 谱系、隐藏时点和扰动验证才增强轨迹可信度。
  • 2.5 不是普适常数。 它是论文筛选出的经验目标，且实现定义含 dt。
  • 包默认值不等于论文 XL。 当前 commit 的 [512,512] / [32,32] 与论文额外调参变体不同。
  • 潜能模型不是所有任务的必要约束。 scDiffEq 可配置 potential SDE，但论文插值改进明确涉及移除漂移的 potential-gradient 约束。
  • 一次模拟不是命运概率。 需要从相同初始条件重复随机模拟并统计终点。

scDiffEq - Learning Cell Dynamics with Neural Differential Equations

Motivation and Novelty

Cell fate decisions combine directional regulatory programs with stochastic fluctuations. In haematopoiesis, a progenitor’s future cannot be measured continuously because scRNA-seq destroys the sampled cell, so methods must infer dynamics from population snapshots and, where available, lineage barcodes.

scDiffEq models this problem as a neural stochastic differential equation in PCA-reduced gene-expression space. Its key novelty is learning both deterministic drift $f(z)$ and state-dependent diffusion $g(z)$ with neural networks, rather than treating diffusion as a constant dataset-level noise term.

Prior approaches leave this gap:

Method Overview

scDiffEq takes scRNA-seq cells, scales expression, projects cells into a 50-PC latent space and trains a neural SDE:

\[\Delta z(t) = f(z(t))\Delta t + g(z(t))\Delta W_t.\]

The model simulates cells from an initial time point and minimizes debiased Sinkhorn divergence between predicted and observed populations at later time points. A velocity-ratio penalty constrains the balance between drift and diffusion, with the main LARRY analyses using $R_v=2.5$ and enforcement scalar $E=100$.

After training, the same model is used for:

  • simulating many futures from a progenitor and estimating terminal fate probabilities;
  • interpolating held-out time points;
  • in silico gene perturbation by modifying expression, projecting into PCA space and simulating trajectories;
  • evaluating drift and diffusion vectors per cell to study state-dependent deterministic and stochastic dynamics.

The strongest evidence is on LARRY because lineage barcodes provide a meaningful fate benchmark. The perturbation results are biologically plausible and recover known regulators, but they remain model-based hypotheses. The paper explicitly notes that marker-gene perturbations can be misleading because changing PCA-space position toward a fate region is not the same as proving causal regulation.

Reproducibility

Rating: 4/5 for using the method; 3/5 for reproducing every paper figure from this workspace alone

Strengths:

  • Public Python package is present locally at commit c91e10e499f2d05aad047a33100fe0260d2fed2b.
  • Core model components are implemented: neural SDE, torchsde integration, geomloss Sinkhorn divergence, velocity-ratio regularization, simulation, perturbation and drift/diffusion characterization.
  • Built-in dataset loaders exist for LARRY, human haematopoiesis and pancreas examples.
  • Paper documents major datasets, benchmark tasks, seeds, hardware and statistical tests.
  • Code is pip/uv-installable and compatible with AnnData/scverse workflows.

Limitations:

  • Exact manuscript analyses are in a separate companion repository (scdiffeq-analyses), not cloned in this rerun per user instruction.
  • Public package defaults differ from paper settings: dropout defaults are 0.1 despite the paper saying no dropout, and scheduler step size must be controlled carefully.
  • SWA exists as a callback but is not automatically enabled in the default callback list.
  • Some evaluation items are notebook-level rather than package-level: negative cross-entropy, XL/task-2 exact configs, constant-diffusion ablation and scaling experiments.
  • Drift/diffusion network internals live in the external neural-diffeqs dependency.

Practical reproduction notes:

  • Set mu_dropout=0, sigma_dropout=0, velocity_ratio_params={"target": 2.5, "enforce": 100, "method": "square"} and paper-matched train_step_size explicitly.
  • Verify whether paper-specific annotation uses Annoy settings from the companion repo; the inspected package now wraps cell_neighbors.kNN.
  • Treat in silico perturbation outputs as prioritized hypotheses, especially for marker genes.
