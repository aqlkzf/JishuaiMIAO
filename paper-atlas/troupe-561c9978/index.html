TROUPE：从末端谱系树反推不可见祖细胞与分化速率

1. 核心问题

TROUPE 处理的不是普通表达矩阵轨迹，而是多棵带时间尺度的细胞谱系树：叶节点是实验末端采到的细胞，叶上有转录组细胞类型标签，边长代表两次分裂之间的时间。它要推断一个定量分化图，包括细胞类型之间的连续时间转换率、各类型的分裂/增长率，以及采样时已经消失、因而没有叶标签的祖细胞类型。

论文为 “Inferring Cell Differentiation Dynamics with Unobserved Progenitors”，bioRxiv 2025，DOI 10.64898/2025.12.09.693214。本地代码固定在 fd52dae21fd0a2f65892af28c7b9e070712fec1e，仓库为 raphael-group/troupe。

2. 为什么祖细胞会“不可见”

设类型 $i$ 的总分化流出率为

\[\alpha_i=\sum_{j\ne i}Q_{ij},\]

分裂率为 $\lambda_i$。论文证明祖细胞的期望数量受

\[\mathbb E[z_i(t)]\lesssim \exp\{t(\lambda_i-\alpha_i)\}\]

控制。当 $\alpha_i>\lambda_i$ 时，祖细胞分化得比自我复制更快，末端采样时很可能一个也看不到。它虽然不在叶端，却在树的内部历史中影响分支长度和后代类型组合。只对可见叶类型拟合模型，会把这部分历史错误归给终末类型之间的直接转换或错误增长率。

这也是 TROUPE 与“给叶类型聚类”的方法本质不同之处：它用一个显式连续时间分支过程，对内部节点的未知类型做概率边缘化。

3. potency 如何编码不可逆分化

一个状态的 potency 是它最终能够产生的终末类型集合。例如，若祖细胞可产生 Somite 和 Neural Tube，它的 potency 是 {Somite, Neural Tube}；终末 Somite 的 potency 是 {Somite}。

分化只能从较大集合走向其子集：

\[Q_{\alpha\beta}=0\quad\text{若}\quad \beta\nsubseteq\alpha.\]

这条约束排除去分化，也允许一个观察到的状态本身是祖细胞，例如 TLS 数据中的 NMP。RateMatrixBuilder._build_mask()（troupe/src/models.py:73-95）逐对检查目标 potency 是否为来源 potency 的子集；只有允许位置拥有可训练参数。forward()（:97-109）对自由参数做 softplus 得到非负非对角速率，再令对角线为该行流出率的负和。

potency 不是代码根据表达量自动发现的细胞身份。观察到的祖细胞 potency 可以由用户约束；隐藏 potency 候选则由叶标签和树结构生成。错误或过强的 potency 先验会直接改变允许的边和最终模型。

4. PoSSE 分支过程与树似然

TROUPE 的主模型是带 potency 约束的多类型纯出生 SSE 过程。参数为：

  • $Q$：连续时间类型转换率矩阵；
  • $\lambda_i$：类型 $i$ 的分裂率；
  • $\pi$：根节点起始类型分布，通常约束到最有潜能的状态。

对树边长 $b$，沿边存活且发生类型转换的传播核来自

\[\exp\bigl(b(Q-\Lambda)\bigr),\qquad \Lambda=\operatorname{diag}(\lambda).\]

每个二分内部节点再贡献该父类型的 $\lambda_i$。对所有可能的内部节点类型求和，就得到观察到叶标签的树似然。FelsensteinPruner.log_prune()（troupe/src/models.py:265-330）用 torch.matrix_exp 计算每条边的传播矩阵，以树深度分组、在 log 空间用 logsumexp 自底向上合并左右子树；二分节点加入 log(growth_rates)。根部再与 softmax 后的 $\pi$ 合并（:396-424）。

因此，分支长度不可省略：它把“发生多少次类型变化/分裂”转换为每单位实验时间的速率。如果输入树没有可信绝对时间尺度，输出只能解释为每个归一化树长单位的率。

5. 两阶段推断为什么必要

5.1 候选隐藏状态

理论上所有非空终末类型子集都可能是 potency，但完整幂集随类型数指数增长。当前统一入口 troupe/scripts/run_troupe.py 根据观察 potency 和树上诱导的候选集合生成有限状态空间，并允许 --max-hidden 控制规模。这是实际可扩展性的关键，也意味着未进入候选集的真实祖细胞无法被恢复。

5.2 Phase 1：稀疏过参数拟合

代码把多个隐藏候选一起放进模型，并在负对数似然上加入 $Q$ 非对角项的 L1 惩罚：

\[\mathcal L_1=-\log L(\mathcal T\mid Q,\lambda,\pi)+\gamma\lVert Q_{\rm off}\rVert_1.\]

troupe/src/optimizer.py:127-162 实现此目标；run_troupe.py:279-321 对每个正则化强度运行 Phase 1。较大的 $\gamma$ 关闭更多转换，使更多候选状态不可达，从而产生祖细胞数不同的一组模型。

L1 选择结构的同时会把保留速率向零压缩，所以 Phase 1 的数值不应直接作为最终生物速率。

5.3 Phase 2：取可达状态并去偏重拟合

run_troupe.py:323-449 读取 Phase 1 模型，从根状态通过长期矩阵传播识别可达状态，裁剪 $Q$ 和增长率，将缩减后的参数作为 warm start，再用极小的 debiasing_l1 重拟合。这一步保留稀疏结构选择结果，但减少 L1 对速率的系统性下压。

源码默认/CLI 暴露的去偏惩罚、可达阈值和优化设置属于实现超参数；换数据时不能只复制论文中的概念流程而忽略它们。

5.4 Pareto front 与 Kneedle

每个 $\gamma$ 得到一个“祖细胞数量—未正则化损失”点。run_troupe.py:458-577 先取 Pareto 前沿，再用 Kneedle 找拐点，选择继续增加祖细胞却只带来很小似然改善的位置。若没有检测到 knee，代码有回退选择逻辑。

这不是对隐藏祖细胞数的后验概率，也不是显著性检验；它是复杂度—拟合度启发式。正则化网格、候选 potency 集、树数和采样率都会改变拐点。

6. 输入到输出的实际流程

  1. 读取多棵 ete3 谱系树；叶端 .state 保存观察细胞类型。
  2. 检查/处理树结构，建立状态标签、终末类型和已知 potency。
  3. 生成隐藏 potency 候选并构造 idx2potency。
  4. 将树张量化为节点、子节点、边长、叶 partial 和深度层级。
  5. 对一组 L1 强度分别拟合过参数 PoSSE 模型。
  6. 从每个稀疏解裁剪可达状态，进行去偏重拟合。
  7. 用 Pareto/Kneedle 选模型。
  8. 输出率矩阵、增长率、根分布、状态/potency 映射、损失和分化图。

主入口是 troupe/scripts/run_troupe.py。仓库也保留 infer_model.py 和实验脚本；另有 ClaSSE 原型，使状态变化发生在分裂事件而非沿分支连续发生。论文主结果使用 PoSSE，不能把 classe_* 代码的假设混入论文主方法。

8. 关键假设与限制

论文 Discussion 明确指出两项核心限制：

  1. 时间齐次。 $Q$ 和 $\lambda$ 在整个实验中固定，无法表达阶段性 fate bias 或随时间变化的增殖。
  2. 完整采样、无死亡。 主解析似然假定观察到完整纯出生树。实际 TLS 只观察估计约 2–5% 的末端细胞；子采样会拉长可见末端枝并低估终末类型增长率。

还应注意：

  • 输入树应有正确根、二叉结构和时间一致的边长；树重建误差未在主模型中联合传播。
  • 叶类型标签被当作已知；转录组注释误差会影响 likelihood partial。
  • 纯出生的“增长率”是分裂率，不包含死亡；不能与净增长率混用。
  • 多套 $Q,\lambda$ 可能给出相近叶端似然，potency 约束和多重复树提高识别性，但不保证唯一真值。
  • 实现强制 float64，以降低深树上矩阵指数的数值问题；这不消除极端率和长枝下的优化困难。

10. 复现结论

本地快照有固定 commit、requirements.txt、可安装包、示例树/参数、统一入口和较完整测试，这是强复现基础。可直接验证核心率矩阵、pruning、优化和两阶段逻辑。仍缺少独立补充材料与完整预计算论文输出，真实数据运行也依赖谱系树和 potency 约束的来源质量。

最稳妥的解读是：TROUPE 在一个明确的、时间齐次、纯出生、potency 不可逆的生成模型内，从多棵末端标记谱系树估计隐藏祖细胞结构和定量速率。输出是条件于输入树、候选状态、采样假设和模型选择规则的统计估计，而不是直接观测到的胚胎细胞历史。

TROUPE: Tree-informed Rate Optimization Using Potency Enforcement

Paper: “Inferring Cell Differentiation Dynamics with Unobserved Progenitors” Authors: Howard-Snyder, Zhang, Schmidt, Chan, Raphael (Princeton) DOI: 10.64898/2025.12.09.693214 | bioRxiv, December 2025 Category: dynamics_fate_trajectory

Motivation & Novelty

The Biological Problem

Understanding cell differentiation is central to developmental biology. Cells progressively restrict their developmental potential — from totipotent progenitors that can become any cell type, to committed terminal fates. This process is captured as a differentiation map: a DAG where nodes are cell types and edge weights quantify transition rates between them.

Single-cell lineage tracing technologies (e.g., CRISPR-Cas9 barcoding) now enable reconstruction of high-resolution cell lineage trees — binary trees where leaves are sampled cells and branch lengths record division times. When paired with transcriptional annotations at leaves, these trees in principle encode full information about differentiation and growth rates. But extracting this information requires an explicit statistical model.

Limitations of Existing Approaches

  • LARRY/WEINREB (Weinreb et al., Science, 2020) and Quantitative Fate Mapping (Fang et al., Cell, 2022): Infer transition rates or progenitor dynamics from lineage barcodes but do not use branch lengths and cannot quantify per-type growth rates.
  • Carta (Sashittal et al., bioRxiv, 2024): Encodes potency constraints and finds parsimonious progenitor sets, but infers transition counts (confounded by growth rates), does not infer rates, treats NMPs as terminal states, and cannot model self-renewal edges.
  • EvoC (Evolutionary Coupling): Clusters cell types based on pairwise tree distances; restricted to binary tree differentiation maps, cannot scale number of progenitors beyond S -1.
  • Standard SSE (BiSSE, Maddison et al., Systematic Biology, 2007; MuSSE, FitzJohn, Methods in Ecology and Evolution, 2012): Infers rates from phylogenetic trees but lacks potency constraints (allows dedifferentiation) and cannot handle unobserved progenitor types.
  • Schiffman et al. (Nature Genetics, 2024): Infers rates for evolutionary processes but assumes all transitions are allowed and cannot discover unobserved progenitor types.

What’s New

TROUPE introduces three interconnected contributions:

  1. PoSSE model — A multi-type pure-birth branching process with potency constraints built into the rate matrix. Constraints enforce irreversibility (no dedifferentiation) and make the rate matrix upper-triangular when types are ordered by potency. This is the first model that jointly infers quantitative transition rates, growth rates, and progenitor potencies from lineage trees.

  2. Theoretical result on progenitor invisibility — Proves that when a progenitor’s differentiation rate exceeds its growth rate, its expected population decays exponentially to zero. This formalizes why naive MLE on observed types alone fails: key parameters are essentially unidentifiable from the observable data.

  3. TROUPE algorithm — Addresses the unobserved progenitor problem through L1-regularized over-parameterization (encoding all candidate potency sets simultaneously), followed by potency extraction, debiased refitting, and Pareto-front knee detection for model selection. Scales to 15+ cell types without enumerating all $2^{ S }$ potency sets.

Method Overview

Algorithmic Framework

TROUPE fits a multi-type Yule (pure-birth) branching process with potency-constrained rate matrix $Q$ and per-type birth rates $\boldsymbol{\lambda}$. The likelihood is the standard BiSSE/MuSSE likelihood (with zero death rate) computed via Felsenstein’s pruning on the leaf-labeled lineage trees.

Two-phase inference pipeline:

  1. Phase 1: Overparameterize — include all biologically plausible progenitor potency sets (induced from tree clades) as candidate hidden states. Optimize the log-likelihood with L1 regularization over a grid of regularization strengths $\gamma$. Different $\gamma$ values encourage solutions with different numbers of active (non-zero-outgoing-rate) progenitors.

  2. Phase 2: Debias — extract the reachable state space from each Phase 1 solution (via long-run matrix exponentiation), construct the reduced rate matrix, and re-fit without regularization (using Phase 1 as warm start). This corrects the systematic underestimation of rates introduced by L1 shrinkage.

  3. Model selection: Build the Pareto front of (number of progenitors, negative log-likelihood) across all regularization values. Apply the Kneedle algorithm to find the elbow — the model where adding more progenitors yields diminishing likelihood gain.

Key Technical Components

  • Potency constraint mask: Binary mask on Q enforces $Q_{\alpha\beta} = 0$ unless $\text{potency}(\beta) \subseteq \text{potency}(\alpha)$. Structurally encoded in RateMatrixBuilder — forbidden transitions are permanently zero and excluded from gradient computation.
  • Batched log-space Felsenstein pruning: Nodes grouped by tree depth level for parallel matrix operations. Uses torch.matrix_exp and logsumexp for numerical stability.
  • Clade-based potency set generation: Avoids the intractable full power set enumeration by inducing candidate progenitors from actual tree topologies (biologically observed clades plus complements).
  • Float64 throughout: Required for numerical stability of matrix exponentials across multiple orders of magnitude in rate values.

Biological Assumptions

  • Time-homogeneous rates (constant Q and λ throughout the experiment).
  • Zero death rate (reasonable approximation for short developmental windows).
  • Complete sampling of surviving cells at observation time (leaves = all cells alive at $t$).
  • Lineage trees are ultrametric (branch lengths = actual time) with known absolute time scale.
  • The process starts from a single most-potent progenitor type.

See doc_method.md for full mathematical derivation and doc_code.md for code-paper mapping.

Evaluation

Datasets

Simulation (Section 4.1):

  • Ground-truth differentiation map with 4 terminal types and 4 progenitor types (Fig. 2a)
  • $N \in {16, 32, 64, 128, 256}$ independent trees, 5 trials each; cutoff time 2.35
  • Compared methods (all given ground-truth number of progenitors except TROUPE and Carta): SSE, EvoC, Carta

TLS real data (Section 4.2):

  • Trunk-Like Structures (TLS): 12 cell lineage trees, 2521 cells, 6 cell types (Endoderm, Endothelial, PGCLCs, Somite, Neural Tube, NMP); trees reconstructed with LAML from Bolondi et al. (Developmental Cell, 2024)
  • TLS^CL (perturbed with WNT agonist + BMP inhibitor): 11 trees, 3165 cells, 5 cell types (no endothelial)

Metrics

  • Jaccard distance between inferred and ground-truth progenitor sets (lower = better)
  • Absolute error in transition and growth rate parameter values
  • Proportion of correct progenitor count identification (model selection accuracy)

Results

Simulation:

  • TROUPE achieves Jaccard distance 0 at $N=32$ trees vs. EvoC at $N=64$ and Carta at $N=128$ — demonstrating ~2-4× better sample efficiency.
  • At $N=256$: TROUPE mean transition rate error = 4.3 vs. SSE = 58.0 (13.5× lower); growth rate error = 1.2 vs. SSE = 6.51.
  • Model selection: TROUPE achieves 100% accuracy at $N \geq 128$ vs. Carta ≤ 60% across all $N$.
  • Simulation confirms theoretical result: mean of 0-1.8 progenitors observed among leaves even for $N=512$ trees.

TLS application:

  • TROUPE infers 5 progenitor types in a differentiation map consistent with known TLS biology (PGCLCs commit first with highest progenitor potency; NMPs are bipotent for somite/neural tube).
  • NMP differentiation rates: nearly symmetric in normal TLS (1.5 to Somite, 1.6 to Neural Tube).
  • In TLS^CL (perturbed): NMP growth rate increased (2.2 vs. 1.9) and asymmetric differentiation bias toward somites (0.87 vs. 0.44), consistent with morphological phenotype of somite overgrowth.
  • Expected cell type proportions at 120h closely match observed proportions, providing quantitative validation.
  • SSE (without potency constraints) produces nonsensical results (nonzero rates between known terminal types).
  • Carta produces similar topology to TROUPE but cannot infer rates or self-renewal, and treats NMPs as multiple proxies rather than a true bipotent progenitor.

Reproducibility

Rating: 4/5

Strengths:

  • Clean, well-structured PyTorch codebase with comprehensive tests (12 test modules, 1949 lines).
  • Unified pipeline script (run_troupe.py) handles the full 2-phase inference end-to-end with clear CLI arguments.
  • Example data provided (example/trees.pkl, example/ground_truth_parameters.json).
  • Real TLS data included in repository (experiments/TLS/trees.pkl, experiments/TLSC/trees.pkl).
  • All randomness seeds are explicit; float64 enforced globally; numerical stability carefully managed.
  • Experiment shell scripts provided for all paper figures (TLS, TedSim, sample efficiency, varied growth rates).

Limitations:

  • No Jupyter notebooks — all analysis is via scripts, requiring some setup effort.
  • Several key parameters not reported in paper (Kneedle S=0.5, debiasing L1=0.0001, reachability threshold=1e-5).
  • The clade-based potency set construction (a major practical innovation) is entirely undocumented in the paper.
  • TedSim benchmark data requires running separate simulation scripts; not pre-included.
  • No pre-computed result files for the paper figures — must re-run experiments from scratch.
  • ClaSSE variant (run_classe_troupe.py) requires torchode which is not in requirements.txt.

Common pitfalls:

  • Trees must be ultrametric (branch lengths = actual time). Non-ultrametric trees will produce incorrect likelihood values with no error.
  • The --observed_potencies file must explicitly encode known biological constraints (e.g., NMPs are bipotent for Somite and Neural Tube). Without this, the algorithm may find a locally-optimal but biologically incorrect potency assignment.
  • float64 is essential; switching to float32 causes NaNs during matrix exponentiation for deep trees.
  • LBFGS can fail for very small datasets (<16 trees) where the likelihood surface is flat — try increasing L1 regularization or providing observed potencies as constraints.
