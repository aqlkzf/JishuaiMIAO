SpaMV 方法解释：把空间多组学拆成共享信号与模态私有信号

一句话概括

SpaMV 不把多个空间组学层强行压进一个共同嵌入，而是假设每个模态都由“跨模态共享状态”与“该模态私有状态”共同生成；它用每个模态各自的共享/私有 GAT 编码器、自重建和交叉重建、跨模态 measurement model，以及第二阶段 HSIC 独立性约束，尽量把两类信息分开，并提供空间域聚类和可解释 topic 两种输出模式。

1. SpaMV 要解决的核心问题

同一组织位置可能同时测到 RNA、染色质、蛋白或代谢物。它们观察的是同一细胞状态，却不应被假定为完全同分布。例如染色质可及性可能预示未来转录，但此刻没有对应 RNA；蛋白量也可能因翻译后调控而偏离编码基因表达。

只学习一个共享空间会保留各模态一致的结构，却可能丢掉这种真正有意义的差异。SpaMV 的多视图假设是：第 $i$ 个模态 $x_i$ 同时受共享潜变量 $z_s$ 和私有潜变量 $z_{pi}$ 影响：

\[p(X,z_s,z_p)=p(z_s)\prod_{i=1}^{m}p(x_i\mid z_s,z_{pi})p(z_{pi}).\]

共享部分表达不同组学都支持的组织或细胞状态；私有部分表达只在某一组学中可见的信号。图 1a 用重叠但不相同的两个模态特征空间展示这一假设。

2. 输入、输出和对齐前提

输入是一组已经按空间 spot/cell 对齐的 AnnData：每个模态拥有同样的观测位置，但特征维度和观测分布可以不同。代码 SpaMV/spamv.py:111-220 会检查模态数量、特征维数、共享/私有维数和重建分布，并为每个模态创建 PyTorch Geometric 图。

输出有两类：

  • domain clustering 模式输出归一化潜在嵌入，供 PCA/mclust 或其他聚类器使用；
  • interpretable topic 模式输出 spot×topic 权重，以及每个模态的 feature×topic 权重，topic 名显式分为 shared 与各模态 private。

“共享”和“私有”是模型在给定损失与先验下学习的统计分解，不等于已经由实验验证的生物学机制。一个 topic 被标为私有，含义是它相对更难由另一模态解释，而不是对应分子通路绝对只存在于该模态。

3. 空间与特征如何进入编码器

每个模态都构建一个 mixed neighboring graph：两个 spot 只要在空间图中相邻，或在该模态的特征空间 kNN 中接近，就建立边。论文默认 GAT 有两层、特征 kNN 的 $k=10$；代码入口 SpaMV/utils.py:65 的 adjacent_matrix_preprocessing 联合空间连接与特征近邻，SpaMV/layers.py:5-18 的 GATEncoder 用两层 GATv2Conv 产生潜变量均值和正尺度。

这个设计使表示同时利用局部组织结构和可能跨空间区域的分子相似性。边界是：图的邻域参数会直接改变模型看到的依赖；空间近邻也只表示几何接近，不自动等于细胞间作用。

4. 每个模态有两套编码器

对模态 $i$，SpaMV 使用：

\[q_{\phi_{si}}(z_s\mid x_i),\qquad q_{\phi_{pi}}(z_{pi}\mid x_i).\]

前者应抽取共享信息，后者应抽取该模态私有信息。代码 SpaMV/model.py:41-69 为每个 omics name 动态注册 shared/private encoder；model.py:189-220 的 guide 用它们参数化正态后验。

多个模态得到的共享后验以 mixture-of-experts 思路整合。最终 model.py:222-231 对各模态 shared posterior mean 求平均；这正是 get_embedding() 返回的 shared 部分来源。

仅仅设置两套编码器不能保证它们自动分工。SpaMV 真正的关键在于四组训练约束：自模态重建、交叉模态重建、measurement model 和 HSIC。

5. 自模态与交叉模态重建分别逼迫什么

5.1 自模态重建

对模态 $j$，使用同一模态推断的 $(z_s,z_{pj})$ 重建 $x_j$。为避免共享编码器把所有信息吞掉，论文在这一分支对 $z_s$ 使用 stop-gradient：

\[\mathcal L_{\mathrm{self}}^{j\prime} =-\mathbb E_{\mathrm{sg}(q_{\phi_{sj}})} [\log p_{\theta_j}(x_j\mid z_s,z_{pj})].\]

代码 SpaMV/model.py:155-171 在 self reconstruction 时对 shared sample 执行 .detach()，使私有表示承担该模态独有的重建信息。

5.2 交叉模态重建

用模态 $j$ 推断的 shared 表示去重建另一模态 $i$。该分支不能借用目标模态真实的 private posterior，而以标准正态辅助变量 $r_i$ 替代：

\[\mathcal L_{\mathrm{cross}}^{j,i\prime} =-\mathbb E_{q_{\phi_{sj}}} [\log p_{\theta_i}(x_i\mid z_s,r_i)].\]

如果 shared 表示漏掉跨模态共同结构，就无法完成交叉重建。model.py:155-185 的双重循环为每个来源—目标模态组合创建相应 Pyro observation site，并在交叉路径拼接随机 private auxiliary sample。

两者配合形成方向性压力：self 分支逼 private 保留专属信息，cross 分支逼 shared 保留可跨模态转移的信息。

6. measurement model 如何阻止 shared 信息泄漏到 private

对每个 $z_{pi}$，SpaMV 训练小型 MLP $M_i^j$ 去预测另一模态 $x_j$：

\[\mathcal L_{\mathrm{measure}}^{i,j} =\mathrm{MSE}(M_i^j(z_{pi}),x_j).\]

如果 private 表示仍含共享信息，measurement model 就能随输入变化并预测另一模态。SpaMV 先把 measurement model 训练成尽可能好的探针，再在主模型目标中最小化其输出方差：

\[\mathcal L_{\mathrm{unique}}^i =\sum_{j\ne i}\mathrm{Var}(M_i^j(z_{pi})).\]

当输出接近常数时，作者把它解释为 private 对其他模态不再含可用信息。代码 SpaMV/layers.py:52-82 定义跨模态 MLP，spamv.py:237-269 在达到预训练 epoch 后周期性重置并训练这些探针，spamv.py:328-359 把输出标准差项加入主目标。

这是代理约束，不是互信息为零的直接证明。measurement model 容量不足或训练未收敛时，输出不变也可能只是探针太弱；因此代码每 100 epoch 重置并集中训练 100 次，以降低局部最优风险。

7. HSIC 如何阻止 private 信息泄漏到 shared

在 topic 模式第二阶段，SpaMV 冻结 private 相关参数，只更新 shared 编码器和解码器，并最小化 shared 与 private 表示间的 Hilbert–Schmidt independence criterion：

\[\mathrm{HSIC}(Z_s,Z_p)=\frac{1}{(N-1)^2}\mathrm{tr}(KHLH).\]

$K,L$ 是两类潜变量的 Gaussian kernel matrix，$H$ 是中心化矩阵。代码 spamv.py:320-326 实现该公式，spamv.py:362-385 在 shared ELBO 中对每个 shared/private 组合加入 HSIC。

代码 spamv.py:270-299 只在 interpretable=True 时运行第二阶段，并通过参数名过滤掉 private ('zp') 参数。这与论文“HSIC 第二阶段只用于 topic modeling”的边界一致；domain clustering 模式并没有同样的第二阶段独立性清理。

8. 两种 decoder 对应两种用途

8.1 Domain clustering

该模式使用两层 MLP decoder 和 Gaussian likelihood，目标是获得灵活嵌入用于空间域聚类。SpaMV/layers.py:21-38 实现 decoder，默认 shared/private 维数各为 32、hidden size 256、学习率 $10^{-3}$。

8.2 Interpretable topic modeling

topic 模式把每一潜在维度解释为一个 topic，并采用 Gamma–Poisson/负二项式式计数模型：

\[\mu_i^f=l_i\,\mathrm{softmax}([z_s,z_{pi}])^T \mathrm{softmax}(\beta_i),\]

其中 $l_i$ 是 spot library size，$\beta_i^{f,j}$ 是特征 $f$ 对 topic $j$ 的贡献。SpaMV/model.py:120-185 在 interpretable 分支用 library size、softmax topic 和 feature weight 重建计数，并根据配置使用 NB 或 ZINB。

代码为 feature-topic 权重加入 regularized horseshoe prior：局部与全局 Half-Cauchy 尺度鼓励大多数权重收缩，同时允许少数强关联逃离收缩。model.py:120-137 对 $c,\delta,\tau,\lambda,\beta$ 建立 Pyro 先验，model.py:281-300 导出 feature×topic 权重。

默认 topic 模式 shared/private 维数各为 10、hidden size 128、学习率 $10^{-2}$。维数是候选 topic 上限，训练后还会做空间性和背景过滤。

9. topic 后处理

SpaMV 对每个潜在维度计算 Moran’s I。若最低值低于默认阈值 0.3，则以 KMeans 将维度分成高/低空间自相关两组，删除低组；随后删除指数化 topic 权重标准差不超过默认 1 的背景维度。spamv.py:301-318 是直接实现。

get_embedding_and_feature_by_topic() 还可基于各模态 top-feature 排名的 RBO 相似度合并冗余 topic（默认阈值 0.4，spamv.py:438-520）。因此最终 topic 数可能少于初始化的潜在维数，且会受阈值影响。

10. 训练流程如何落到代码

代码的 active path 与论文 Algorithm 1 基本对应：

  1. 建图并初始化 Pyro model/guide；
  2. 第一阶段优化变分 ELBO；
  3. 达到 measurement start epoch 后，交替训练跨模态 measurement models，并把其输出方差惩罚加回主模型；
  4. topic 模式进入第二阶段，只优化非-private 参数并加入 HSIC；
  5. 计算 meaningful dimensions，并导出 shared/private topic 与 feature 权重。

值得注意的是代码默认 pretrain_epoch = 200 if interpretable else 10（spamv.py:191），而论文方法段写的是 domain clustering 200、topic modeling 10。这里命名/条件与论文文字相反：代码的 interpretable/topic 模式为 200，非 interpretable/clustering 为 10。中文解释保留这个直接实现差异，不把两者强行视为一致。

13. 结果边界与局限

SpaMV 的模拟实验最能支持“分解共享/私有因子”的机制，因为真值已知。真实数据中的 topic 解释则依赖空间一致性、feature correlation、marker、通路与原始注释，属于多种证据共同支持的解释，不是直接观察到潜变量真值。

论文限制段指出当前分析聚焦两个模态；当有三个以上模态时，还可能出现“只在某一模态子集共享”的层级，简单的全局 shared + 每模态 private 不足以表达。代码循环在形式上能接收多个 AnnData，但这不等于论文已经验证多模态子集共享结构。

此外，topic 可解释性依赖 decoder 线性分解、softmax、horseshoe prior 和后处理阈值；改变这些设置可能改变 topic 数和 top feature。候选基因仍需外部功能或实验验证。

SpaMV: Interpretable Spatial Multi-omics Data Integration and Dimension Reduction

Paper Overview

Title: Interpretable spatial multi-omics data integration and dimension reduction with SpaMV Authors: Yang Liu, Kexin Ma, Haoran Xu, et al. Affiliations: Hong Kong Baptist University, Sichuan University, Vanderbilt University, City University of Hong Kong, Chinese University of Hong Kong Posted: September 10th, 2025 (Preprint) DOI: https://doi.org/10.21203/rs.3.rs-7396454/v1

Keywords: Spatial multi-omics data, disentangled representation, interpretable topic modeling, multi-view learning

1. Biological Problem and Motivation

Current Limitations

“Existing spatial multi-omics integration methods often assume that data from different modalities share a common underlying distribution, aiming to project them into a single unified latent space. This assumption, however, can obscure the unique insights offered by each modality, thereby limiting the full potential of multi-omics analyses.” (Abstract, lines 22-26)

“Existing spatial multi-omics integration algorithms typically project multi-modal data into a shared latent space, which can result in the loss of modality-specific information when the data across modalities do not fully overlap. For example, chromatin accessibility peaks may be primed for future transcriptional activation without corresponding gene expression.” (page 4, lines 61-65)

Key Insight

The paper argues that modality-specific signals, unique to certain omics layers, are critical for understanding complex biological processes. Losing these signals can compromise the accuracy of downstream analyses such as cellular state characterization.

2. Core Innovation: Multi-View Assumption

SpaMV adopts a multi-view assumption for multi-modality data:

“SpaMV adopts a multi-view assumption for the multi-modality data, positing that each omics modality $x_i$ can be viewed as a different perspective of the same tissue slice, encompassing both cross-modal shared information $z_s$ and modality-specific private information $z_{pi}$.” (page 5, lines 101-104)

Key Differentiator

Unlike previous approaches that project all modalities into a single shared latent space, SpaMV explicitly disentangles:

  • Shared latent variables ($z_s$): Information common across all modalities
  • Private latent variables ($z_{pi}$): Modality-specific information unique to each omics

3. Technical Architecture

3.1 Three Key Components

SpaMV incorporates three key components to achieve robust decomposability:

  1. Dual-encoder architecture: Each omics modality employs separate Graph Attention Network (GAT) encoders to capture spatially informed shared and private signals, coupled with modality-specific decoders for faithful reconstruction.

  2. Auxiliary measurement models: Utilized to minimize mutual information between inferred private latent variables from one modality and data from other modalities, preventing leakage of shared information into private latent spaces.

  3. Non-parametric independence test (HSIC): Enforces statistical independence between shared and private latent variables, avoiding contamination of shared space by modality-specific signals.

3.2 Model Formulation

The generative model for spatial multi-omics data $X = {x_i}_{i=1}^m$ has the form: \(p(X, z_s, z_p) = p(z_s) \prod_{i=1}^m p(x_i \mid z_s, z_{pi}) p(z_{pi})\)

The Evidence Lower Bound (ELBO) with modifications:

\[\mathcal{L} = -\frac{1}{m} \sum_{j=1}^{m} \left( w_j \mathbb{E}_{\text{sg}(q_{\phi_{sj}}(z_s|x_j))} \left[ \log p_{\theta_j}(x_j \mid z_s, z_{pj}) \right] + \sum_{i \neq j} \left( w_i \mathbb{E}_{q_{\phi_{sj}}(z_s|x_j)} \left[ \log p_{\theta_i}(x_i \mid z_s, r_i) \right] + \alpha_i \text{Var}(M_i^j(z_{pi})) \right) \right) + D_{KL}(\cdot)\]

where:

  • $w_i$: Reconstruction loss weights for different modalities
  • $\alpha_i$: Strength of uniqueness constraint on private latent variables
  • $\text{sg}(\cdot)$: Stop gradient operation
  • $M_i^j$: Measurement model from modality $i$ to modality $j$

3.3 Encoders and Decoders

Encoders: Graph Attention Networks (GAT) with 2 layers

  • Mixed neighboring graph combining spatial proximity and feature similarity
  • Shared encoder: $q_{\phi_{si}}(z_s \mid x_i)$
  • Private encoder: $q_{\phi_{pi}}(z_{pi} \mid x_i)$

Decoders (two modes):

  1. Domain Clustering Mode: MLP-based decoder with Gaussian likelihood \(p_{\theta_i}(x_i \mid z_s, z_{pi}) = \mathcal{N}(D_i(z_s, z_{pi}), \sigma_i)\)

  2. Topic Modeling Mode: Matrix multiplication decoder with Gamma-Poisson (NB) distribution \(\mu_i^f = l_i \cdot \text{softmax}([z_s, z_{pi}])^T \cdot \text{softmax}(\beta_i)\)

The feature embedding matrix $\beta_i$ uses a horseshoe prior for sparsity: \(p(\beta_i^{f,j}) = \mathcal{N}(r_f, \frac{c^2\delta_f^2\tau_j^2\lambda_{f,j}^2}{c^2 + \delta_f^2\tau_j^2\lambda_{f,j}^2})\)

3.4 HSIC Independence Constraint

To prevent private information leakage into shared latent variables: \(\mathcal{L}_{\text{HSIC}}^{i,j} = \frac{1}{(N-1)^2} \text{trace}(K_i H L_j H)\)

where $K_i, L_j$ are Gaussian kernel matrices and $H$ is a centering matrix.

4. Two Operational Modes

4.1 Domain Clustering Mode

  • Uses MLP decoders
  • Concatenates shared and private representations for clustering
  • Applies mclust algorithm on PCA-reduced embeddings

4.2 Topic Modeling Mode (Interpretable Dimension Reduction)

  • Uses matrix multiplication decoder
  • Each dimension of $[z_s, z_{pi}]$ corresponds to an interpretable biological topic
  • Each column of $\beta_i$ quantifies feature contributions to topics
  • Incorporates post-processing to prune noisy/background topics using Moran’s I z-score

5. Benchmark Results

5.1 Simulated Data

“SpaMV was the only algorithm capable of identifying all factors. Other algorithms, such as SpatialGlue, CellCharter, and SMOPCA, successfully identified all factors present in the Omics 2 dataset but failed to recover the omics 1 private factor, implying a bias towards the omics 2 modality.” (page 6, lines 155-158)

6. Key Biological Discoveries

Mouse Embryo (Transcriptome-Epigenome)

  • Shared topics: Lateral ventricle, central nervous system
  • Transcriptome-private: Hindbrain, thalamus, trigeminal ganglion
  • Epigenome-private: Wall of diencephalon, eye regions
  • Top genes validated: Mt3, Gpr98, Celsr1, Nr2e1 (brain development)

Mouse Embryo (H3K27ac-H3K27me3)

  • Identified 33 genes showing differential expression across histone modifications
  • Novel candidate genes: Gpr3711 (nervous system), Csrp3 (muscle), Hoxb8 (spinal sensory)

Mouse Thymus

  • Proteome-private topic characterized by B cell markers (CD45R, IgG2a, CD19, CD90-2)
  • Low correlation between top-ranking proteins and their coding genes in private topic
  • Enabled accurate cell type annotation (B cells, pDCs, macrophages) where traditional DEG-based methods failed

8. Limitations

“One current limitation of SpaMV is that it only considers scenarios with two modalities. When more modalities are present, information may be shared across subsets of modalities, increasing the complexity of the analysis.” (page 17, lines 400-402)

Future directions:

  • Extension to multiple modalities (>2)
  • Integration of H&E histology images
  • Single-cell multi-omics integration for automated cell-type annotation

10. Summary

SpaMV represents a significant advance in spatial multi-omics integration by:

  1. Explicitly disentangling shared and modality-specific information
  2. Providing interpretable outputs through topic modeling
  3. Achieving superior clustering performance across diverse omics combinations
  4. Enabling accurate cell type annotation by leveraging modality-specific topics

The method’s ability to preserve both shared and private information makes it particularly valuable for understanding complex biological systems where different molecular layers provide complementary insights.
