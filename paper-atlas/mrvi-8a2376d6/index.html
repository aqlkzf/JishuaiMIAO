MrVI：在单细胞分辨率上理解样本间异质性

先抓住论文的核心问题

多样本单细胞研究通常先把细胞聚类，再比较各簇的比例或平均表达。这种流程隐含了一个强假设：真正的疾病、个体或药物效应恰好与预先划定的细胞簇一致。若效应只发生在某个连续状态区域、某个簇中的少数细胞，或不同细胞亚群给出不同的样本分组，先聚类再汇总就会稀释信号。

MrVI（multi-resolution variational inference）把问题改写为：对每个细胞状态，如果把样本身份替换成另一个样本，它的表示和表达会怎样变化？ 这种 counterfactual inference 让同一个细胞位置可以从所有样本的视角被重新计算，由此同时支持：

  • exploratory analysis：哪些细胞状态会给出哪些样本分层；
  • differential expression（DE）：样本属性在每个细胞状态上改变哪些基因；
  • differential abundance（DA）：哪些细胞状态在样本组间富集或缺失。

1. 输入、协变量与输出

对细胞 $n$，模型输入包括：

  • 原始基因计数 $\mathbf x_n\in\mathbb N^G$；
  • target/sample covariate $s_n$，通常是 donor、病人或 perturbation ID；
  • nuisance covariate $b_n$，例如测序批次、建库平台或研究来源；
  • 可选细胞类型标签，用于给 $u$ 的 mixture prior 提供监督。

输出不是单一 embedding，而是两层潜变量及其后训练统计量：

  • $u_n$：希望保留跨样本共享的细胞类型/状态结构；
  • $z_n$：在 $u_n$ 基础上加入目标样本效应，但把 nuisance effect 留给解码器处理；
  • 每细胞的 sample-by-sample distance matrix；
  • 每细胞的 DE effect size、gene-level LFC 和 DA log density ratio。

Figure 1 的关键不是“两个普通 latent space”，而是职责分离：$u$ 提供一个可比较的细胞状态坐标系，$z$ 表达同一状态在具体样本中的偏移。

2. 分层生成模型

论文将生成过程写为

\[u_n\sim p(u),\qquad z_n=g_\theta^{u\to z}(u_n,s_n),\] \[h_n=g_\theta^{z\to h}(z_n,b_n),\qquad x_{ng}\sim\mathrm{NB}(l_n h_{ng},r_{ng}),\]

其中 $l_n$ 是细胞总计数，$h_n$ 是归一化基因比例，$r_{ng}$ 是 inverse dispersion。核心包中的 _module.py:308-343 直接体现这条路径：先从 q(u|x,sample) 取样或取均值，再把 counterfactual sample index 送入 qz，得到 z_base + eps；_module.py:363-386 再以 $z$、batch 和 library size 生成 negative-binomial 分布。

为什么 $u$ 使用 mixture-of-Gaussians prior

单细胞数据包含多个离散/连续状态，单峰标准正态先验可能过度压缩多群结构。MrVI 默认使用 $K=20$ 的 Gaussian mixture prior；若有 cell-type labels，代码在相应 mixture component 的 categorical logits 上加入 10 的 offset。Extended Data 和补充消融显示 mixture prior、cell-type supervision 与 cross-attention 会影响 integration 和 downstream 结果，但论文并未声称所有数据集都必须依赖标签。

cross-attention 在哪里起作用

$u\to z$ 模块把 $u$ 当 query、learned sample embedding 当 key/value，使样本效应依赖于细胞状态；$z\to h$ 解码器以 batch embedding 表示 nuisance factor。它与简单“给每个样本加一个固定向量”不同：同一 sample embedding 对不同 $u$ 可以产生不同偏移。

本地实现还给出必须保留的边界：论文描述 ReLU，而 AttentionBlock 默认路径使用 GELU；u encoder 也通过 ConditionalNormalization 使用 sample ID，因此“sample-unaware”是训练目标和表示性质，不是编码器从未看到 sample identity 的结构性保证。

3. 训练目标

模型用变分后验 $q_\phi(u_n\mid x_n,s_n)$ 近似 $u_n$，优化重构项与潜变量正则项。代码中的实际 per-cell loss 是

\[\mathcal L_n= -\log p_\theta(x_n\mid z_n,b_n) +\mathrm{KL/MC}\bigl(q_\phi(u_n\mid x_n),p(u_n)\bigr) -\log p(\epsilon_n),\]

其中 $\epsilon_n=z_n-z_{\mathrm{base},n}$。_module.py:388-442 计算 NB reconstruction、$u$ prior 项与 eps 的 Normal prior penalty；当使用 mixture prior 时，$u$ 项用 sampled q.log_prob(u)-p.log_prob(u)，不是解析 Gaussian-to-mixture KL。

论文把最后一项解释为限制 $z$ 不要无约束偏离 $u$ 的平方距离。代码写成 Normal negative log probability；在固定单位 scale 下与平方惩罚只差比例和常数，但若 scale 可学习，就不能简单等同为裸 MSE。

4. 反事实表示是所有分析的共同接口

对一个观测细胞，先得到共享状态 $u_n$。随后把 sample ID 依次替换为每个候选 $s’$：

\[z_n^{s'}=g_\theta^{u\to z}(u_n,s').\]

这里不是生成一个全新细胞，而是固定当前 $u_n$，只改变“它来自哪个样本”这一条件。合理性依赖 overlap：若某个细胞状态在候选样本中没有支持，counterfactual 会外推。因此 MrVI 另做 admissibility/OOD 判断，而不是默认所有 cell–sample pair 都可信。

完整数据流可以写成：

raw counts x + sample s + nuisance batch b
        │
        ▼
qφ(u | x,s) → shared cell-state latent u
        │
        ├── observed s  → z → decoder(z,b) → NB gene likelihood
        │
        └── enumerate every s' → counterfactual z^(s')
                                  │
                  ┌───────────────┼────────────────┐
                  ▼               ▼                ▼
             local distances     DE regression     decoded gene LFC

u posterior across samples ───────────────────────→ DA density ratio

5. 探索性分析：每个细胞一张样本距离矩阵

对细胞 $n$ 和样本对 $(a,b)$，定义

\[D_n[a,b]=\left\|z_n^{s_a}-z_n^{s_b}\right\|_2.\]

如果某个细胞状态对疾病非常敏感，病例与对照的 counterfactual 表示在该处距离大；若另一个状态不受影响，它给出的距离矩阵可能近乎无结构。实际分析把每个 $D_n$ 的上三角展开，对细胞做 PCA/Leiden，获得“共享相似样本分层”的细胞群；再在群内平均距离矩阵并对样本层次聚类。

Figure 2 的 semi-synthetic 数据清楚展示这一点：只有 subset A 被植入 DE，subset A 的距离矩阵恢复了模拟 hierarchy，而无该效应的 subset B 距离很小。Figure 3 中，monocyte/DC 和 T/NK 产生不同病人分层；DSS 相关的 COVID 子分组主要在 myeloid distance matrix 中显现。Figure 4 的 A549 cell-line 数据更均一，因此论文改用全细胞平均距离矩阵比较药物。

6. Differential abundance：在 $u$ 空间比较密度

对每个样本 $s$，模型用该样本细胞的 variational posteriors 构成 aggregated posterior $q_s(u)$。两个样本组 $A,B$ 的局部 DA 分数为

\[r_{AB}(u)=\log q_A(u)-\log q_B(u).\]

正值表示状态 $u$ 在 $A$ 中更富集，负值表示在 $B$ 中更富集。核心代码 _model.py:771-930 先得到每个 sample 对各细胞的 log probability，再通过 logsumexp - log(number of samples) 聚合组内样本，最后做组间差。它是 posterior-density comparison，不是先聚类再数细胞。

Figure 2e 的真实图给出 semi-synthetic DA PR-AUC：MrVI 0.93，Milo 0.74。Figure 3e 显示 COVID/healthy 与 high/low DSS 的 myeloid abundance shifts；Figure 5c 显示 Crohn’s B2/B1 在 stromal states 中的局部 abundance difference。

7. Differential expression：先在潜空间估计效应，再解码到基因

论文用 sample-level design vector $c^{s’}$ 对每个细胞的 counterfactual latent state 建线性模型：

\[z_n^{s'}=c^{s'\top}\beta_n+u_n.\]

$|\beta_n|^2$ 表示该 covariate 对细胞 $n$ 的总体表达效应。随后把效应状态与 baseline state 送入 decoder，得到每基因的 log fold change。

直接代码揭示了更精确的实现：_model.py:1161-1218 对所有样本产生的是 eps=z-z_base，先在 sample axis 上中心化/标准化，再用 admissibility-weighted least squares 求 betas；统计量用经 $X^TMX$ 缩放后的系数平方和，并以 chi-squared CDF 得 p value。_model.py:1223-1288 再把 effect/no-effect latent 输入 decoder，计算 gene-wise log2 fold change，并跨 nuisance batches 加权平均。

因此，“论文回归 $z$”与“代码回归标准化 $eps$”应记为 Partial，而不是抹平。两者都意在隔离 sample-specific displacement，但系数尺度和数值流程不同。

8. admissibility：避免不受支持的反事实

候选 sample 若在当前 $u$ 附近没有相似细胞，就不应信任该反事实。代码 _model.py:932-1010 为每个 sample 构造 aggregated posterior，用本样本细胞 log probability 的 5% 分位数作为基准，再判断其他 cell–sample pair 是否超过阈值。DE 可选择只用 admissible samples，通过对角 mask 进入 weighted least squares。

这与论文中用最大 posterior density 描述的 admissibility score 并非逐字相同，所以是 Partial 实现边界；但二者目标一致：避免在没有局部数据支持的区域解释 counterfactual effect。

9. 图和补充证据如何支持结论

Figure 1–2：机制与可识别性

Figure 1 把 $u/z$、local stratification、DA 和 DE 放在同一图中。Figure 2 的 semi-synthetic truth 将 DE 放在 subset A、DA 放在 B/C、其余为 null，因而能分别检查三个输出，而不是只展示漂亮 embedding。真实图中 DA AUC 为 0.93 对 0.74；DE 与 DESeq2 reference 的 Pearson $r$ 为 0.52 对 miloDE 的 0.09。

Figure 3：COVID-19

$u$ 按 immune type 分离且混合 infection status，$z$ 中 disease effect 明显；由局部距离矩阵得到的 myeloid group 提供 DSS 相关分层。DA 和 DE 将该分层落到 CD14/CD16 composition 与 interferon/inflammatory gene modules。这里是“某个细胞子集给出特定样本分层”的核心实例。

Figure 4：sci-Plex

$u$ 主要反映 cell cycle，$z$ 显示 drug/pathway effect。MrVI 距离在 intra-drug percentile 和 Connectivity Map silhouette 上优于 compositional PCA/scVI baselines；clustered distance matrix 组织出 HDAC inhibitor、trametinib 以及部分非平凡 drug relationships。Supplementary Figures 5–19 展示超参数选择、不同 cell line、距离矩阵、cluster LFC/GSEA 和稳健性，说明结果不是只依赖一个主图面板。

Figure 5：Crohn’s disease

全数据中 B2 stenosis effect 聚焦到小型 pericyte/stromal 区域。细分后，DA、raw expression 和 cell-level LFC 指向特定 pericyte 与 endothelial/fibroblast states。Supplementary Figures 20–24 与 Extended Data Figures 6–7 补充 cell-type prior、细分标记、raw expression 和不同超参数/模型比较。论文的价值不是宣布所有 stenosis 标记都由 MrVI 首次发现，而是把总体样本属性定位到连续细胞状态及其基因效应。

10. 论文与代码的 Exact / Partial / Not found 边界

Exact 或高度一致

  • raw counts → log1p encoder → variational $u$；
  • learned sample embedding 和 cross-attention 产生 sample-aware displacement；
  • nuisance-conditioned NB decoder 与 library size；
  • counterfactual sample substitution；
  • per-cell local sample distances；
  • mixture prior、label offset、KL warmup、gradient clipping；
  • DA、DE、OOD/admissibility 的公开 API 与完整 reproducibility scripts。

Partial

  • 论文写 ReLU，核心实现默认 GELU；
  • 论文把 $u$ 称 sample-unaware，但 inference encoder 使用 sample-conditioned normalization；
  • 论文 DE 方程写 $z$，实现回归标准化 eps；
  • 论文用较简洁的 density/admissibility 表达，实现使用 aggregated posterior、log-sum-exp 和分位阈值；
  • squared-distance regularizer 在代码中以 Normal prior negative log-probability 实现；
  • deterministic $z$ 是主要默认路径，但代码也支持 stochastic eps。

Not found / 未在本次验证中闭合

  • 本地两个代码目录嵌在 PaperCode 快照中，内部 .git 已移除，因此不能把外层提交 206cc19... 冒充官方 MrVI 或 reproducibility commit；官方 repo commit 在本地证据中 Not found。
  • 本次没有重跑需要大规模原始数据和长训练的所有论文 benchmark；图中结果是论文证据，不是本地复现实验结果。
  • 个别 notebook 依赖外部数据、缓存结果和计算环境，完整 end-to-end rerun 仍需要按 reproducibility README 配置。

11. 最后怎样理解 MrVI

MrVI 不是“更好的聚类器”，也不是简单把 donor embedding 拼到 scVI latent。它建立一个共享 cell-state coordinate $u$，再让每个 sample 在每个 $u$ 位置产生一个条件性位移。这样，样本比较不必先决定细胞簇；不同细胞状态可以支持不同的 sample geometry，且相同 counterfactual 接口同时连接 sample stratification、DE 与 DA。

它最强的地方也是主要风险：结果依赖 counterfactual overlap、sample identity 的建模和潜空间可解释性。admissibility、supplementary ablations、direct code inspection 和明确的 Partial 标签因此不是附属说明，而是正确使用 MrVI 的必要部分。

MrVI: Comprehensive Paper Summary

Motivation & Novelty

The Biological Problem

Large-scale single-cell genomics studies now profile hundreds to thousands of human samples, creating cohorts for clinical research (COVID-19 patients, IBD cases, cancer samples) and pharmaceutical screening (hundreds of drug perturbations). These datasets hold transformative potential — but realizing it requires rethinking analysis. Most current pipelines:

  1. Cluster cells into discrete types, then compare cluster proportions or average expression
  2. Discard within-cluster heterogeneity that may capture the most relevant biology
  3. Force a single clustering resolution for all samples and conditions

The core limitation is that sample-level effects may manifest in only particular subsets of cells, and these subsets may not align with any pre-specified clustering scheme. A COVID-19–specific response in a subset of monocytes will be diluted if those cells are pooled with all monocytes.

Limitations of Existing Approaches

Method Approach Limitation
Compositional (PCA/scVI-based) Cluster cells → compare proportions Requires pre-annotation; misses partial effects
Milo (Dann et al., Nature Biotechnology 2022) k-NN graph neighborhoods → DA Neighborhood-based effects smear cell resolution; no uncertainty
miloDE (Missarova et al., Genome Biology 2024) Milo neighborhoods → local DE Same as Milo; less accurate effect sizes
scVI (Gayoso et al., Nature Biotechnology 2022) VAE with Gaussian prior No counterfactual mechanism; assumes constant sample effects
CPA/CINEMA-OT variants Covariate embeddings in latent Constant effects across all cells; no per-cell heterogeneity

MrVI’s Unique Contributions

  1. Annotation-free DE and DA at single-cell resolution — no need to cluster first
  2. Counterfactual framework: ask “what would this cell look like from sample X?” for any sample X
  3. Per-cell sample distance matrices: each cell produces its own sample-stratification view, enabling automatic identification of which cell subsets “see” which sample effects
  4. Uncertainty-aware: uses variational posterior over $u$ to quantify distance uncertainty (normalized distances)
  5. MoG prior (K=20) replaces unimodal Gaussian → avoids posterior collapse in diverse cell type datasets
  6. Cross-attention architecture (not MLP) to model heterogeneous covariate effects — allows sample embeddings to interact non-linearly with cell state

Method Overview

MrVI is a hierarchical deep generative model. The paper’s frozen standalone implementation is JAX/Flax; the maintained scvi-tools implementation is a later PyTorch port.

Two-level latent hierarchy:

  • $u_n$ (dim=10): sample-unaware cell representation. Trained to capture cell type and state, be batch-corrected, and be independent of which sample a cell came from.
  • $z_n$ (dim=30): sample-aware cell representation. $z_n = u_n + \text{cross-attention}(u_n, e_{s_n})$. Captures sample-specific shifts on top of cell state.

Key architectural choices:

  • Encoder: MLP (2 layers, 128 hidden units) with ConditionalNormalization per sample
  • u→z encoder: cross-attention (u as query, learned sample embedding as key/value), GELU activation
  • Decoder: cross-attention (z as query, learned batch embedding as key/value) → softmax → NB likelihood
  • MoG prior for u (K=20 components, all parameters learned)

Three analysis modes post-training:

  1. Exploratory: For each cell, compute counterfactual $z_n^{s’}$ for all $s’ \in {1,\ldots,S}$ → pairwise distance matrix $D_n$ (S×S). PCA + Leiden clustering of cells by $D_n$ identifies groups of cells with similar sample stratifications. Hierarchical clustering of the average $D_n$ per cluster gives sample dendrograms.

  2. Differential Expression: Fit per-cell linear model $\epsilon_n^{s’} = c^{s’T}\beta_n$ over counterfactual epsilons. Chi-squared test gives p-values per covariate. Decode $\beta_n + u_n$ to get gene-level LFCs.

  3. Differential Abundance: In $u$ space, aggregate per-sample posteriors $q_s(u)$. Compare group-level log probabilities: $r_{AB}(u) = \log q_A(u) - \log q_B(u)$.

Evaluation

Datasets

Dataset Cells Samples Source
PBMC 68K (semi-synthetic) 68,000 32 synthetic 10x Genomics public dataset
COVID-19 PBMC (Haniffa et al., Nature 2021) 418,768 55 individuals Newcastle site only
sci-Plex (Srivatsan et al., Science 2020) 251,088 752 (92 drugs × 4 doses + vehicle) A549, MCF-7, K562 lines
IBD/Crohn’s (Elmentaite et al.) 463,000 71 (46 IBD + 25 controls) Broad Institute SCP1884

Key Results

Semi-synthetic benchmark:

  • Sample stratification: MrVI recovers ground-truth hierarchy in subset A; competitors (PCA-compositional, scVI-compositional) produce noisy hierarchies and introduce spurious distances in null subsets
  • DA (PR-AUC): MrVI outperforms Milo in identifying differentially abundant subsets B/C
  • DE (Pearson’s r vs DESeq2): MrVI $r=0.52$ versus miloDE $r=0.09$ (Fig. 2g)

COVID-19 cohort:

  • MrVI identifies monocyte/DC cluster as the cell subset most stratified by disease status
  • Discovers two COVID-19 subgroups via monocyte-specific distance matrix, correlated with days since symptom onset (DSS) — information NOT provided to the model
  • DA identifies decreased non-classical CD16+ monocytes in COVID-19; DE identifies interferon-response (GBP1, IFITM3, IFI27) upregulation in early infection

sci-Plex:

  • MrVI outperforms composition-based baselines on:
    • Intra-drug distance percentile (lower=better): MrVI lowest vs PCA/scVI-compositional
    • Connectivity Map silhouette score (higher=better): MrVI highest
  • Groups HDAC inhibitors into dose-dependent clusters; identifies non-trivial JQ1 ↔ JAK2 inhibitor similarity

IBD/Crohn’s:

  • Identifies pericyte subset (HIGD1B+STEAP4+) with strongest B2 stenosis effect
  • DA: decreased lymphatic/LTC4S+ endothelial cells, increased ADAMDEC1+ fibroblasts in B2
  • DE: LUM, PDGFRB, TGFBI upregulated uniquely in pericyte subset — validated against raw data (Extended Data Fig 7a)
  • Discovers CD36+ endothelial cells with mixed pericyte/endothelial markers → hints at endothelial-to-mesenchymal transition

Integration Performance

On COVID-19 data: MrVI $u$ space outperforms PCA and scVI on scib integration metrics (mixing samples while preserving biological signal). For IBD: MrVI with cell-type prior outperforms scVI on overall SCIB score.

Reproducibility

Rating: 4/5

Justification: Code is open-source, integrated into scvi-tools, and accompanied by a versioned Nextflow/figure-analysis repository. Data provenance is public for all four experiments. The paper used the now-deprecated standalone JAX/Flax branch; current scvi-tools is a PyTorch port with the same computational contract, not a byte-for-byte reproduction snapshot. Large datasets and cached products were not downloaded, so exact numerical reproduction was not attempted.

Strengths:

  • Standalone mrvi package preserved at github.com/YosefLab/mrvi/tree/paper_reproducibility for exact replication
  • mrvi-reproducibility repo contains all figure scripts with dataset configs
  • Code deposited on Zenodo (DOI: 10.5281/zenodo.14927976)
  • The frozen paper branch uses JAX/Flax; current scvi-tools uses PyTorch and carries MrVI tests
  • Extensive supplementary notes (A and B) document datasets and hyperparameter sensitivity

Practical Setup:

pip install scvi-tools  # current integration
# or for exact paper results:
git clone --branch paper_reproducibility https://github.com/YosefLab/mrvi
pip install -e mrvi/

Known Pitfalls:

  • Memory: counterfactual computation scales as O(N × S × L); 400K cells × 55 samples × 30 latent dims ≈ 66M floats per batch
  • Preprocessing: HVG selection (Seurat v3 flavor) is critical — paper uses 10K genes for COVID-19/IBD, 5K for sci-Plex
  • For datasets with strong batch effects: set batch_key AND labels_key for best integration
  • sci-Plex requires explicit drug filtering before training (retain drugs with ≥ N DE genes in at least one cell line)
  • Default hyperparameters (n_latent=30, n_latent_u=10, K=20) are validated; sensitivity analysis in Supplementary Note B

Weaknesses:

  • Quadratic complexity in number of samples for distance matrix
  • Counterfactual quality depends on sufficient representation of each sample across the u space (OOD filtering required for small/rare samples)
  • Cell-type supervised variant requires reliable annotations to be beneficial
  • No multimodal extension (RNA only)
