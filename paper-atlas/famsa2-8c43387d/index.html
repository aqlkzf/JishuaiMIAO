Fast and accurate multiple-protein-sequence alignment at scale with FAMSA2

Open paper

FAMSA2：让渐进式蛋白多序列比对扩展到百万级序列

核心思路

FAMSA2 不是神经网络，而是高度工程化的渐进式 MSA 算法。输入是一组蛋白 FASTA；输出是插入 gap 后的多序列比对。它仍走经典两阶段：先按两两差异构建 guide tree，再按树的合并顺序把序列逐步合成 profile。创新集中在距离、树构建、profile 动态规划和多层并行，使准确度没有为速度大幅让步。

1. 用 LCS 构造便宜而稳健的差异

对序列 $A,B$，最长公共子序列长度为 $L=LLCS(A,B)$。插入/删除量可写为

\[\operatorname{indel}(A,B)=|A|+|B|-2L.\]

FAMSA2 默认差异是

\[d(A,B)=\frac{\operatorname{indel}(A,B)^{0.75}}{L}.\]

指数 $0.75$ 压缩大 indel 的影响，同时除以 LCS，能把无关污染序列推远。源码 AbstractTreeGenerator.hpp 对应这一公式；LCS 用 bit-parallel 算法并通过 AVX/AVX2/AVX-512 或 ARM NEON 一次处理多个机器字。长度下界还可提前排除不可能改善当前最近距离的比较。

这仍是序列启发式距离，不是进化距离；重复域、低复杂度和极端长度差异可能影响 LCS。它的价值是为 guide tree 提供快速、排序足够好的近似。

2. 两种 guide tree 路线

默认 single-linkage 路线用 Prim MST，避免保存完整 $N\times N$ 距离矩阵，空间近似线性，但时间仍为 $O(N^2)$。源码 MSTPrim.cpp 实现这一生产路径。

超大集合可启用 -medoidtree。算法递归把集合围绕 medoid 划分；当子集降到阈值 $M$ 以下，再生成精确子树，最终连接各子树。近似复杂度为 $O(MN\log N)$。它借鉴 PartTree，但用 CLARANS/PAM 风格 medoid 代替完全随机 seed，以降低输入顺序和随机抽样造成的树不稳定。默认参数在代码中是 100 seeds、sample size 2,000、threshold 2,000、两轮 clustering。

medoid tree 是速度—准确度选择，不是默认必开。论文 extHomFam 中精确 FAMSA2 得到 SP 79.6、TC 61.8、约 15 小时；medoid 版 SP 76.5、TC 58.5、47 分钟。后者仍优于多种快速工具，但不能把两套结果混成一个“FAMSA2 分数”。

3. 沿树做 profile alignment

叶节点先做 sequence–sequence DP，内部节点做 sequence–profile 或 profile–profile DP。评分采用替换矩阵与 affine gap：开 gap 和延长 gap 分开计分，terminal gap 也有独立参数。源码默认 PFASUM43，而旧 FAMSA 默认 MIQS。

profile_seq.cpp/profile.cpp 保存三种状态：匹配/对角 $D$、横向 gap $H$、纵向 gap $V$，回溯生成合并 profile。FAMSA2 还会按序列数重新缩放 gap penalties；因此默认分数并非所有 family size 下固定不变。重复序列默认先去重、完成后恢复，减少无意义计算；-keep_duplicates 可关闭此行为。

4. 并行不只是“多开线程”

FAMSA2 在三层并行：LCS/SIMD 距离、guide-tree 计算、progressive profile 合并。树上互不依赖的 profile pair 可并发；很大的单个 DP 又可拆给多个线程。queues.h 的有界优先队列保证结果按树依赖顺序消费，queues.cpp/profile_par.cpp 根据空闲线程、排队任务和 profile 宽度动态分配资源，避免所有线程被一个小任务占用。

图和扩展数据表明线程扩展受阶段影响：距离阶段通常更易扩展，profile alignment、内存带宽、I/O 和任务粒度会限制线性加速。因此“平均快 400 倍”是指定 32-thread AMD EPYC 9554、具体工具参数和 benchmark 上的结果，不是任意机器的固定倍数。

5. refinement 与输出功能

默认 refine_mode=auto：不超过 1,000 条序列时启用 refinement，最多 100 次；大集合默认跳过以控制成本。动态 partial refinement 只重算受影响区域。-trim_columns 是输出阶段删除低非-gap 比例列，不改变内部优化过程，不能把 trimmed 输出与未 trimmed 结果直接比较。

代码还支持 gzip I/O、guide tree 导入/导出、距离/PID 矩阵、profile–profile alignment。导出的 Newick branch lengths 当前统一为 1，重新导入只恢复拓扑，不保留真实分支长度。

论文证据怎样读

论文用多种互补指标：结构 benchmark 的 SP/TC、AlphaFold cluster 的 LDDT、模拟与真实数据的 phylogenetic signal、酶 active-site entropy。FAMSA2 在大 family 上通常更稳健，但并非每项第一：功能 active-site entropy 中 Muscle5 为 0.12，FAMSA2 为 0.15。ME–ML tree agreement 只是 phylogenetic proxy，论文也明确它不能单独证明树更正确。

污染实验把无关序列混入 homolog family，支持新差异度量的鲁棒性；它仍是构造 benchmark。结构参考只覆盖 family 子集，SP/TC 也会受参考选择影响。可靠结论是 FAMSA2 在多类 benchmark 上提供很强的准确度—规模折中，而不是对所有蛋白 family 都最优。

代码、版本与复现边界

本地代码快照为 refresh-bio/FAMSA 提交 d03b85c3eba5da1f44991404b745ef6ad1235102，核心公式、MST/medoid tree、PFASUM43、gap rescaling、profile DP、队列并行、去重和 trimming 均可直接核对。论文 benchmark 使用 FAMSA2 2.4.1、32 threads；源码构建要求 GCC/G++ 11+，不同 CPU 会选择不同 SIMD 路径。

当前快照没有递归取得全部 submodule 内容，完整构建验证可能失败；生产 aligner 源码存在，不等于论文全部 benchmark 编排、所有输入数据和统计脚本都在仓库。论文的 Zenodo/补充资产仍需另取，巨型 extHomFam/Pfam 测试也需要论文级硬件和时间。三个 supplement 已在本地：补充方法/表格与 reporting materials 可用于核对参数，但不能替代缺失的完整 benchmark runner。

一句话总结

FAMSA2 的关键不是发明新的 MSA 范式，而是把经典渐进式比对的每个瓶颈重新设计：LCS 差异、线性空间 MST、可选 medoid 近似、并行 profile DP、动态 refinement 与流式 I/O，共同把高质量蛋白 MSA 推到百万序列规模。

FAMSA2 Summary

Motivation And Novelty

FAMSA2 addresses a scaling problem in protein multiple-sequence alignment. Protein databases and metagenomic protein families are now large enough that accurate MSA methods can become too slow or memory-intensive, while very fast methods may lose alignment quality on large, divergent, or contaminated families.

The method’s novelty is practical algorithm engineering around progressive MSA. It keeps the guide-tree then profile-alignment structure, but changes several bottleneck points: a longest-common-subsequence dissimilarity with exponent 0.75, a scalable medoid-tree approximation for huge datasets, length-based distance prefiltering, SIMD LCS kernels, two-level profile-alignment parallelism, dynamic refinement support, parallel gzip output, and output-only column trimming.

Compared methods include FAMSA (Scientific Reports, 2016), Clustal Omega (Molecular Systems Biology, 2011), MAFFT (Molecular Biology and Evolution, 2013), Kalign 3 (Bioinformatics, 2019), T-Coffee regressive (Nature Biotechnology, 2019), Muscle5 (Nature Communications, 2022), MAGUS (Bioinformatics, 2021), and UPP2/UPP (Bioinformatics, 2023).

Method Overview

FAMSA2 takes protein FASTA sequences and produces a multiple-sequence alignment. It first computes LCS-derived dissimilarities between sequences. In default mode it builds a single-linkage guide tree using Prim’s MST algorithm; in medoid mode it recursively samples and clusters medoid seed sequences to approximate the guide tree faster.

The guide tree defines a progressive merge order. Leaves become single-sequence profiles, internal nodes align two child profiles, and the final profile becomes the output MSA. FAMSA2 dynamically allocates CPU threads between independent profile-pair tasks and fine-grained dynamic-programming work inside one large profile-pair alignment. Optional output features include gzip compression and nongap-fraction column trimming.

Code inspection supports the production aligner claims closely. The main implementation caveats are that internal partial refinement is configurable rather than unconditionally active by default, and the full benchmark orchestration is not present in the cloned production repository.

Evaluation

The paper evaluates FAMSA2 across structural, phylogenetic, and functional alignment settings.

On extHomFam, default FAMSA2 reports the best average structural accuracy among tested methods while being much faster than the slow accurate baselines. The medoid-tree mode trades some accuracy for large speed gains. Increasing-family-size and mixed-homolog/nonhomolog tests support the claim that the new dissimilarity and tree construction are robust at scale.

The AlphaFold Database cluster benchmark uses LDDT as a reference-free structural consistency score and again places FAMSA2 variants at the top. Simulated MSAs test recovery of known evolutionary alignments. Active-site entropy tests whether functional residues concentrate into the same alignment columns. The ME/ML tree-agreement benchmark is weaker evidence and should be interpreted conservatively; the paper itself states it is not direct proof of phylogenetic accuracy.

Reproducibility

Rating: 3.5 / 5.

The production code is available, compact, and maps well to the paper’s main algorithmic claims. CLI modes, defaults, distance formula, guide-tree methods, SIMD LCS, profile-alignment scheduling, gzip output, and output-only trimming are all visible in source.

The score is not higher because this acquired checkout was not buildable as-is: it was cloned without submodule contents, and PaperCode cleanup removed nested .git metadata, leaving dependency directories empty. Also, the full benchmark pipelines for all figures are not included in the production repo, although datasets are linked from Zenodo and the README provides command examples. Reproducing the paper’s quantitative claims would require reacquiring dependencies recursively plus reconstructing benchmark workflows from paper methods, Zenodo datasets, and possibly author-side scripts not present here.
