HuDiff

An adaptive autoregressive diffusion approach to design active humanized antibodies and nanobodies

Open paper Code

HuDiff 方法解读

HuDiff 要解决的是抗体和纳米抗体的人源化：在降低免疫原性时，尽量不破坏决定结合特异性的 CDR。传统 CDR grafting 要先选择人源框架模板，还可能依赖回突变或结构信息。HuDiff 的关键不同是只固定输入 CDR，并从掩码化的框架区直接生成新的、人源化的 FR。

CDR + 已对齐序列
 -> 只扩散/掩码 FR
 -> 编码残基、区域、位置和链类型
 -> CNN 与 RoFormer 注意力
 -> 预测 FR 残基 logits
 -> 预训练重建；微调时用 AbNatiV 分数引导
 -> 多次采样并筛选候选序列

HuDiff-Ab 同时输入重链和轻链，因此可学习两条链之间的信息；HuDiff-Nb 面向单条 VHH 样序列。预训练使用人源序列重建被掩码的 FR，CDR 在整个扩散过程中保持不变。微调中，论文用 Gumbel-Softmax 将 logits 变成可反传的近似 one-hot 表示，再由 AbNatiV 提供人源性/天然性引导（paper.md:21-23,139-165）。

论文将 HuDiff-Ab 与 Sapiens、HuDiff-Nb 与 Llamanade 比较，并对 2B04 抗体和 3-2A2-4 纳米抗体做实验验证。最佳抗体的 BLI 亲和力为 0.15 nM（亲本 0.12 nM）；最佳纳米抗体为 2.52 nM（亲本 5.47 nM）。公开代码包含训练和 CDR 条件采样入口；但在限定的源码核查中，模型工厂以及 Gumbel-Softmax/AbNatiV 微调实现仍为 Not found，不能把它们表述为已逐行验证的实现对应关系。

HuDiff

HuDiff is a sequence-space, adaptive autoregressive diffusion framework for antibody and nanobody humanization. Rather than choosing a human template, it fixes the supplied CDRs and reconstructs a human-like FR from progressively masked sequence states; HuDiff-Ab models paired heavy/light chains and HuDiff-Nb models a single VHH-like chain.

Classical CDR grafting depends on a compatible human framework and may require backmutation or structural analysis. The paper compares HuDiff-Ab with Sapiens and HuDiff-Nb with Llamanade, using humanness/nativeness, germline/FR analyses and experimental binding validation. The selected antibody retained near-parental affinity (0.15 nM versus 0.12 nM) and one nanobody improved from 5.47 nM to 2.52 nM in the reported BLI experiments (paper.md:5,17).

The public HuDiff repository supplies training, sampling and evaluation scripts, plus data/checkpoint links. Direct source inspection supports the paired model interface, training loop and CDR-conditioned sampling CLI. The exact factory dispatch and implementation of the paper’s Gumbel-Softmax/AbNatiV guidance are Not found within the bounded code read, so code-paper fidelity is medium rather than high. No training or inference run was executed.
