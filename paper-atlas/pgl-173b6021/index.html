PGL

Generative single-cell transcriptomics via large language models

PGL 方法详解：把单细胞转录组变成可生成的“语言”

1. PGL 要解决什么问题？

PGL（Portraying Gene Language）试图完成的不是“把一个细胞编码成向量”，而是根据组织、器官、疾病状态、扰动条件等元数据，直接生成一个新的单细胞 RNA 表达谱。它把每个细胞写成一串有顺序的“基因-表达等级”文本，让 decoder-only 大语言模型逐 token 生成，再把文本解析回基因表达矩阵。论文第 1-12 行；论文第 21-24 行

这项工作针对两个实际场景：

  1. 在指定组织或疾病背景下构造虚拟细胞队列，用于比较分析和候选假设生成；
  2. 当空间转录组没有匹配的 scRNA-seq 图谱时，按样本元数据“按需”生成一个参考数据集，用于细胞类型解卷积或标签转移。论文第 101-110 行

2. 为什么已有方法还不够？

论文列举的 scGPT（Nature Methods, 2024）、Geneformer（Nature, 2023）、TranscriptFormer（bioRxiv, 2025）、CELLama（Advanced Science, 2024）和 Cell2Sentence（bioRxiv, 2024）已经证明 Transformer 或语言模型能够学习单细胞表示。但这些方法的主要输出通常是用于分类、扰动预测或表征学习的低维嵌入，而不是一个可重新放入 Scanpy、Harmony、TACCO 等流程的显式细胞表达矩阵。论文第 18-24 行；论文第 304-314 行

PGL 的新意因此不只是“使用 LLM”，而是改变任务定义：

传统表征任务：细胞表达谱 -> 模型 -> 低维向量 -> 分类/预测

PGL 生成任务：组织/疾病等元数据 -> 模型 -> 基因表达文本 -> 新细胞矩阵

3. 输入、输出与核心假设

项目 论文中的定义 研究者应如何理解
训练数据 原始 count matrix 与标准化细胞元数据 用真实细胞构造文本监督信号
条件输入 tissue、organ、disease、perturbation 等自然语言提示 推理时只提供元数据，不提供目标细胞表达谱
训练目标 <START_GEN> 与 <END_GEN> 之间的 GENE(Level) 序列 把细胞生成变成条件自回归 next-token prediction
单细胞输出 解析后的 gene-level 对，再随机映射为连续数值 输出可聚合为 AnnData
隐含假设 训练语料已包含元数据对应的稳定共表达规律 训练集中没有的状态、患者特异变异不会自动出现

论文明确说明，合成细胞不能替代实验图谱：它们不保证包含患者特异遗传差异、训练集中缺失的稀有状态或某次实验独有的技术伪影。论文第 110-113 行

4. 从真实细胞到训练文本

4.1 数据整理与质控

作者从 scBaseCount 中选择 droplet-based 癌症 scRNA-seq 数据。Methods 报告约 1,400 万个细胞、2,118 个数据集，覆盖肺癌、乳腺癌、结直肠癌、胰腺癌等；Results 写成 2,119 个数据集，两处相差 1 个，论文没有解释。论文第 41-44 行；论文第 119-128 行

质控规则包括：

  • 去除检测基因数少于 200 的细胞；
  • 不设置检测基因数上限，以保留复杂的恶性或活化免疫细胞；
  • 在每个数据集中去除表达比例低于 0.1% 的基因；
  • 离散化之前保留 raw counts，不做全局 normalization 或 log transform。论文第 131-134 行

随后将基因 ID 统一为标准 gene symbol，并按训练配置过滤到 10x Genomics 的 Visium-compatible panel。这样既减少 token 长度，又让生成结果更容易与空间转录组取交集。不过，论文没有给出具体 panel 版本和完整基因列表。论文第 137-140 行

4.2 先找出每个数据集的重要 marker

为了获得 dataset-level marker，作者对每个数据集执行无监督聚类：必要时下采样；仅为聚类进行 normalization 和 log transform；选择 highly variable genes；降维；Leiden 聚类；再用 rank-based differential expression 找每个 cluster 的高排名 marker，合并成该数据集的 marker 列表。论文第 143-146 行

这里的关键是：用于 marker discovery 的标准化流程与用于表达等级离散化的 raw-count 流程不同。论文没有报告下采样规模、HVG 数量、PCA 维数、Leiden resolution 或 marker 截断阈值。

4.3 三层基因抽样

一个训练细胞不会把所有基因都写入文本，而是选约 200 个基因：

  1. 数据集级 marker genes：保留主要细胞类型和稳定转录程序；
  2. 该细胞的高表达基因：保留瞬时或状态特异信号；
  3. 剩余 panel 中的随机基因：扩大基因覆盖，降低对固定组合的记忆。论文第 149-160 行

每个 epoch 都会重新随机选择部分基因，因此同一个细胞可以产生不同训练文本。这可以理解为一种面向基因子集的数据增强。但三层各取多少基因、随机分布是什么，论文均未给出。论文第 187-193 行

4.4 把连续表达值离散成语言符号

PGL 在每个细胞内部，基于已表达基因的 percentile threshold，把表达划分为五级：

Absent < Low < Medium < High < Very High

然后按表达从高到低排序，序列化为：

<START_GEN>
GENE_A(Very High), GENE_B(High), GENE_C(Medium), ...
<END_GEN>

这种处理强调单个细胞内部的相对排名，降低 library size 差异的影响；代价是丢失连续 count 的精细动态范围。论文没有给出五个区间的准确 percentile cutoff，也没有说明 Absent 的具体赋值规则。论文第 163-169 行；论文第 110-113 行

5. 模型如何学习“细胞语言”？

5.1 主干模型与 LoRA

Methods 指定主干为 Qwen3-0.6B decoder-only Transformer；Results 简写为 Qwen-0.6B，二者命名不完全一致。元数据 prompt 放在基因序列前面，模型据此生成后续的 gene-level tokens。论文第 41-44 行；论文第 178-184 行

基础参数被冻结，LoRA 加在全部 attention projection 和 feed-forward/MLP projection 上。论文报告：

  • rank $r=32$；
  • scaling parameter $\alpha=64$（转换后的正文显示为 a =64）；
  • LoRA dropout = 0.05。

论文说明冻结矩阵 $W_0\in\mathbb{R}^{d\times k}$，训练两个低秩矩阵 $B\in\mathbb{R}^{d\times r}$ 与 $A\in\mathbb{R}^{r\times k}$。但精确更新公式在原网页中是嵌入图片，本地 paper.md 没有保留，因此其 scaling convention 在当前证据中为 Not found，不能仅按常见 LoRA 写法补造。论文第 178-184 行

5.2 训练目标

训练采用 teacher forcing 的 causal language modeling。模型根据元数据和之前的 token 预测下一个 gene-expression token。loss 只计算基因表达目标段，prompt token 被 mask；每个 epoch 的随机基因组合会变化。论文第 187-193 行

论文的 loss 公式同样以图片形式存在，转换文本没有保留数学表达式。可以确认的是“条件 next-token likelihood + prompt loss mask”，不能确认其代码级 shift、normalization 或 reduction 实现。

论文称一个生成细胞通常需要 8,000-16,000 tokens；肺腺癌实验将最大长度设为 8,192，最终每个细胞约有 72.3 个可解析基因。也就是说，这里的“完整细胞生成”仍然是稀疏的基因子集生成，不是无缺失地重建全转录组。论文第 41-44 行；论文第 163-169 行

推理部分以下细节为 Not found：temperature、top-p/top-k、重复基因处理、非法字符串处理、未生成 <END_GEN> 时的终止策略，以及五个等级映射到连续数值的概率分布。论文第 196-202 行

7. 作者如何验证生成结果？

7.1 匹配与不匹配元数据

作者选取 10 个组织/疾病元数据匹配的真实数据集，以及 10 个组织或疾病不匹配的数据集，分别与生成数据比较。论文第 205-210 行

角度 计算方法 匹配 vs 不匹配结果
全局基因分布 对每个基因跨细胞求和，再算 Spearman correlation $0.47\pm0.04$ vs $0.34\pm0.05$
单细胞混合 联合 PCA；可用 Harmony；按 real/synthetic 标签算 silhouette $0.28\pm0.02$ vs $0.37\pm0.06$，越低越混合
总体 marker 重叠 两个数据集所有 cluster marker 的并集做 Jaccard $0.25\pm0.04$ vs $0.11\pm0.04$
cluster 匹配 marker 每个 synthetic cluster 找最佳 real cluster，再求平均 $0.17\pm0.04$ vs $0.056\pm0.025$

Figure 2 的图内 p 值约为 $1.65\times10^{-4}$ 到 $3.84\times10^{-4}$；正文转换后的指数出现 10LL 等乱码，因此这里采用直接读图值。论文第 47-64 行；Figure 2

这些结果支持“匹配元数据时更相似”，但不等于 synthetic 与 real 完全一致：相关系数是中等水平，silhouette 并非 0，Jaccard 也显示 marker 只部分重叠。

7.2 独立生成两类乳腺癌

作者分别生成 10,000 个 HR-positive 和 10,000 个 TNBC 细胞，使用标准 Scanpy 流程进行 normalization、log transform、HVG、PCA、邻居图和 UMAP；再叠加 luminal marker（ESR1、KRT8、KRT18）、basal marker（KRT5、KRT14、EGFR）以及 proliferation marker（MKI67、TOP2A、CDK1）。结果恢复了已知的 luminal/basal 差异及组成变化。论文第 67-78 行；论文第 235-250 行

这里比较的是两个合成队列，不是与匹配患者队列进行独立效应量验证。marker 同时参与注释，因此也不是完全盲法的外部验证。

7.3 用生成细胞做空间参考

作者分别处理真实和 PGL 生成的前列腺癌 scRNA-seq reference，注释 epithelial、fibroblast、endothelial、myeloid/macrophage、lymphocyte 等大类。与 Visium 数据取 gene symbol 交集后，使用 TACCO 默认参数分别生成 spot-by-cell-type proportion，并比较每种细胞的 spot-wise correlation；CellDART 被用作另一种方法，Visium HD 乳腺癌则用于另一组织和分辨率。论文第 253-280 行

Figure 4 直接显示所有细胞类型为正相关，但强度不一致，epithelial/fibroblast 的一致性明显强于 lymphocyte/macrophage。这个实验衡量的是“使用两种 reference 得到的计算结果是否一致”，不是有 ground truth 的空间定位准确率。Figure 4；论文第 81-95 行

8. 论文结论、分析解释与假设输出要分开

论文直接支持的结论

  • PGL 可以从元数据生成可解析的稀疏单细胞表达谱；
  • 与不匹配数据集相比，生成结果在匹配组织/疾病背景下更接近真实数据；
  • 生成的乳腺癌亚型队列能够恢复已知 marker program；
  • 在示例数据中，synthetic reference 与 real reference 给出的空间映射存在正向一致性。

基于证据的解释

  • 三层抽样把“稳定 marker、单细胞强信号、背景覆盖”同时放入监督目标，是一种定向数据增强；
  • per-cell ordinal binning 提高了对 library size 的鲁棒性，却把学习目标从绝对 count 改成了细胞内部相对等级；
  • PGL 更适合作为“背景条件匹配的基线参考”，而不是患者特异实验图谱的替代品。

假设生成输出

论文讨论了 TNBC 生成结果中的 LGALS1 与 IFITM3，并指出它们与既有文献一致。作者明确说明，这不构成生物学验证，也不是新 marker 的发现；合理用途是形成需要后续实验检验的候选优先级。论文第 107 行

PGL: Generative Single-Cell Transcriptomics via Large Language Models

Overview

PGL (Portraying Gene Language) is a bioRxiv 2026 framework for generating synthetic single-cell RNA-seq profiles from metadata alone. It converts a cell into an ordered text sequence of gene-expression pairs, adapts a decoder-only language model to generate those sequences, and parses the output back into a matrix usable by standard single-cell and spatial-transcriptomics tools. Paper, lines 1-12; Paper, lines 21-24

Problem and prior limitations

Single-cell foundation models have mainly learned embeddings for classification, perturbation prediction, or representation learning. The paper contrasts this with explicit cell generation: synthesizing thousands of coordinated gene measurements rather than returning a latent vector. Named predecessors include scGPT (Nature Methods, 2024), Geneformer (Nature, 2023), TranscriptFormer (bioRxiv, 2025), CELLama (Advanced Science, 2024), and Cell2Sentence (bioRxiv, 2024). The manuscript argues that these methods established the value of transformer/language representations but did not make metadata-conditioned generation of complete cell profiles their primary output. Paper, lines 18-24; Paper, lines 304-314

PGL targets two practical gaps: creating context-specific virtual cohorts for comparative analysis and supplying a synthetic scRNA-seq reference when a matched experimental atlas is unavailable for spatial deconvolution. Paper, lines 101-110

Method in brief

The training corpus contains about 14 million cancer cells from scBaseCount. Methods report 2,118 datasets, while Results report 2,119, an unresolved one-dataset discrepancy. Cells with fewer than 200 detected genes and genes present in fewer than 0.1% of a dataset’s cells are removed; genes are standardized and filtered to a Visium-compatible panel. Paper, lines 41-44; Paper, lines 119-140

For each cell, PGL selects roughly 200 genes using dataset markers, cell-level highly expressed genes, and random remaining-panel genes. Raw expression is binned per cell into Absent, Low, Medium, High, and Very High, then serialized in descending expression order as GENE(Level) tokens. Paper, lines 143-169

A Qwen3-0.6B decoder is adapted with LoRA on attention and MLP projections while base weights remain frozen. Reported LoRA settings are rank 32, scaling parameter 64, and dropout 0.05. Training uses teacher-forced causal language modeling with loss only on gene-expression tokens; random gene selections are regenerated each epoch. At inference, a metadata prompt drives sampling, generated pairs are parsed, and categorical levels are stochastically mapped to numeric values in an AnnData matrix. Paper, lines 178-202

Evaluation and main results

  • Generated lung adenocarcinoma cells: 4,000 cells generated with an 8,192-token maximum contain about 72.3 parsed genes per cell and form marker-annotatable clusters. Paper, lines 41-44
  • Context specificity: against 10 matched and 10 mismatched real datasets, matched comparisons have higher mean gene-wise Spearman correlation (0.47 +/- 0.04 versus 0.34 +/- 0.05), lower Harmony-corrected silhouette score (0.28 +/- 0.02 versus 0.37 +/- 0.06), higher overall marker Jaccard similarity (0.25 +/- 0.04 versus 0.11 +/- 0.04), and higher cluster-matched Jaccard similarity (0.17 +/- 0.04 versus 0.056 +/- 0.025). Direct inspection of Figure 2 shows group p-values from $1.65\times10^{-4}$ to $3.84\times10^{-4}$; the converted prose corrupts several exponents. Paper, lines 47-64; Figure 2
  • Cancer subtype biology: independently generated cohorts of 10,000 HR-positive and 10,000 TNBC cells recover expected luminal-versus-basal marker patterns, subtype-associated compositions, and differential-expression structure. This is recovery of known biology in synthetic cohorts, not prospective biological validation. Paper, lines 67-78
  • Spatial reference use: prostate Visium maps inferred with PGL-generated and real references show positive spot-wise agreement across broad cell types using TACCO. The paper reports similar findings with CellDART and breast Visium HD, but those supporting panels are supplementary and unavailable locally. Paper, lines 81-95

Claims, interpretation, and hypotheses

Paper-supported claim: PGL generates sparse, context-conditioned profiles that are more similar to matched than mismatched datasets and can act as a baseline reference for spatial mapping.

Interpretation: the core tradeoff is deliberate. Per-cell ordinal tokens and hierarchical subsampling make long-form generation feasible, but the reconstructed matrix loses continuous count resolution and covers only a subset of genes. Agreement with a real-reference deconvolution measures concordance between computational mappings, not ground-truth spatial accuracy. Paper, lines 110-113

Hypothesis-generation output: the paper discusses TNBC-associated LGALS1 and IFITM3 as literature-consistent candidates. The authors explicitly state that these observations are neither biological validation nor discovery of new markers; they require downstream experimental testing. Paper, line 107

Verified code behavior: none. No paper-linked implementation was found and CODE_SOURCE_TYPE=none.

Limitations and reproducibility

The biological scope is limited by the training corpus: generated cells cannot be assumed to recover patient-specific variants, states absent from training, or experiment-specific artifacts. Ordinal binning compresses expression dynamics, while the LLM context length causes sparse gene coverage. Paper, lines 110-113

Reproducibility rating: 1/5 (paper-only). The manuscript gives the conceptual pipeline, several QC thresholds, backbone, LoRA settings, and public data sources, but no code, trained adapter, environment, or runnable example was found. It does not report the exact panel version, bin cutoffs, sampling quotas, prompt template, optimizer/training schedule, decoding settings, category-to-value conversion, or most downstream-analysis parameters. Supplementary tables and figures are also absent locally. Paper, lines 187-202; Paper, lines 283-286
