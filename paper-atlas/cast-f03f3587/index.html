CAST

Search and match across spatial omics samples at single-cell resolution

CAST 方法详解：在单细胞分辨率下搜索、配准与整合空间组学样本

1. CAST 要解决什么问题？

不同空间组学样本通常没有可直接比较的坐标系。即使它们来自相近的解剖位置，也可能因为个体差异、切片深度、组织形变、测量技术、分辨率、基因面板和批次效应而呈现完全不同的外观。

传统图像配准依赖染色图像或人工标记点。当染色方式、图像质量、组织大小或视野不同，配准容易失效。已有的转录组空间配准方法，例如 PASTE（Nature Methods, 2022），更适合分辨率较低、规模较小且技术相近的数据；论文报告它在部分单细胞级任务上失败或受到内存限制。Tangram（Nature Methods, 2021）和 cell2location（Nature Biotechnology, 2022）主要解决单细胞到空间位置的映射，也没有同时利用两个空间样本已经观测到的组织结构。

CAST 的目标更完整：

  1. 从多个空间样本中学习可比较的组织表示；
  2. 把查询样本变换到参考样本的物理坐标系；
  3. 在对齐后的样本间匹配单个细胞；
  4. 比较疾病与对照的局部空间差异；
  5. 将不同空间模态重建到同一个单细胞组织框架中。

2. 输入、输出与核心假设

对于样本 (s)，CAST 的基本输入为：

  • 空间坐标 (Psi_s \in \mathbb{R}^{M_s\times 2})，其中 (M_s) 是细胞或 spot 数量；
  • 分子特征矩阵 (X_s \in \mathbb{R}^{M_s\times N})，例如基因表达；
  • 可选的细胞类型、区域标签或其他模态，用于评估和下游解释。

主要输出为：

  • CAST Mark：每个细胞的图嵌入；
  • CAST Stack：查询样本在参考坐标系中的新坐标；
  • CAST Projection：跨样本细胞匹配、权重、特征距离、物理距离和重建后的分子层；
  • ∆Analysis：疾病/对照或损伤/正常之间的局部差异图；
  • 论文应用中的 scRTE：转录组与转译组整合后的相对翻译效率。

CAST 的核心假设是：同源组织位置的局部分子组织具有相似性，即使它们的原始物理坐标、组织形状和测量技术不同。因此，方法先学习不依赖绝对坐标的组织图表示，再用该表示指导物理配准。

4. CAST Mark：学习跨样本共同空间特征

4.1 从坐标构建组织图

对含 (M) 个细胞的样本，CAST 使用空间坐标进行 Delaunay 三角剖分，得到邻接矩阵 (A\in\mathbb{R}^{M\times M})。这一步把组织表示为局部细胞邻接图，而不是直接使用绝对坐标。

代码在 CAST/CAST/main.py:16-21 中为每个样本构图，并把图与表达矩阵组成训练输入。每个样本保留自己的图结构，但所有样本共享同一个 GNN 参数。

4.2 为什么使用 GCNII？

普通 GCN 加深后容易出现过度平滑：不同节点的表示越来越相似，难以保留精细空间结构。GCNII 在每一层重新注入初始特征，并使用恒等映射控制参数变换。论文中的更新式为：

\[{H}^{\left(l+1\right)}=\sigma \left(\left(\left(1-{\alpha }_{l}\right)\left({D}^{-\frac{1}{2}}\hat{A}{D}^{-\frac{1}{2}}\right){H}^{\left(l\right)}+{\alpha }_{l}{H}^{\left(0\right)}\right)\Big(\left(1-{\beta }_{l}\right){I}_{n}+{\beta }_{l}{W}^{l}\Big)\right)\]

其中：

  • (hat A) 是加入自环后的邻接矩阵；
  • (D) 是度矩阵；
  • (H^{(0)}) 是初始细胞特征；
  • (H^{(l)}) 是第 (l) 层表示；
  • (sigma) 默认是 ReLU。

论文和代码都默认使用 9 层。代码中的 GCNII 位于 CAST/CAST/models/model_GCNII.py:45-77，可选的线性编码器先把大基因面板压缩到 512 维。

4.3 两视图自监督学习

CAST 对同一个样本随机遮蔽部分边和基因特征，得到两个增强图 (G_1) 与 (G_2)。共享参数的 GNN 分别产生 (H_1) 与 (H_2)，然后按特征维标准化：

\[\widetilde{H}=\frac{H-\mu(H)}{\sigma(H)\sqrt{M}}\]

论文目标函数为：

\[{\mathcal{L}}={\left\Vert\widetilde{H}_{1}-\widetilde{H}_{2}\right\Vert}_{F}^{2} +\lambda\left( {\left\Vert\widetilde{H}_{1}^{\top}\widetilde{H}_{1}-I\right\Vert}_{F}^{2} +{\left\Vert\widetilde{H}_{2}^{\top}\widetilde{H}_{2}-I\right\Vert}_{F}^{2} \right)\]

第一项要求两个扰动视图仍产生一致表示；后两项约束每个视图的不同嵌入维度不要高度冗余。

代码在 CAST/CAST/CAST_Mark.py:51-75 中生成两个增强视图，并用负的跨视图对角相关加两个去相关项训练。由于嵌入已经标准化，这与论文的两视图平方距离目标只差常数或比例因子，优化方向一致。

默认代码参数包括：400 个 epoch、学习率 (10^{-3})、损失权重 (lambda=10^{-3})、边丢弃率 0.5、特征丢弃率 0.3。

4.4 Mark 的输出意味着什么？

Mark 不使用细胞类型或组织区域标签。它输出的是细胞在“分子组织图”中的表示。论文再对多个样本的嵌入联合聚类，观察相同颜色的区域是否在不同切片中保持相似的解剖位置。

这一步的关键不是得到唯一的生物学区域标签，而是提供一个跨样本的相似度坐标，使 Stack 可以判断某个查询细胞更可能对应参考组织的哪个位置。

5. CAST Stack：从嵌入相似度到物理配准

5.1 为什么不能直接逐细胞最近邻？

如果每个查询细胞都独立选择嵌入最相似的参考细胞，局部噪声可能把相邻细胞分配到相距很远的位置，组织拓扑会被破坏。CAST Stack 的解决方案是：对整个查询组织施加统一的空间变换，使变换后的查询细胞在物理上靠近嵌入相似的参考细胞。

5.2 粗略定位

代码先在有限的缩放、旋转、平移和镜像候选中寻找较好的初始化（CAST/CAST/CAST_Stack.py:60-93）。这是必要的，因为“当前最近的参考细胞”会随坐标变化，损失函数具有分段特性，差的初始化容易落入错误位置。

5.3 仿射阶段

论文使用不含剪切的仿射变换：

\[\Psi=T_{\mathrm{affine}}(\Psi^0)=A\Psi^0+\mathbf b\]

其中参数向量为：

\[\boldsymbol\theta=[a,d,\phi,b_1,b_2]^\top\]

(a,d) 控制两个方向的缩放，(phi) 控制旋转，(b_1,b_2) 控制平移；负缩放可表达镜像。

对于查询细胞 (i)，在当前变换后找到物理距离最近的参考细胞，并读取二者预先计算的嵌入 Pearson 相关 (r_i)。损失定义为：

\[J=\sum_{i=1}^{M}J_i,\qquad J_i=(\max r)-r_i\]

参数更新为：

\[\boldsymbol\theta_{t+1}=\boldsymbol\theta_t-\alpha\nabla_{\boldsymbol\theta}J\]

代码在 CAST/CAST/CAST_Stack.py:218-247 中根据当前最近物理邻居取出嵌入距离；在 252-278 中通过坐标正负扰动估计 (partial J/\partial(x,y))；再在 280-343 中使用链式法则计算仿射参数梯度。

5.4 B-spline 自由形变

仿射配准只能纠正整体旋转、缩放和平移，无法处理局部组织形态差异。CAST 因此在第二阶段建立 (s\times s) 控制点网格，用三次 B-spline 进行自由形变：

\[\Psi=T_{\mathrm{B\text{-}spline}}(\Psi^0) =\sum_{l=-2}^{1}\sum_{m=-2}^{1}B_l(u)B_m(v)\omega_{i+l,j+m}\]

控制点通过同一个嵌入相似度目标更新：

\[\omega_{t+1}=\omega_t-\alpha\nabla_{\omega}J\]

代码 CAST/CAST/CAST_Stack.py:145-216,365-464 实现网格建立、B-spline 基函数、控制点更新、最大移动限制和坐标重计算。

5.5 搜索空间图谱

论文把 Stack 用于两阶段图谱搜索：

  1. 对所有候选图谱切片只运行仿射阶段，按损失筛选候选；
  2. 对少数候选运行完整的仿射 + B-spline；
  3. 选择最终损失最低的切片。

GitHub 包提供了配准函数，但没有发布该图谱遍历驱动脚本。

6. CAST Projection：在对齐组织间匹配细胞

6.1 共同低维特征空间

对于不同样本或模态，论文先使用 Combat 和 Harmony 建立共同低维空间。代码路径为：

缩放后的 AnnData layer
  -> 可选 Combat
  -> PCA
  -> Harmony
  -> 邻居图与 UMAP
  -> 使用 X_pca_harmony 进行匹配

也可以传入外部已经整合好的低维特征（CAST/CAST/main.py:210-265；CAST/CAST/utils.py:99-132）。

6.2 同时满足“空间近”和“分子像”

对每个目标细胞，CAST 先根据局部 Delaunay 边长估计物理搜索半径，再在半径内寻找余弦距离最小的源细胞。论文默认使用平均细胞距离的 2 倍，但具体实验可使用 1.5 倍或 3 倍。

代码还有一个论文短描述中不明显的回退机制：如果半径内候选不足，就先取物理距离最近的 20 个源细胞，再从中选择特征距离最小者（CAST/CAST/CAST_Projection.py:155-211）。这可缓解稀疏区域或小幅配准偏移。

匹配后，源样本的原始表达被写入目标 AnnData 的新 layer，并生成归一化层（CAST/CAST/CAST_Projection.py:84-109）。

需要注意的代码细节：公开函数虽然暴露 k2 参数，但内部调用固定为 k2=1（CAST/CAST/CAST_Projection.py:58-79）。因此当前 commit 实际执行单源细胞匹配，而不是多邻居加权。

7. ∆Analysis：对齐后比较局部空间差异

对每个中心细胞，定义半径 (R) 内的局部 niche，然后比较对齐样本在该位置附近的统计量。论文包括：

  • ∆Cell：某细胞类型的局部数量差；
  • ∆Exp：局部平均基因表达差；
  • ∆CCA：Delaunay 图两跳邻域中的细胞类型邻接差；
  • ∆CCI：配体–受体相互作用强度差。

对所有细胞重复后，可得到连续的空间差异梯度图。论文还进行重复样本聚合、统计检验、空间模式聚类、径向基函数插值和 hot-zone 定义。

代码 CAST/CAST/utils.py:313-432 只直接实现了半径掩码、∆Cell、∆Exp、秩和检验和简单显著性图。未找到 ∆CCA、∆CCI、重复样本聚合、FDR 处理和完整疾病/损伤分析流程，因此代码匹配应标为 Partial。

∆Analysis 有三个重要解释限制：

  1. 上游配准错误会直接产生假差异；
  2. 半径 (R) 决定分析关注局部变化还是大区域变化；
  3. 由于 Stack 会扭曲坐标，∆Cell 更接近局部细胞组成的相对变化，而不是绝对细胞密度变化。

8. scRTE：空间转录组与转译组整合

论文把 STARmap 转录组投影到 RIBOmap 参考细胞后，定义：

\[{\mathrm{scTE}}_{i,j}=\log_2\left(\frac&#123;&#123;\mathrm{RIBO}}_{i,j}}&#123;&#123;\mathrm{STAR}}_{i,j}}\right)\]

再对每个基因跨细胞做 z-score：

\[{\mathrm{scRTE}}_{i,j}=\frac&#123;&#123;\mathrm{scTE}}_{i,j}-\mu_i}{\sigma_i}\]

这里 RIBO 和 STAR 使用 norm1e4。由于两个模态来自不同相邻切片和不同技术，scRTE 不是同一个细胞中的绝对核糖体结合比例，而是数据集内的相对翻译水平排名。

论文进一步使用基因内标准差衡量空间异质性，并用 Kruskal–Wallis 检验比较细胞类型或区域。官方 GitHub 快照中未找到 scRTE、RIBOmap 或翻译效率相关实现，因此这一部分只能由论文证据支持，代码状态为 Not found。

9. 主要实验结果如何理解？

  • 模拟数据中，真实配对细胞的嵌入相关平均为 0.97，随机配对为 0.04。
  • (k=20) 时，Mark 聚类平均 ARI 为 0.79，90% 细胞与真实对应细胞落入一致聚类。
  • Stack 对齐后，真实配对平均物理距离约 38 µm，随机配对约 1,133 µm。
  • 方法可处理 64 基因与 2,766 基因面板、不同组织大小以及 STARmap、MERFISH、Slide-seq、Stereo-seq 和 Visium。
  • S4 投影到 S1 时，中位物理距离为 72 µm，细胞类型匹配率为 91%。
  • RIBOmap–STARmap 整合的平均标签匹配率为 85%，随后观察到明显的细胞类型和脑区特异 scRTE 模式。

Fig. 5 的关键消融显示：只看低维特征会产生很长的物理距离尾部；加入空间半径后，匹配集中在合理的局部范围。这直接说明 Projection 同时使用“分子相似”和“空间接近”是必要的。

11. 最值得记住的思想

CAST 的关键并不是某一个单独网络层，而是下面这条组合逻辑：

先用局部分子图学习跨样本可比较的组织表示，再让整个组织在物理空间中向高相似位置移动，最后只在合理物理邻域内进行单细胞分子匹配。

Mark 解决“什么位置在分子组织上相似”，Stack 解决“如何在不破坏组织结构的情况下把这些位置重合”，Projection 解决“对齐后哪些细胞可以交换或合并分子信息”。∆Analysis 和 scRTE 则是建立在这三个基础模块之上的应用层。

CAST: search and match spatial omics samples at single-cell resolution

What problem does it solve?

Spatial omics studies increasingly contain multiple tissue slices, animals, conditions, technologies and molecular modalities, but their physical coordinate systems are not directly comparable. Image registration can fail when staining, resolution, tissue size or morphology changes, while early transcriptomics-based alignment methods were mainly designed for similar, lower-resolution datasets. The paper specifically contrasts CAST with PASTE (Nature Methods, 2022), an optimal-transport alignment method that the authors report can handle Visium but fails or becomes memory-limited on several single-cell-scale tasks.

CAST (cross-sample alignment of spatial omics) treats integration as a search-and-match problem: learn molecularly comparable tissue representations, physically register samples, assign corresponding cells, and then compare or merge their measurements at single-cell resolution.

Method in one view

CAST has three core modules:

  1. CAST Mark constructs a Delaunay tissue graph for each sample and trains a nine-layer GCNII with a two-view CCA-style self-supervised objective. The output is a per-cell graph embedding intended to preserve shared molecular tissue organization without labels.
  2. CAST Stack uses Pearson similarity between those embeddings to guide physical registration. It first optimizes a global affine transform and then a local B-spline free-form deformation while moving the entire tissue coherently.
  3. CAST Projection places aligned samples in a shared low-dimensional feature space using Combat/Harmony or pre-integrated features, then matches each target cell to a physically nearby, feature-similar source cell and reconstructs source molecular layers on the target tissue.

Aligned samples enable ∆Analysis, which subtracts local niche statistics across conditions, and the paper uses Projection to combine STARmap transcriptomics with RIBOmap translatomics and calculate relative single-cell translation efficiency (scRTE).

What is novel?

  • It combines representation learning and physical registration rather than using raw coordinates, images or independent cell assignments alone.
  • The deep GCNII encoder addresses oversmoothing and learns consistent spatial signatures across samples without tissue-region annotations.
  • The Stack objective preserves global tissue organization while allowing both affine correction and constrained local warping.
  • Projection explicitly combines molecular similarity with physical proximity. This avoids biologically implausible long-range matches that can arise from feature-only integration.
  • The same registered coordinate system supports atlas search, spatial differential analysis and spatial multi-omic reconstruction.

Evaluation and main results

The study spans STARmap PLUS, RIBOmap, MERFISH, Slide-seq, Stereo-seq, Visium and a mouse central nervous system atlas.

Key reported results include:

  • On a simulated query/reference pair with known cell partners, ground-truth embedding correlations average 0.97 versus 0.04 for random pairs. CAST Mark clustering reaches average ARI 0.79 and 90% consistent cells at (k=20); even at (k=100), average ARI is 0.47 with 56% consistency.
  • After CAST Stack alignment, the mean ground-truth-pair distance is about 38 µm versus 1,133 µm for random pairs.
  • CAST aligns eight biological brain slices into one coordinate system and handles cross-technology, unequal-size and unequal-gene-panel settings, including 64 versus 2,766 genes.
  • A coarse affine atlas search followed by full affine + B-spline refinement identifies the expected mouse brain depth near −1.755 mm.
  • CAST Projection from S4 to S1 has a median physical assignment distance of 72 µm and 91% matched cell-type labels. Spatial constraints shorten match distances relative to feature-only projection; the authors also report advantages over Tangram (Nature Methods, 2021) and cell2location (Nature Biotechnology, 2022).
  • RIBOmap–STARmap Projection gives average matched-label accuracy of 85% and enables spatial scRTE profiles with cell-type- and region-specific patterns.
  • ∆Analysis identifies Alzheimer-associated spatial gene modules, glial composition changes, ligand–receptor patterns and injury-associated programs in axolotl regeneration.

The main figures visually support a coherent chain from consistent embedding regions to registration, constrained projection and localized downstream signals. The most convincing quantitative evidence is the separation of true/random embedding similarity and distance, near-diagonal projection confusion matrices, and the physical-distance ablation for Projection.

Limitations

  • Alignment quality is upstream of every downstream analysis. The paper recommends inspecting Stack Pearson similarities and filtering misaligned regions.
  • ∆Analysis depends on niche radius, replicate count and warping. ∆Cell after warping is a relative local composition change, not necessarily an absolute density change.
  • scRTE is a relative z-scored log ratio across adjacent samples and technologies, not an absolute translation-efficiency measurement in the same cell.
  • Several biological workflows require expert choices, including brain-region refinement, gene clustering, enrichment analysis, hot-zone thresholds and condition-specific radii.
  • The Supplementary Information was linked but not converted in this workspace, so full ablation and parameter-sensitivity details are not source-indexed here.

  • the GitHub snapshot contains no tests, notebooks or datasets, although its README points to Zenodo and external tutorial pages for demos and reproduction material;
  • dependencies are loosely specified, and DGL is documented but omitted from setup.py requirements.

The source tree passes Python bytecode compilation, but no end-to-end run was attempted because the required datasets and demo pipelines are outside the acquired snapshot.

Reproducibility rating: 3/5

The core algorithms are public, compact and statically traceable to the paper, which is a strong foundation. Reproducing the complete publication still requires external Zenodo assets/tutorials and unreleased or unacquired downstream workflows, especially for ∆CCA/∆CCI, scRTE and figures. A researcher should expect the library to support method use, but not the GitHub commit alone to regenerate the paper.
