ISO: An RLVR-Native Optimization Stack

ISO 方法详解：继承谱，优化奇异向量框架

1. 它要解决什么问题？

RLVR（基于可验证奖励的强化学习）已经广泛用于数学推理和代码能力训练，但优化层基本照搬预训练：直接对稠密权重 $W$ 使用 AdamW、Muon 等优化器。ISO 问了一个更基础的问题：

RLVR 学到新能力时，权重矩阵中的哪些部分必须改变，哪些部分可以直接继承基础模型？

对每个二维权重矩阵做薄 SVD：

\[W=U\Sigma V^\top.\]

$\Sigma$ 表示每个奇异模态的尺度，$U$ 和 $V$ 分别表示输出侧和输入侧方向。论文发现，在所研究的 RLVR 训练中，基础模型的 $\Sigma_0$ 可以继续使用，而新能力主要由 $U,V$ 的变化承载。作者把这种功能性复用称为 spectral inheritance（谱继承）。

2. 为什么不能只看“谱变化很小”？

论文没有把相关性直接当成因果性。RLVR 的谱残差确实约占完整权重位移的几个百分点，并明显小于 SFT；但经过维度校准后，作者没有发现超出高维几何效应的强烈“保谱偏好”。

更关键的是干预实验：

  1. 保留 RLVR 学到的 $U,V$，把 $\Sigma_{\mathrm{RL}}$ 换回 $\Sigma_0$，性能基本保留；
  2. 从训练开始就固定 $\Sigma_0$、只更新 $U,V$，仍能有效学习；
  3. 反过来只更新 $\Sigma$、冻结 $U,V$，提升很有限；
  4. 只允许一侧框架变化，或者只在原有子空间内部重混合，都无法像“双框架可变、谱固定”那样解释 RLVR 权重变化。

所以准确结论是：在论文测试的 RLVR 转换中，谱可以复用，但 $U$ 和 $V$ 两侧都需要可适应。

3. ISO 的整体结构

基础权重 W0 ──SVD──> U0, Σ0, V0
                       │
                 固定并继承 Σ0
                       │
       ┌───────────────┴────────────────┐
       │                                │
离线：ISO-Merger                 在线：ISO-Optimizer
输入多个同源专家检查点             输入 RLVR 损失梯度
对齐并合并 U/V 的变化              在 U/V 上运行 AdamW 或 Muon
投影 + 掩码 + 加权 + 回缩           每步做极分解回缩
       │                                │
输出一个合并模型                  输出固定谱训练轨迹

两条路径最后都保持 $W=U\Sigma_0V^\top$，因此奇异值与基础模型一致到数值误差范围。

4. ISO-Merger：不使用数据的专家合并

输入与输出

输入是一个共享基础模型 $W_0$ 和从它出发训练的 $K$ 个 RLVR 专家 $W_1,\ldots,W_K$。输出是一个同时吸收多个专家能力的检查点。合并过程不需要训练数据、rollout、梯度更新或蒸馏。

第一步：消除 SVD 符号歧义

SVD 的每对奇异向量可以同时乘以 $-1$ 而不改变矩阵。如果不先对齐，$U_i-U_0$ 可能只是数值程序选了不同符号，并不是真实学习变化。

论文按列计算

\[s_{i,k}=\operatorname{sign}(\langle u_{0,k},u_{i,k}\rangle),\]

并同时把 $u_{i,k},v_{i,k}$ 乘以 $s_{i,k}$。

第二步：把框架变化投影到 Stiefel 流形切空间

对于正交列矩阵 $X_0$，投影为

\[\Pi_{X_0}(Y)=Y-X_0\operatorname{sym}(X_0^\top Y).\]

因此每个专家得到两组局部方向：

\[\xi_{U,i}=\Pi_{U_0}(U_i-U_0),\qquad \xi_{V,i}=\Pi_{V_0}(V_i-V_0).\]

第三步：过滤尾部模态

尾部小奇异值对应的方向估计更不稳定，专家之间也更容易冲突。ISO 保留前 $90\%$ 的列，把其余列置零。这个掩码会破坏切空间约束，所以后面还要重新投影。

第四步：计算每个专家的保留系数

先构造一阶权重效应：

\[g_i=\widetilde{\xi}_{U,i}\Sigma_0V_0^\top+ U_0\Sigma_0\widetilde{\xi}_{V,i}^\top.\]

再用 $\Gamma_{ij}=\langle g_i,g_j\rangle_F$ 构造 Gram 矩阵，求解

\[(\Gamma+10^{-12}I)\bar c=\operatorname{diag}(\Gamma), \qquad c^\star=\operatorname{clip}(\bar c,0,1.5).\]

直观上，它希望每个专家自身的一阶效应在合并结果中都保留为单位强度，同时用 ridge 和截断避免病态解、反向系数或过度放大。

第五步：重新投影、回缩并重建

把各专家方向按 $c_i^\star$ 加权，重新投影到切空间，再用极分解回到 Stiefel 流形：

\[U_\star=\operatorname{polar}(U_0+\xi_{U,\star}),\qquad V_\star=\operatorname{polar}(V_0+\xi_{V,\star}),\] \[W_\star=U_\star\Sigma_0V_\star^\top.\]

当前仓库中的 iso_merger.py 直接实现了这条流程。二维 Transformer 投影矩阵以及 embedding/lm_head 使用 ISO；一维归一化参数和偏置使用 task-vector 平均；其他张量从基础模型复制。

5. ISO-Optimizer：在固定谱坐标中训练

ISO-Optimizer 不发明新的 AdamW 或 Muon 更新公式，而是改变优化变量。固定

\[W(U,V)=U\Sigma_0V^\top,\]

若损失对权重的梯度为 $G_W$，则链式法则给出

\[G_U=G_WV\Sigma_0,\qquad G_V=G_W^\top U\Sigma_0.\]

基础优化器分别更新 $U,V$ 及各自状态，得到临时变量 $\bar U,\bar V$；随后做

\[U^+=\operatorname{polar}(\bar U),\qquad V^+=\operatorname{polar}(\bar V),\]

再重建 $W^+=U^+\Sigma_0(V^+)^\top$。

这不是“先对 $W$ 做普通更新，再投影回固定谱集合”。优化器状态从一开始就定义在 $U,V$ 坐标中，因此优化几何和可行轨迹都不同。

6. 实验结果怎样理解？

  • ISO-Merger 在 Qwen2.5-7B 三专家设置中总体平均为 63.80，最佳无数据基线为 62.88；在 DeepSeek-R1-Distill-Qwen-1.5B 双专家设置中为 44.38，对应最佳基线为 43.52。
  • ISO-AdamW 在 1.7B 和 4B 数学任务上分别达到 28.74 和 43.46 的总体分数，并在编码任务上从 AdamW 的 25.13 提高到 26.20。
  • Qwen3-8B 上，ISO-AdamW 在 100 步达到 AdamW 约 270 步才达到的 0.495，并在 210 步达到 0.509。
  • 4B 的性能分析显示，FP64 SVD 回缩增加约 86 秒优化器更新时间，但在 rollout 占主导的完整 RL 步中约占 7% 额外开销。

这些是特定模型、数据和训练配置下的结果，不能直接推广为所有 RLVR 都必然适合固定谱优化。

7. 当前代码能复现到哪里？

代码仓库只发布了 ISO-Merger，核心算法与论文高度对应，但没有提供示例模型、测试、评估脚本或实验检查点，因此本次只能完成静态代码核对，不能重跑论文表格。

ISO-Optimizer 实现未找到。 仓库 README 明确写着 verl 训练代码 “coming soon”。分布式回缩、训练配置、评估流水线和运行资产也没有发布。因此，ISO-Optimizer 目前可以依据论文理解算法，但不能仅靠这个仓库复现实验。

ISO: An RLVR-Native Optimization Stack

Problem

RLVR has advanced rapidly in objectives, data, and systems, but still usually inherits weight-space parameterizations and optimizers from pre-training. ISO studies this neglected layer by separating each matrix into singular values and two singular frames, then asks which components RLVR must change.

Main finding and method

The paper identifies spectral inheritance: in the studied RLVR runs, a base model’s singular-value spectra remain functionally reusable while capability is acquired through changes to both input and output frames. Raw near-isospectrality is not by itself evidence of an intrinsic optimization preference—the authors’ dimension-aware control weakens that interpretation—but interventions are stronger: restoring the base spectrum preserves most RLVR gains, fixed-spectrum training learns well, and spectrum-only training does not.

ISO operationalizes this result in two forms:

  • ISO-Merger composes shared-base RLVR specialists without data or rollouts. It sign-aligns their singular frames, projects frame changes to Stiefel tangent spaces, masks noisy trailing modes, solves for per-expert retention coefficients, polar-retracts the aggregate, and reconstructs weights with the base spectrum.
  • ISO-Optimizer trains online in the parameterization $W=U\Sigma_0V^\top$. AdamW or Muon updates $U,V$ and ISO polar-retracts the tentative factors after every update, keeping $\Sigma_0$ fixed.

Evaluation

ISO-Merger is tested on a three-expert Qwen2.5-7B-Instruct composition (coding, tool use, memory) and a two-expert DeepSeek-R1-Distill-Qwen-1.5B composition (coding, math). Against Task Arithmetic, TIES, TSV, RAM, and OrthoMerge-G-TIES, it reports the highest overall averages: 63.80 versus the best baseline’s 62.88, and 44.38 versus 43.52.

ISO-Optimizer is evaluated with verl/DAPO on DeepMath-103K and ArcherCodeR across 1.5B-8B models. Reported aggregate math scores improve from 28.35 to 28.74 at 1.7B and from 42.23 (best AdamW/Muon comparator) to 43.46 at 4B; coding average improves from 25.13 to 26.20. On Qwen3-8B, ISO-AdamW reaches AdamW’s eventual 0.495 score at step 100 rather than 270 and reaches 0.509 by step 210. The profiled 4B run attributes about 7% end-to-end step-time overhead to the SVD-based retraction.

Reproducibility and limitations

Reproducibility: 2/5. The official repository at commit a4b951f79b4dbf3c6c5778753bd0c986451adb10 releases a readable, self-contained ISO-Merger script whose core equations closely match the paper. It does not include example checkpoints, tests, evaluation scripts, or experiment configs, so the reported merging results were not rerun.

ISO-Optimizer is Not found in the released snapshot: the README says its verl-based training code is coming soon. Distributed retraction, training/evaluation pipelines, checkpoints, and runtime assets are therefore unavailable. Reported optimizer results can be understood from the paper but cannot be reproduced from this repository alone.

The evidence is also recipe-specific. ISO does not establish that all RLVR transitions are spectrally inheriting, nor that factor-space ISO is superior to every spectrum-preserving weight-space alternative. Repeated or close singular values create frame-identifiability subtleties, and the extra factor state/storage may matter outside rollout-dominated RL workloads.
