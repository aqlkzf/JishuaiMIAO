SIMO

Spatial integration of multi-omics single-cell data with SIMO

Open paper

SIMO 方法解读：以空间转录组为锚点，顺序定位多种单细胞组学

1. SIMO 的任务与基本假设

SIMO 要把没有空间坐标的 scRNA-seq、scATAC-seq、单细胞 DNA 甲基化或 CUT&Tag 细胞放回空间转录组（ST）组织切片。它不是一次性联合拟合所有模态，而是采用顺序锚定：先把 scRNA-seq 映射到 ST，因为二者共享基因表达；再把其他组学映射到已经获得空间坐标的 RNA 细胞，最后在共同坐标系中分析跨模态调控关系。

这个设计把困难拆成两个较可控的问题，但也带来明确边界：第二阶段依赖第一阶段的 RNA 坐标与细胞类型，前一步的标签或空间错误会向后传播。最终坐标是算法重建，不是同一细胞的原位测量。

2. 第一阶段：用 FGW 同时对齐表达与内部结构

输入 ST spots 与 scRNA cells 必须有共同基因，并在 layers['counts'] 中提供计数；ST 在 obsm['spatial'] 有二维坐标，scRNA 在 obsm['reduction'] 有低维表示。代码将两边计数拼接后共同预处理，以欧氏距离构造跨域表达代价 $M$；同时分别从 ST 坐标和 scRNA 低维表示构造 kNN 图，再由最短路得到模态内距离 $C_s,C_r$。

SIMO 用 fused Gromov–Wasserstein（FGW）最优传输求 spot—cell 耦合 $\Pi$：

\[\min_{\Pi} (1-\alpha)\sum_{ij}M_{ij}\Pi_{ij} +\alpha\sum_{ii'jj'} (C_{s,ii'}-C_{r,jj'})^2\Pi_{ij}\Pi_{i'j'}.\]

第一项偏好表达相似的 spot 与细胞；第二项要求 ST 空间邻域和 scRNA 流形邻域在映射后保持相似。默认 $\alpha=0.1$。论文模拟表明它比只看表达（$\alpha=0$）或只看图结构（$\alpha=1$）更抗噪，但这是实验选择，不是所有组织的理论最优值。

alignment_1() 默认使用均匀 spot/cell 质量。它还默认 aware_st=True 与 aware_sc=True：若两个节点的 obs['type'] 标签不同，distances_cal() 会放大相应图距离。这会利用已有细胞类型信息提高对齐，但也意味着默认流程并非完全“标签无知”；错误或粒度不一致的标签会主动扭曲几何。没有这些列时，默认调用也会失败，用户需提供标签或关闭 type-aware 选项。

底层 fgw_ot() 是适配旧 POT 接口的条件梯度实现，显式调用 ot.gromov.init_matrix、gwloss/gwggrad 和 ot.optim.cg。论文/README 指定 POT 0.8.2；较新 POT 的内部 API 可能不同，当前静态源码对应不能替代环境兼容性测试。

3. 从概率耦合到每个 spot 的细胞组成

$\Pi$ 只是连续运输质量，不能直接理解成一个 spot 内的离散细胞清单。SIMO 先估计 spot 容量与细胞类型组成，再从高权重候选中分配细胞。

代码在坐标分配流程中用非负最小二乘（NNLS）拟合 spot 表达：以各细胞类型的平均表达解释 ST spot，从而得到非负类型比例。随后结合 spot 的估计细胞数、类型配额和 FGW 权重选择实际单细胞。这个步骤防止数量多的类型仅凭较多候选占满 spot，但结果仍依赖参考表达、细胞类型注释与容量估计。

选中的 RNA 细胞先继承 spot 附近的坐标，再在相邻 spots 之间按细胞表达与 spot 表达的 Pearson 相关系数细化位置。源码会缩放邻居相关性，沿 spot 间坐标差做加权或平均偏移，并把位置限制在局部范围内。所得“spot 内坐标”是可视化和局部排序的启发式细化，不具有亚 spot 级实验分辨率。

4. 第二阶段：把 ATAC、甲基化或组蛋白信号接到空间 RNA 上

其他模态通常没有与 RNA 相同的原始特征，因此 SIMO 先准备可桥接的表示，例如 ATAC gene activity、甲基化—基因关联或 CUT&Tag 对应信号。这些输入往往由 Signac、ArchR、chromVAR 或其他外部流程生成；Python 包并不从原始 fragments/BAM 自动完成所有上游处理。

第二阶段分两层：

  1. 簇级标签转移：对 RNA cluster 与 modality-2 cluster 的平均桥接特征计算 Pearson 相关。cluster_cor() 以 unbalanced OT 的 MM 求解器在簇之间分配质量，允许某些簇没有完全对应。
  2. 簇内细胞匹配：在匹配的类型/簇内分别构造低维 kNN 图，用纯 GW 比较两边内部几何，得到 RNA cell 与 modality-2 cell 的耦合。

对通常与表达正相关的 ATAC/gene activity，代价使用 $1-r$；当 modality2_type='neg' 时，代码直接用相关矩阵 $r$ 作为最小化代价，因此更负的相关得到更低成本，用来处理 H3K27me3 等与转录倾向反相关的模态。这是符号方向的工程编码，并不意味着所有该模态特征都必然负调控。

第二模态细胞从其匹配的、已经定位的 RNA 细胞继承邻域，再按低维嵌入余弦相似度在附近坐标间细化。最终不同模态共享同一个 ST 坐标框架，但不是跨模态同一细胞的实测配对。

5. 空间调控分析在算什么

获得坐标后，SIMO 提供两层关联分析。regulation_analysis() 先在每个模态按细胞类型做差异特征分析，再对预定义的基因—motif、基因—甲基化等配对，比较其跨细胞类型 fold-change，并计算 Pearson 相关。正负相关是跨类型一致性指标，不等价于直接调控因果。

spatial_regulation() 先在每个模态内做空间 kNN 平滑，再通过跨模态空间近邻互相估计信号。组合后的特征矩阵用高斯空间核

\[K_{ij}=\exp\left(-\frac{\lVert z_i-z_j\rVert^2}{2\sigma^2}\right)\]

计算空间加权相关，默认 $\sigma=140$，随后用重复子采样的 consensus clustering 划分调控模块并过滤内部相关/连通性不足的模块。平滑、核宽度、候选调控配对和模块过滤阈值都会影响结果；模块是空间共变程序，不是实验验证的调控网络。

7. 当前代码快照与复现边界

应使用嵌套仓库 SIMO/，其 HEAD 为 2d05908d2ba780a18b43d950279ccdc707f968a0；旧合同误把工作区根部的 setup.py 当作 code source。根部还存在一份包文件副本，但本轮版本证据以带 .git 和 .repo_source 的 SIMO/ 为准。

核心论文路径在 SIMO/simo/simo.py、helper.py、regulation.py 和 clustering.py 中可直接找到，但完整数值复现仍受以下条件限制：

  • 需要论文数据、细胞类型注释、counts/reduction/spatial 等 AnnData 字段和多种外部生成的桥接特征。
  • 默认 type-aware 距离不是纯无监督设置，且标签错误会传播。
  • 第一阶段 FGW、第二阶段 UOT/GW、NNLS 和坐标启发式是顺序依赖关系，不能把最后误差归因于单个 OT 求解器。
  • POT 0.8.2、scanpy 1.9.1、anndata 0.9.2 等旧依赖需隔离环境；当前工作区没有锁定完整 R/Python 系统环境和论文全部随机种子。
  • alignment_1_batch() 通过拆分细胞减少内存，但各批独立求解会改变全局运输问题，不保证与完整 FGW 等价。
  • FGW/GW 需要稠密跨域耦合和平方图距离；空间调控还构造全体细胞的高斯核，大数据会受到内存限制。

8. 一句话把握 SIMO

SIMO 先用共享表达和图结构把 scRNA 细胞定位到 ST，再以这些已定位 RNA 细胞为中介，把其他单细胞组学按簇级相关与簇内几何接入空间；它能处理正相关和反相关模态并支持空间调控模块分析，但坐标和调控关系都是顺序模型推断，强烈依赖注释、桥接特征、参数和上游预处理。

SIMO: Spatial Integration of Multi-Omics Single-Cell Data

Paper: Yang P, Jin K, Yao Y, Jin L, Shao X, Li C, Lu X & Fan X. Nature Communications (2025). DOI: 10.1038/s41467-025-56523-4

Code: https://github.com/ZJUFanLab/SIMO (Python, GPL-3.0)

Motivation & Novelty

The Problem

Current spatial omics technologies primarily capture a single modality — mainly transcriptome or proteome — on tissue sections. Single-cell multi-omics methods (scRNA-seq, scATAC-seq, snmC-seq) provide rich multi-modal profiles but destroy spatial information during tissue dissociation. Existing computational methods either focus solely on transcriptomics integration with ST (e.g., Tangram, Nature Methods 2021; CARD, Nature Biotechnology 2022), rely on pre-paired multi-omics data (SpaTrio, Cell Genomics, 2023), or fail to effectively incorporate spatial information when integrating modalities (Seurat, Cell 2021; LIGER, Cell 2019; Scanorama, Nature Biotechnology 2019).

What’s New

SIMO introduces three key contributions:

  1. Sequential multi-omics spatial mapping: A two-stage alignment strategy that first maps scRNA-seq to ST via shared transcriptomics (FGW-OT), then maps additional modalities (ATAC, methylation) to already-mapped RNA cells via bridging features (gene activity scores). This decomposition avoids the complexity of joint multi-modal OT while preserving spatial information.

  2. Handling anti-correlated modalities: Unlike all compared methods, SIMO can correctly integrate modalities that show negative biological correlation with transcriptomics (e.g., H3K27me3 CUT&Tag — high silencing marks correspond to low gene expression). This is achieved by using the correlation matrix directly (instead of 1-correlation) when modality2_type='neg'.

  3. Integrated downstream analysis: Beyond spatial mapping, SIMO provides gene regulation analysis (TF-gene correlation across modalities) and spatial regulation analysis (identifying gene modules with coherent spatial regulation patterns via consensus clustering on spatially-weighted correlations).

Method Overview

SIMO is a computational pipeline for projecting multiple single-cell omics modalities into a shared spatial coordinate system anchored by spatial transcriptomics.

Core Pipeline:

  1. Gene selection: Wilcoxon DEG analysis → top 100 marker genes per cluster, intersected across datasets
  2. Modality 1 alignment: Fused Gromov-Wasserstein optimal transport (FGW-OT) with α=0.1, balancing gene expression similarity and graph structure preservation
  3. Spot deconvolution: Non-negative least squares (NNLS) estimates cell type composition per spot
  4. Coordinate refinement: PCC-based adjustment using neighboring spot expression
  5. Modality 2 alignment: Unbalanced OT for cluster label transfer → Gromov-Wasserstein for within-type cell matching → cosine similarity-based coordinate refinement
  6. Regulation analysis: Gene regulation (fold change correlation) and spatial regulation (spatial smoothing → cross-modal smoothing → Gaussian kernel-weighted correlation → consensus clustering)

Key assumptions: (i) Transcriptomics is the shared modality between ST and single-cell data; (ii) cell type annotations or unsupervised clusters are available; (iii) gene activity scores or similar bridging features connect non-transcriptomic modalities to RNA.

See doc_method.md for mathematical details and doc_code.md for implementation mapping.

Evaluation

Simulated Data

Six patterns of increasing spatial complexity (3-10 cell types, 15%-91% multi-type spots), tested with noise levels (pseudocount δ = 0 to 5). SIMO (α=0.1) achieves:

  • Pattern 1: >91% mapping accuracy under high noise (δ=5), RMSE near 0
  • Pattern 4 (67.8% multi-type spots): 73.8% accuracy, RMSE=0.205
  • Pattern 6 (91% multi-type spots, 10 types): 55.8% accuracy, RMSE=0.182

Benchmarks vs Existing Tools

Method Type Performance
SIMO Multi-omics spatial Best across all metrics on noisy data; close to best on clean data
CARD (Nature Biotechnology, 2022) Spatial deconvolution Strong on simple patterns, degrades with noise
Tangram (Nature Methods, 2021) Spatial mapping Competitive on Dataset 2 (RMSE=0.101 vs SIMO 0.119 clean), but worse under noise
Seurat (Cell, 2021) Multi-modal integration Moderate; does not handle anti-correlated modalities
LIGER (Cell, 2019) Multi-modal integration Second-best on some noisy datasets
Scanorama (Nature Biotechnology, 2019) Batch integration Weakest performance overall

Key advantage: Under noise (δ=5), SIMO’s lead becomes more pronounced — e.g., Dataset 3 RMSE = 0.186 vs LIGER 0.221 (15.8% improvement). SIMO is uniquely capable of handling H3K27me3 data (anti-correlated with RNA).

Biological Datasets

  • Dataset 1 (mouse embryo Spatial ATAC-RNA-seq): Correctly reconstructed Six6 localization to eye region
  • Dataset 2 (mouse brain Spatial ATAC-RNA-seq): Resolved brain region-specific markers (Pde10a/striatum, Sox10/corpus callosum)
  • Dataset 3 (mouse brain Spatial CUT&Tag-RNA-seq H3K27me3): Only method to correctly capture anti-correlation between H3K27me3 and RNA expression; reconstructed 611 feature associations (highest among all tools)

Real-World Applications

  • Mouse cerebral cortex (Drop-seq + snmC-seq + 10x Visium): Correctly reconstructed cortical layer ordering; revealed Layer5a heterogeneity with two spatial modules showing distinct expression-methylation patterns
  • Human myocardial infarction (scRNA-seq + scATAC-seq + 10x Visium): Identified cardiomyocyte subpopulations with wound-healing activity near infarct zone; spatial module analysis revealed gene-motif modules with distinct spatial distributions relative to infarct area

Reproducibility

Rating: 4/5

Strengths:

  • Code publicly available on GitHub with GPL-3.0 license, also deposited on Zenodo
  • Two tutorial notebooks (mouse brain, human heart) with step-by-step workflows
  • All datasets have public accession numbers (GEO, Zenodo, atlasxomics)
  • Clear documentation of default parameters
  • Pinned dependency versions in setup.py

Weaknesses:

  • No conda/pip environment file (only setup.py with == pinned versions)
  • Tutorial notebooks reference pre-processed .h5ad files not included in the repo
  • Gene activity score computation is external (R/Signac), creating a cross-language dependency
  • Some parameters in real-data analyses (e.g., sigma=140, region delineation) require biological judgment

Practical notes:

  • Install: pip install -e . from the repo root
  • Requires POT 0.8.2 specifically — newer versions may have API changes in ot.gromov
  • ATAC preprocessing requires R (Signac/ArchR for gene activity scores, chromVAR for TF motifs)
  • For the mouse cortex analysis, data comes from three separate sources (Drop-seq, snmC-seq, Visium), each requiring separate downloading and preprocessing
  • The alignment_1_batch function can help with memory for large datasets but is undocumented
