TopACT 方法解读：在最小可信尺度上定位细胞类型

一句话定位

TopACT 解决的是一个由“分辨率过高”造成的反常问题：Stereo-seq、Visium HD 等技术的单个测量 spot 比细胞小，每个 spot 只有细胞转录组的一小部分，不能直接做可靠分类；若先把 spot 固定合并成大 bin，又会丢掉单细胞位置并漏掉稀疏细胞。TopACT 对每个位置逐级扩大邻域，选择第一个让参考分类器达到置信阈值的尺度，从而在尽量小的空间范围内给出细胞类型。

论文随后把 TopACT 定位出的免疫细胞转成点云，用 multiparameter persistent homology（MPH）描述它们是否围成环。两部分必须区分：TopACT 核心包负责参考分类器和多尺度定位；RIVET 与 SpatialPatterningOfImmuneCells 是下游拓扑分析，不是 topact 包内部的分类步骤。

输入、输出与关键假设

核心输入有两类：带细胞类型标签的 sc/snRNA-seq 参考矩阵，以及亚细胞分辨率空间转录组的坐标—基因—计数表。两者必须有足够的共享基因。输出首先是一个四维置信数组：空间行、空间列、聚合尺度、参考细胞类型；给定阈值后，再得到 spot 到细胞类型的映射或分类图。研究者可把相邻的同类阳性 spot 膨胀、连通并取中心，形成候选细胞位置。

方法的生物学假设是：若一个查询点位于某个细胞内，逐渐汇总其周围亚细胞 spot 后，累积表达会越来越接近该细胞类型在单细胞参考中的表达。最小可信尺度能保留位置精度；更大的尺度只在读数稀疏时才启用。这个假设在细胞密集边界、RNA 扩散强或参考缺少真实状态时会变弱。

第一步：训练能输出概率的局部分类器

本地实现 SVCClassifier 对参考矩阵逐细胞做 library normalization：

\[\tilde{x}_{cg}=\log\left(1+\frac{10^r x_{cg}}{\sum_g x_{cg}}\right),\qquad r=5.\]

随后使用不做均值中心化的 StandardScaler 和 LinearSVC。普通线性 SVM 给的是间隔而非概率，因此外层用 CalibratedClassifierCV 做 Platt calibration，得到每个细胞类型的置信度向量。论文允许局部分类器换成别的监督模型，但当前发布代码实现的是这一条 SVM 管线。

这意味着 TopACT 不是 reference-free：参考数据的标签体系、批次差异和缺失类型都会影响空间预测。所谓“自动”指给定已训练分类器后自动选择空间尺度，并不代表不需要单细胞参考或人工注释。

第二步：逐位置构造多尺度表达

对空间位置 $s=(i,j)$ 和尺度 $r$，定义邻域表达总和

\[X_r(s)=\sum_{s'\in\mathcal{N}_r(s)}v_{s'}.\]
论文用“ball”描述邻域；代码的 square_nbhd_vec 实际使用 $L_\infty$ 方形邻域，即 $ i’-i \le r$ 且 $ j’-j \le r$。方形可用规则网格快速索引，但它与欧氏圆盘在角落处并不相同，应标为实现约定而非数学上完全同一。

对从 min_scale 到 max_scale 的每个整数尺度，worker 汇总表达，跳过前导全零尺度，并把剩余尺度一次送进分类器。由此得到

\[A(s)=[v_{r_1},v_{r_2},\ldots,v_{r_k}],\]

其中 $A_{jc}(s)$ 是位置 $s$ 在尺度 $r_j$ 被判为类型 $c$ 的概率。CountGrid.classify_parallel() 以多进程按空间行分发任务，并把结果写入 memory-mapped NumPy 数组，避免整个大型置信张量常驻内存。

空间背景可先用 density_mask 排除：代码对总转录本图做局部 pooling 和阈值判断，再取高表达区域的 convex hull。这是计算域限制，不是细胞边界分割；凸包内部仍可能含空洞或非组织区域。

第三步：取最小可信尺度

设阈值为 $\theta$，TopACT 选择

\[j^*=\min\{j:\max_c A_{jc}(s)\ge\theta\},\]

并将对应的 $\arg\max_c A_{j^*c}(s)$ 作为位置标签。若所有尺度都未过阈值，则不分类。

源码 extract_classifications() 用 np.where(confidence_matrix >= threshold) 找出所有过阈值项。NumPy 返回的索引按空间位置、尺度、类别顺序排列，字典只保留每个位置第一次出现的项，因此落实“最小尺度优先”。需要注意，若同一最小尺度有多个类别同时超过阈值，当前逻辑取索引顺序最前的类别；通常 calibration 概率和高阈值会降低这种并列情况，但代码没有显式再做一次 argmax 决胜。

阈值控制覆盖率与精确率：高阈值会留下更多未分类点，却减少低置信调用；低阈值扩大覆盖但更易受邻近混合表达影响。半径和阈值是数据集参数，而非跨平台固定常数。论文对 Xenium 使用 1 µm bin、2–5 µm 半径和 0.9 置信度；Stereo-seq 的网格与扩散尺度不同，不能照搬。

从 spot 标签到候选细胞

TopACT 的直接输出仍是 spot-level 标签。论文针对稀有类型，把同类型阳性点构成二值图，做 binary dilation 连接被稀疏读数切开的部分，再以 connected component 的中心作为细胞位置，并按组件大小过滤。这个过程比核染色分割少依赖图像，但也不是恢复精确细胞膜：膨胀半径、最小组件面积和相邻同类细胞会影响“一块是否等于一个细胞”。

因此论文标题中的“classifies cells”应理解为从亚细胞转录点定位候选单细胞类型，而不是输出每个细胞的像素级轮廓。Xenium 图中形成更合理的管腔形态，是转录本分类图与组织结构一致的结果，不能把它等同于通用实例分割模型。

第四步：用 MPH 描述空间环结构

定位某类细胞后，作者把细胞中心视为二维点云。Rips-codensity bifiltration 同时改变两个参数：空间连接半径 $s$ 与 codensity 阈值 $t$。半径决定哪些点可形成边和环，codensity 过滤不同局部稀疏程度的点。第一同调 $H_1$ 跟踪环状结构，MPH landscape

\[\lambda_k:\mathbb{R}^2\rightarrow\mathbb{R}\]

概括第 $k$ 个显著拓扑特征在 $(s,t)$ 平面中的强度。论文聚焦 $\lambda_1$：高半径区域出现强激活，对应较大的环；codensity 维度让结构对少量离群点更稳健。

这部分需要外部 RIVET 计算 bifiltration，再由 SpatialPatterningOfImmuneCells 仓库读取输出和生成 landscape。TopACT 主仓库没有把它封装成端到端 API；两个本地代码快照分别固定为 TopACT commit ab032e3ac243f615964d729198e7fa6e6feeb20e 与 MPH 辅助仓库 commit b86114a135b3e45dac37edf7219b0ebad9517163。

图 2–4：分类性能与定位证据

图 2的 Voronoi 模拟给出已知细胞边界和类型。100 次模拟中，TopACT 平均准确率约 0.808，高于 RCTD 固定 bin 的 0.668 和固定 bin 可达到的 modal 上界 0.693，并能召回 immune、podocyte、urothelium 等稀有类型。这个比较支持“自适应尺度优于固定窗口”，但模拟用参考构造表达，不能覆盖真实批次偏移。

图 5：从预测到正交验证

在 IMQ 诱导的 lupus-like 小鼠肾中，TopACT 预测 treated glomerular patches 的免疫细胞数高于 non-glomerular patches，而 control 无显著差异。免疫细胞至 podocyte 的距离进一步支持 glomerular infiltration。

treated patch 的平均 MPH landscape 在大半径处激活，作者预测免疫细胞沿肾小球外围成环。随后 multiplex immunofluorescence 显示 treated glomeruli 的总免疫信号升高，并且 T cell 与 myeloid 信号更偏外围；B cell 没有相同趋势。这里的强点是拓扑预测得到独立成像支持。不过 MPH 对点云和 patch 的结构进行组间概括，不证明具体细胞的迁移轨迹或因果机制。

论文与当前代码的对应

核心对应为 Exact：classifier.py 中 CPM-like normalization、LinearSVC 与概率校准；spatial.py 中多尺度方形汇总、首个非零尺度、并行置信矩阵与最小过阈值提取；densetools.py 中 density hull；这些都能从固定快照直接定位。

需保留为 Partial 的地方包括：论文写一般的 radius ball，代码固定为方形 $L_\infty$ 邻域；阈值与半径是实验参数，demo/default 不能代替论文各数据集配置；候选细胞的 dilation、连通组件和尺寸过滤属于实验工作流，不是核心 extract_classifications() 自动完成的全部步骤。

下游 MPH 是第二代码库加 RIVET 的组合。模拟生成、RCTD 比较和完整论文实验脚本由论文另行存放在 Zenodo，当前核心 TopACT 仓库不能单独重现所有图。现有 SpatialPatterningOfImmuneCells 主要是此前发表的 MPH landscape 工具和示例 notebook，不应误记为 TopACT 的核心 code source。

使用与解释边界

  1. 必须有可靠的带标签单细胞参考；参考缺失的类型不会凭空被发现。
  2. 每个位置独立选最小尺度，不能保证相邻 spot 标签形成拓扑一致的细胞轮廓。
  3. RNA diffusion、低捕获和细胞边界混合会改变合适半径；模拟显示扩散增大时优势会下降。
  4. 高阈值提高特异性但降低覆盖；未分类不代表该处没有细胞。
  5. connected component 是细胞调用启发式，相邻同类细胞可能合并，稀疏单细胞也可能断裂。
  6. MPH 的环是点云组织模式，不是分子通路，也不直接给出形成该结构的机制。
  7. 大型空间张量写入 memmap 仍可能占用数十 GB；运行前需根据网格、尺度数和类型数估算存储。

TopACT: Summary

(Oxford Mathematics + BGI Research) Journal: Nature 630(8018), 2024-06-19 DOI: 10.1038/s41586-024-07563-1 Code: https://gitlab.com/kfbenjamin/topact (Python, GPL-3.0) Category: segmentation_annotation

Motivation & Novelty

The problem

Subcellular spatial transcriptomics platforms (Stereo-seq, Visium HD, Seq-Scope, HDST) measure gene expression at resolutions of 0.5–2 μm — far smaller than the ~10–20 μm diameter of a typical cell. Each measurement spot contains transcripts from a fraction of one cell. To obtain single-cell annotations, existing approaches apply expression binning: aggregate spots into a fixed grid (~10–20 μm bins) and apply decomposition methods (RCTD [Nat. Biotechnol. 2021], Tangram [Nat. Methods 2021], Cell2location [Nat. Biotechnol. 2022]). This approach:

  • Discards the subcellular resolution advantage
  • Fails for sparsely distributed cells (immune cells, podocytes) caught between bin boundaries and dominated by abundant tissue-specific signatures
  • Cannot resolve individual cell morphology

For imaging-based platforms (Xenium, MERFISH, seqFISH), cell segmentation is image-driven, which is sensitive to imaging quality, tissue heterogeneity, and staining artifacts.

What TopACT introduces

  1. Transcription-based subcellular cell type identification without image segmentation: classifies each spot by dynamically aggregating its local neighborhood at multiple radii, finding the smallest scale at which a confident prediction can be made
  2. Detection of rare, sparsely dispersed cells: immune cells and podocytes invisible to fixed-window decomposition can be pinpointed individually
  3. Integration with multiparameter persistent homology (MPH): translates spot-level annotations into a topological feature vector (MPH landscape) that characterizes the spatial arrangement of cell types across samples — enabling comparison of cell organization patterns between conditions

Compared methods and their limitations

RCTD Decomposition (NMF-like) Nat. Biotechnol. 2021 Fixed-window only; cannot resolve single cells
Tangram Imputation (DL) Nat. Methods 2021 Requires fixed window; does not localize cells

Method Overview

TopACT is a two-stage pipeline: (1) spot-level cell type annotation via multiscale aggregation and SVM classification; (2) spatial pattern quantification via multiparameter persistent homology.

Stage 1: TopACT cell type annotation

  • Trains a local SVM classifier (LinearSVC + Platt scaling) on an annotated sc/snRNA-seq reference, using CPM normalization ($10^5$ scale) and log1p transformation
  • For each spot in the spatial grid, aggregates expression from a square neighborhood at multiple radii $r_1 \leq r_2 \leq \cdots \leq r_k$
  • Produces a multiscale confidence matrix $A \in \mathbb{R}^{K \times k}$ (K cell types, k scales)
  • Assigns cell type at the smallest radius where a confident prediction ($\geq \theta$) exists

Key biological assumption: summing transcripts from enough subcellular spots of the same cell type produces an expression vector comparable to a full sc/snRNA-seq profile of that cell type.

Stage 2: MPH spatial pattern analysis

  • Extracts coordinates of TopACT-predicted cells as a 2D point cloud per tissue patch
  • Computes the Rips-codensity bifiltration (two parameters: radius $s$ and sparsity $t$)
  • Summarizes the topology (loops = rings of cells) as an MPH landscape $\lambda_1(s,t)$
  • Averaged landscapes across samples reveal characteristic spatial motifs (e.g., peripheral ring of immune cells around glomeruli)

Key technical components

  • L∞ (square) neighborhoods for computationally efficient grid-based aggregation
  • Python multiprocessing (Queue-based) for parallel spot-level classification
  • Memory-mapped numpy arrays for large-scale output
  • External RIVET binary + SpatialPatterningOfImmuneCells repo for MPH

Key results

Synthetic benchmarking (n=100 iterations):

  • TopACT accuracy: M = 0.808 (s.d. = 0.006)
  • RCTD (fixed-window): M = 0.668 (s.d. = 0.010)
  • Theoretically optimal fixed-window modal: M = 0.693 (s.d. = 0.009)
  • TopACT maintains superiority up to 5 μm mean RNA diffusion

Rare cell detection: TopACT consistently identifies all (or all but a few) cells for rare types (Immune, Podocyte, Urothelium) across 100 synthetic iterations

Mouse brain: Identified 66 perivascular macrophage (PVM) cells invisible to standard 50×50 nanoball binning and ssDNA segmentation; validated by expression of known PVM marker genes

Human kidney (Xenium): TopACT-predicted tubule segments show biologically plausible lumen structure consistent with H&E; all podocytes correctly localized to glomeruli (conventional Seurat labels podocytes in extra-glomerular regions)

Mouse lupus kidney (IMQ model):

  • Significant increase in glomerular immune cells (t=3.988, P=4.2×10⁻⁵) in treated vs. control
  • 80% of TopACT immune predictions concordant with ssDNA segmentation; 92% for podocytes
  • MPH landscape activated at high radius in treated samples → predicted peripheral ring of immune cells
  • Validated by multiplex immunofluorescence: increased glomerular immune staining (P=5.6×10⁻¹²), peripheral enrichment (outer/central ratio, P=7.3×10⁻⁵) in T cells and myeloid cells

Reproducibility: 4/5

Justification: Core TopACT library is well-structured, documented, and publicly available (GitLab + Zenodo archive). Demo script covers the full workflow from data loading to annotation. However:

  • Experiment code is at Zenodo, not in the main repo — requires downloading separately (10.5281/zenodo.11050996)
  • MPH pipeline requires two separate codebases: topact library + SpatialPatterningOfImmuneCells + RIVET binary (C++ binary, must be compiled separately from https://github.com/rivetTDA/rivet/)
  • Raw Stereo-seq mouse data available (BioProject PRJNA1099448, GEO GSE264321); human Xenium (GEO GSE264334)
  • Python 3.10 strict requirement (pyproject.toml specifies >=3.10,<3.11) — may cause environment setup issues

Environment setup:

pip install git+https://gitlab.com/kfbenjamin/topact.git
# or
git clone https://gitlab.com/kfbenjamin/topact.git && cd topact && pip install .
# For MPH: compile RIVET (https://github.com/rivetTDA/rivet/)
# then clone: https://github.com/MultiparameterTDAHistology/SpatialPatterningOfImmuneCells

Common pitfalls:

  1. Python 3.10 strict requirement — using 3.11+ will fail poetry install
  2. first_nonzero_1d depends on py-find-1st and utils_find_1st — these are the same package; import name differs from pip name
  3. RIVET must be compiled from source; no pip package available
  4. Memory-mapped .npy output files for large ST datasets can reach tens of GB — ensure sufficient disk space before classify_parallel()
  5. The MPH code from SpatialPatterningOfImmuneCells uses raw RIVET output format — coordinate systems must match

Strengths: Clear library structure, test suite (pytest), demo script, ReadTheDocs documentation, code archived at Zenodo

Weaknesses: No end-to-end workflow script combining topact + MPH; strict Python 3.10 constraint; experiment reproduction requires downloading data and additional software (RIVET)
